## 1. 核心问题:目的论稳定性 vs 反应式正确性

论文把整个设计动机压缩成一句话式的张力:

- **Teleological stability(目的论稳定)**:agent 要能连贯地追求跨越数天的多重目标(升学、升职、攒钱、盖房)。
- **Reactive correctness(反应式正确)**:agent 又必须对瞬时变化正确响应——价格在变、库存在变、别人在抢同一批矿石、自己饿了困了病了。

传统做法要么长链顺序规划(远视但脆弱,环境一变整条计划报废),要么反应式策略(灵活但短视,永远爬不上社会阶梯)。AIvilization 的答案是**分层 + 预演 + 分级重规划**三件套,再叠加一套**双过程记忆**来承载身份演化。

## 2. Agent 架构(论文第 2 节)

认知核心分四块:(A) 双过程记忆、(B) 分层规划器、(C) 动作模拟器、(D) 环境。四者构成闭环:记忆→规划→预演→执行→反馈→记忆。

### 2.1 Branch-Thinking Planner(BTP,分支思考规划器)

四层流水线:

**① Strategic Decomposition(战略分解)**
把顶层长期目标拆成若干**并行、半独立的目标分支**,典型分支包括:

- personal development(个人发展:健康、教育)
- production & resource management(生产与资源管理)
- trading & market analysis(交易与市场分析)
- social engagement(社交参与)

分支化的本质是**问题因子化**:每个分支在受限子空间内推理,长链误差传播被切断,同时天然支持多域并发思考。分支内还有第二层拆解——分支目标 → 抽象子任务序列,提供**时间抽象(temporal abstraction)**。

> 关键工程取舍:最高层分解**不是每周期都跑**,只在环境显著变化或需要战略重估时触发。算力省下来喂给底层的实时适应。

**② Contextual Prioritization and Selection(情境优先级选择)**
每个规划周期的入口。把所有活跃分支的候选子任务放在一起,对齐当前:

- 内部状态:health / energy / satiety / inventory
- 外部情境:市场价格、世界规则、资格门槛

然后依据**长期目标 + 人格 + 价值观**(来自长期记忆)排序,选出最可行的一个子任务。这不是过滤器而是排序器——作用是把长期战略锚定在当下现实,避免在已失效或不可行的动作上做无用功。

**③ Action Sequence Generation(动作序列生成)**
由 domain-specific micro-planner 把抽象子任务翻译成原子动作序列。因为前两层已经收窄了上下文,micro-planner 面对的动作空间显著缩小,产出的序列可执行性更高。

**④ Global Synthesis(全局综合)**
把各活跃分支的动作序列**编排**而非简单拼接。按「对顶层目标的贡献 + 分支紧急度 + 共享资源(时间、能量)约束」赋优先级并交错插入,显式处理局部最优与全局最优的冲突——比如防止「产能最大化」这一个分支把 agent 的健康搞崩。最终计划要重新对齐最初的战略意图,形成闭环。

### 2.2 Action Simulator(AS,预执行模拟)

在真正提交动作到环境之前跑一次**反事实推演**:用世界预测模型前向演化 agent 状态,提前发现资源不足、约束违反、逻辑矛盾。

发现问题后走**两阶段修补**:

1. **local repair**:一组预定义的廉价启发式规则。
2. **reactive correction**:启发式不够时升级,调用缓存的历史经验做快速模式化推理,生成替代动作或微调计划。

整个循环**不重入完整规划栈**。这是「深思」与「敏捷」之间最重要的一道成本隔离墙。

### 2.3 分级自适应重规划

| 触发条件 | 响应层级 | 成本 |
| --- | --- | --- |
| 单个动作小失败 | 查短期记忆(近期成功/失败动作 + 反思),调整下几步 | 低,类似「肌肉记忆」 |
| 轻量修补连续失败 / 环境剧变 | 完整重跑 BTP,自顶向下重建战略 | 高,兜底保证 |

### 2.4 Adaptive Agent Profile(自适应身份档案)

论断:agent 身份不是静态参数,而是**在经历中演化的档案**,主要引擎是社交。

**社交演化循环**:主动规划(基于目标/状态/人格选交互对象与话题)→ 自然语言对话(交换知识、观点、社交信号)→ **交互后反思**(更新对他人的关系/态度模型,把经历写入记忆)。当前档案指导社交行为,社交结果反塑档案。

**双过程记忆**(对应 Kahneman 快慢思考):

- **STM(短期记忆)**:高频缓冲区,记录执行轨迹,分类为 Successful / Failed Actions,并总结成具体经验。成功模式优化「子目标→动作」映射;失败模式为重规划模块预热。作用于行为,**不改变核心身份**。
- **LTM(长期记忆)**:稳定但演化的语义内核。整合重要经历(尤其社交)形成 Agent Profile:values、personality、habits、社交记录摘要。它作为**高层控制信号**,偏置 Contextual Prioritization 层的目标选择。

两条流是**双向对话**的:STM 中反复出现的战术成功会逐步固化进 LTM;LTM 中的价值观/人格反过来自顶向下决定 STM 经验如何被解读和排序。

**Unified Agent Profile 三段结构**(论文附录 Table 6 的真实样例):

```

  Education Score 31 | Balance 191,696,904 | Residential Tier 5
```

### 2.5 Human-in-the-Loop Steering(混合自治)

这是产品与研究的接缝处,也是最有设计巧思的一节。两条干预通道**映射到架构的不同层级、走不同的传播路径**:

**Strategic Steering(战略引导)**
用户设定/修改长期目标。该输入被当作顶层长期目标,**同时写入长期记忆**。它影响:BTP 如何构造与加权并行分支、优先级层如何排序子任务、Global Synthesis 如何权衡跨域取舍。

优点:
1. **稳定可解释的治理**——人类意图在与 agent 战略分解**同一抽象层级**上表达,避免了用反复的低层指令去硬掰行为的脆弱性。
2. **算力高效的持久性**——因为最高层分解只在重大情境变化时重入,一次长期引导能跨越许多周期持续生效。

**Reactive Steering(反应式引导)**
短、具体、即时的命令(如 "buy 10 fish now"、"sleep for 8 hours"、"read books for 2 hours")。走**轻量规划路线**:只调用 (i) 局部规划器翻译成动作序列 + (ii) Action Simulator 验证可行性并快修,**跳过完整 BTP**。

设计原则原话:*short-horizon clarity should not pay the cost of full-horizon deliberation*。

但即时指令**不是一次性覆盖**:其计划、执行结果与结果都写入 STM 立刻影响后续规划周期;长期反复出现则可固化进 LTM,改变 habits、preferences 乃至价值倾向,最终反向偏置最高层规划。

这套 **memory-mediated propagation(记忆中介传播)** 带来两个性质:
- **行为连续性**:即使用户反复插手,agent 也是把后果纳入既有决策流,而不是在互不相关的指令之间震荡。
- **交互式个性化**:重复的引导成为身份演化的一部分,agent 逐渐内化用户的管理风格,不需要持续微操。

一句话总结两通道分工:**长期目标决定 agent 正在成为什么,即时指令决定 agent 现在该做什么。**

## 3. 社会模拟平台设计(论文第 3 节)

设计立场:拒绝把经济行为做成简化规则模块,追求**结构现实性(structural realism)与系统级相互依赖**。宏观现象(产业专业化、财富分层、资源瓶颈)必须从微观交互中**内生涌现**,而不是靠预设均衡假设。

平台级定义:

- 货币余额 $B_a(t)$
- 库存 $Q_a(t) = (q_{a,1}(t), \dots, q_{a,n}(t))$
- 净资产 $W_a(t) = B_a(t) + \sum_{i=1}^{n} p_i(t)\, q_{a,i}(t)$(v0 无债务工具)
- 住宅等级 $R_a(t)$——离散状态,**门控**部分生产技术与职业

### 3.1 生存与生理约束

三个核心生理状态:satiety $S_a$、energy $E_a$、health $J_a$,上限受住宅等级 $R_a$ 约束。

- 所有工作与生产消耗 satiety 与 energy
- satiety 靠吃恢复,高等级食物恢复更快
- energy 主要靠 sleep 恢复
- health 因随机疾病事件与**累积睡眠不足**恶化,可去医院看医生恢复
- energy 或 health 跌破临界值 → agent 暂时失能,无法劳动或生产

生产效率被生理状态调制:

$$\text{Eff}_a(t) = G\big(S_a(t), E_a(t), J_a(t), R_a(t), H_a(t)\big),\quad G \in (0, 1]$$

$G$ 对每个自变量非递减,$H_a(t)$ 是教育分。

还有 **safety-net(安全网)**:对持续处于临界生理状态之下的 agent 发放基础食物补贴,防止不可逆退出经济系统——既保模拟连续性,也保最低福利标准。

设计意图很明确:把生物约束直接嵌进经济理性。**加班和熬夜会立刻带来效率损失**,从而制造短期产出与长期产能之间的非平凡取舍,并内生出对食物、休息、医疗的真实市场需求。

### 3.2 价格机制与宏观指数

**微观:AMM 恒定乘积做市商**

每种商品与基础货币配对成流动性池,遵循 Uniswap 式恒定乘积:

$$\text{IS}_i(t) \cdot \text{CR}_i(t) = k$$

- $\text{IS}_i$:池中商品库存量
- $\text{CR}_i$:池中基础货币储备
- $k$:实验期内固定的不变量

报价(无穷小交易的边际价)$p_i(t) = \text{CR}_i(t) / \text{IS}_i(t)$。有限规模交易存在**滑点**,有效价 $p_i^{\text{eff}} = \Delta\text{CR} / \Delta\text{IS}$。买入使 $\text{IS}$ 降、$\text{CR}$ 升,报价连续上行,直接编码稀缺性信号。

> **AMM 同时充当算法央行**。这是一个容易被忽略但很关键的设计:agent 向池子卖出商品时**铸造新货币注入流通**,买入时则回收销毁。因此货币总量与真实产出**结构性耦合**——生产力提升、资源产出增加带来持续的卖压,进而带来流动性的长期扩张,反映真实经济增长。这跳出了固定货币基数的封闭经济模拟。

**宏观:价格趋势指数(不影响成交价,只作其他模块的输入)**

价格变化率:$\text{PCR}_i(t) = p_i(t) / p_i(0)$

分类通胀率用**几何平均**(防单品暴涨扭曲总量):

$$\bar{\text{PCR}}_{\text{food}} = \Big(\prod_{i=1}^{n_{\text{food}}} \text{PCR}_i\Big)^{1/n_{\text{food}}}, \quad \bar{\text{PCR}}_{\text{non-food}} = \Big(\prod_{j=1}^{n_{\text{non-food}}} \text{PCR}_j\Big)^{1/n_{\text{non-food}}}$$

全局指数用**加权算术平均**(权重为品类数量占比):

$$\bar{\text{PCR}}_{\text{overall}} = \frac{n_{\text{food}}}{N}\bar{\text{PCR}}_{\text{food}} + \frac{n_{\text{non-food}}}{N}\bar{\text{PCR}}_{\text{non-food}}$$

该指数驱动工资动态调整,相当于内建了一个「政策响应」通道:食品通胀上行 → 基础工资上调。

### 3.4 硬资源依赖的生产函数

Leontief 式(完全非替代)条件合成:

$$Y_{a,i}(t) = \mathbb{I}\big(R_a \geq R^i_{\min}\big) \cdot \min\Big(\min_{m \in \mathcal{M}_i} \frac{M_{a,m}(t)}{\alpha_{i,m}},\ \frac{E_a(t)}{\epsilon_i},\ \frac{S_a(t)}{\sigma_i},\ \frac{L_a(t)}{\tau_i}\Big)$$

- $\mathbb{I}(\cdot)$:住宅门槛指示函数
- $\mathcal{M}_i$:配方所需材料集,$\alpha_{i,m}$ 单位用量
- $\epsilon_i, \sigma_i, \tau_i$:单位能量 / 饱食度 / 劳动时间需求
- 所有技术系数均为**外生指定的制度规则**,实验期内固定,除非显式干预

`min` 算子意味着**任一要素短缺直接卡住产出**——材料、能量、饱食度、劳动时间,一个都不能少。加上住宅门槛,「动态(资源驱动)约束」与「结构(资格驱动)约束」交织,既防产能暴涨,又让供给瓶颈等冲击沿链条连贯传播。

### 3.5 教育与职业系统

**双重门控(dual-gating)**:必须同时满足**教育要求**与**住宅等级门槛**才能申请高层职业。这直接对应现实不平等的两个基础维度——人力资本投资 与 资产型准入约束。

**教育即人力资本投资**,不免费,需付费报名:

$$H_a(t + \Delta t) = H_a(t) + \eta \cdot \Delta t$$

$\eta$ 为固定积累速率。教育分双重作用:① 高层职业的资格凭证;② **提升所有生产活动的效率**(见 $\text{Eff}$ 公式)。于是 agent 面临经典跨期取舍:投入教育就要放弃即时劳动收入与消费,短期生存能力下降,但长期竞争力上升。

| 3 | Backbone | 3 | 70 | Sushi | static |

**动态知识门槛(最精妙的机制之一)**

资格条件:

$$\mathbb{I}\big(H_a(t) \geq \widehat{H}_{\min}^{(j)}(t)\big) \cdot \mathbb{I}\big(R_a \geq R^{(j)}_{\min}\big) = 1$$

其中动态门槛由**全平台教育分的经验分布**决定。设 $F_t(h)$ 为活跃 agent 教育分的经验 CDF,$\pi_j$ 为职业 $j$ 的目标合格人口占比:

$$\text{q}_{1-\pi_j}(t) = \inf\{h \in \mathbb{R} : F_t(h) \geq 1 - \pi_j\}, \qquad \widehat{H}_{\min}^{(j)}(t) = \max\big(H_{\text{floor}}^{(j)},\ \text{q}_{1-\pi_j}(t)\big)$$

例:$\pi_j = 0.28$ 意味着门槛被设到「按教育分排序的前 28%」。**全民卷学历时门槛自动水涨船高**,从而防止文凭贬值、保持持续投资激励,并复现现实中的**相对位置竞争(positional competition)**——同时保留硬性下限 floor,维持长周期内稳定的分层结构。

**工资双制度**:

- 静态制(Tier 1–3):$w^{(j)}(t) = w_0^{(j)} \cdot \bar{\text{PCR}}_{\text{overall}}$ —— 只跟通胀,提供稳定可预期的收入底线。
- 动态制(Tier 4–6):$w^{(j)}(t) = w_0^{(j)} \cdot \Phi\big(\widehat{H}_{\min}^{(j)}(t)\big) \cdot \bar{\text{PCR}}_{\text{overall}} \cdot (1 + \delta_t)$

$\Phi(\cdot)$ 非负非递减,把上升的知识门槛转化为**工资溢价**;$\delta_t \in [-\bar\delta, \bar\delta]$ 是有界短期调整项(临时劳动市场冲击或政策干预)。这套「静态底 + 动态顶」的分割直接对应劳动市场分割理论。

**劳动—消费反馈环**:任何职业按小时消耗 energy 与 satiety。要工作就得挣到足够买回恢复用消耗品的钱。于是劳动供给被内生决定于三者互动:名义工资(购买力)、商品价格(生存可负担性)、职业的生理需求强度。

## 4. 实证验证(论文第 4 节)

### 4.1 数据

公开部署产生的高频交易日志,累计 >60 万条,取**成熟期**(日成交量与参与人数已稳定)的连续 40 万条,规避冷启动瞬态。按 5 分钟分箱构造标准 **OHLC** 序列,取末次成交价为代表价。分析窗口示例:现实时间 2025-09-09 至 09-15,倍率 7:1。

### 4.2 宏观稳定性

指标:对数价格极差 $\mathrm{Range} = \max \ell_t - \min \ell_t$;最大回撤 $\mathrm{MDD} = \max_t \big(1 - p_t / \max_{s \le t} p_s\big)$。

以流动性最好的**鱼市**为例:价格仅在 **304.398 – 304.808** 之间波动,对数极差 **0.001**,最大回撤 **0.0715%**。既没爆炸也没崩盘,且保持持续微观波动(没有退化为常数)。

**但稳定 ≠ 静态定价。** 供应链层面出现结构性持久重定价:

- **硅链**:终端品 Transistor **放大**了中间品 Pure Silicon 的涨幅,而原料 Silicon Ore 稳定 → 说明定价主因是下游产能瓶颈与终端需求,不是原料成本(与该时期 Transistor 高成交量一致)。
- **木链**:终端品 Book 升值而原料 Wood **贬值**,价格分化 → 制造成本、品牌、下游需求主导终端定价。

这说明复杂的增值过程在稳定的市场框架内被**内生定价**。

### 4.3 典型事实(Stylized Facts)复现

对数收益 $r_t = \log p_t - \log p_{t-1}$。

**分布性:厚尾 + 偏斜**

十种商品的超额峰度全部 **> 6.0**,最高 Silicon Ore 达 **9.873**——与现实股指日收益常见的 5–10 区间**量级可比**(高斯分布超额峰度为 0)。偏度则正负并存,说明市场内生出多样化的非对称风险画像。

**时序性:波动率聚集**

对 $|r_t|$ 计算自相关 $\rho(k)$,并做 **Ljung-Box 检验**。

| 商品 | 超额峰度 | 偏度 | $\text{ACF}(|r_t|)$ lag-1 | p 值 |
| --- | --- | --- | --- | --- |
| Wood | 9.644 | -1.659 | 0.450 | $<10^{-6}$ |
| Apple | 6.637 | 1.382 | 0.585 | $<10^{-6}$ |
| Fish | 9.489 | -0.254 | 0.189 | $<10^{-6}$ |
| Copper Ore | 9.695 | 0.009 | 0.133 | $<10^{-6}$ |
| Silicon Ore | 9.873 | -0.636 | 0.108 | $<10^{-6}$ |
| Wheat | 9.502 | 0.168 | 0.118 | $<10^{-6}$ |
| Iron Ore | 9.280 | -0.204 | 0.127 | $<10^{-6}$ |
| Chicken | 9.516 | 0.289 | 0.105 | $<10^{-6}$ |
| Circuit Board | 8.203 | 0.700 | 0.187 | $<10^{-6}$ |
| Copper Ingot | 9.737 | -0.632 | 0.082 | $<10^{-6}$ |

所有商品的自相关均为正,Apple(0.585)与 Wood(0.450)短期记忆尤强;即使最弱的 Copper Ingot(0.082)也强烈拒绝无序列相关的原假设。作者的解读:agent 与市场机制的交互产生了**内生反馈动力学**——信息冲击或大额交易触发需要时间耗散的活动级联。

### 4.4 分层与不平等的涌现

实验结束时的横截面快照。

- **教育—财富梯度**:教育分限定 [0, 1500],按宽度 50 分箱取中位财富,二阶多项式拟合 → **单调上升的非线性关系**。
- **职业—财富分层**:按中位净资产降序排列职业,顶端是 **CEO / Principal / Hospital Director**,中段是 Doctor / Teacher 等技术专业,底部是长尾的服务与体力工作。

作者对「涌现」一词很克制地做了界定:高层职业与教育/住宅前置条件的**关联本身是规则写死的,不算涌现**;真正涌现的是 **agent 群体动态自我分选进入这些阶层的过程**。完整路径是:

> 更高人力资本 → 获得排他性高回报职业准入 → 这些职业产出显著更多财富 → **自我强化反馈环**:初始的「有能力投资教育」这一优势被复利放大为持久的经济不平等。

### 4.5 规划视野与阶层流动(最有意思也最谨慎的一节)

核心挑战是经典跨期取舍:教育投资长期回报高但即时机会成本大。**只优化即时需求的 agent 会"理性地"早早进入低端劳动市场,从而无意中永久丧失高层职业资格。**

这里人类给出的**长期目标充当了外部信息信号**。例如:

> "Do not work yet; study until your education score exceeds a specified threshold"

它作为**启发式推动(heuristic nudge)**,重构 agent 的决策框架,提高长期计划的感知价值。日志观察显示:最终进入高地位职业的 agent,**往往在生命周期早期就接触过这类教育导向提示**。

作者明确标注局限:**这是相关性而非因果性**。也可能是有利初始条件与「收到提示」这件事恰好相关。要建立因果需要 A/B 测试,留作未来工作。但初步结论仍有分量:**定向、非强制的干预可能是改变个体轨迹并塑造宏观社会结构的有力机制。**

## 5. 消融实验(论文第 5 节)

**设置**:每组 80 个 agent,profile 初始化为空,仅填 personality——按 16 种 MBTI 各 5 个。初始 health / satiety / energy 统一为 60,货币、教育分、库存清零。时间倍率提到 **35×**(正式服 7×),所有时间相关过程一致缩放。

**三个变体**:
- **Default**:完整分层 BTP
- **Without-Branch**:去掉分支分解,单一推理分支
- **Without-OD**:去掉目标分解,并行分支直接生成动作列表

### Task 1 — 高科技生产 + 状态维持(复杂多目标)

目标:「尽可能多产高价值物品、尽可能多挣钱,同时维持较高的饱食/能量/健康」

| Planner | 货币余额 | 净资产 | 教育分 | 饱食 | 能量 | 健康 | 物品数 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Without-Branch | 11,573 | 75,237 | 6.39 | 136.14 | 183.30 | 208.45 | 7.85 |
| Without-OD | 29,946 | 95,279 | 4.10 | 198.45 | 165.58 | 137.63 | 7.85 |
| **Default** | **39,097** | **110,098** | **20.90** | 181.14 | 110.25 | 184.03 | **8.33** |

Default 在高科技产量与净资产上双双领先。能量最低,作者归因于**生产负荷更高**导致能量保有基线更低——但三项生理状态全程稳定。最关键的是**教育分 20.90 vs 6.39 / 4.10(3–5 倍差距)**:Default 会主动把学习动作插进计划以提升长期生产效率,这正是「协调延迟投资与长期回报」这一长视野能力的直接证据。

### Task 2 — 财富 + 教育

目标:「尽可能多挣钱,同时尽可能多增加学习经验」

| Planner | 货币余额 | 库存价值 | 净资产 | 教育分 |
| --- | --- | --- | --- | --- |
| Without-Branch | 141,955 | 21,833 | 163,788 | 103.63 |
| **Without-OD** | **229,416** | 30,098 | **259,514** | **158.48** |
| Default | 185,470 | **54,510** | 239,980 | 125.34 |

**这里 Default 输了**(Without-OD 略胜)。作者给的解释很诚实:本环境中的教育活动**没有复杂前置结构**——不像工业生产要遵配方、要囤上游材料。因此目标分解收益有限,反而引入额外规划开销损害效率。Without-Branch 依然全面最差。

### Task 3 — 动作多样性(故意模糊的目标)

目标:「产生多样化动作,鼓励尝试各种可用动作以探索世界」——刻意不枚举子目标与成功标准。

| Planner | 每轮独特动作 | 每分钟独特动作 | 总独特动作 |
| --- | --- | --- | --- |
| **Default** | 1.11 | **0.033** | **66.01** |
| Without-Branch | **1.14** | 0.028 | 65.43 |
| Without-OD | 0.73 | 0.030 | 42.06 |

Without-OD 在约 42 个独特动作处**迅速触顶停滞**。Without-Branch 每规划步探索更多、更快收敛到探索上限——但本环境中**动作带显式时长,时间成本是生产成本的关键组成**。按时间归一化后 Default 的每分钟探索率更高,说明它更能把细粒度环境约束(时间动力学、动作成本)纳入考虑,在真实执行预算下实现更有效、更持续的探索。

### Task 4 — 高效造芯片(简单任务)

| | Default | Without-Branch | Without-OD |
| --- | --- | --- | --- |
| Chips | 6.14 | **6.15** | 5.60 |

Default 与 Without-Branch **几乎完全打平**。这条实验专门用于验证 §2.3 反应式引导所走的**轻量规划路线**:目标明确、程序简洁、执行路径直接的任务,轻量机制**足够且有效**——减少无谓规划开销、提升对外部指令的响应性、更快收敛而不牺牲任务表现。

### 结论

收益**高度任务依赖**:

- **复杂**(长视野 + 竞争目标 + 结构化依赖):Default 在鲁棒性、平衡性、长期效率上占优,尤其体现在协调生产、状态维持与延迟投资(学习)三者。
- **简单**(指令明确 + 依赖浅 + 路径短):轻量路线接近最优,开销极小。

这正好验证了**分级规划架构**的设计选择:按任务结构**选择性激活规划复杂度**。

## 6. 局限(论文自陈)

1. **受底座 LLM 推理能力上限约束**。BTP 显著降低了误差传播,但在涉及高度复杂多步依赖的边缘情形下,agent 仍会偶发次优规划或**幻觉出并不存在的约束**。
2. **分层与规划视野的分析是观察性的**。发现了早期引导与长期财富积累的相关性,但因果链需要受控 A/B 测试。
3. **算力是规模瓶颈**。维持数千个并发、带记忆增强的 agent 成本高昂,要把人口推到百万量级需要进一步优化。

## 7. 设计要点提炼(可迁移的工程经验)

对做 agent 系统的人,这篇论文里最值得抄的几条:

1. **分层的真正价值是成本分级,不是"更聪明"**。三处都体现同一原则:顶层战略分解只在情境剧变时触发;Action Simulator 的修补循环不重入完整规划栈;失败先查 STM 快修,连败才升级全量重规划。**把昂贵的深思留给真正需要它的时刻。**

2. **并行分支 = 长链误差传播的解药**。把「一条 20 步的计划」换成「4 条 5 步的分支 + 一个综合器」,单点失败不再摧毁全局,还顺便支持多域并发推理。

3. **人类干预要打在与 agent 内部抽象层级匹配的地方**。长期目标进顶层规划 + 长期记忆;即时指令进局部规划器 + STM。**用反复的低层指令去掰行为是脆弱的反模式**——这是论文明确点名批评的做法。

4. **干预效果应经由记忆传播,而非 prompt 覆盖**(原文:*propagated through memory rather than brittle prompt overrides*)。这一条既保证了行为连续性(不在指令间震荡),又免费换来个性化(用户风格被逐渐内化)。

5. **Leontief `min` 算子是防退化循环的利器**。任一要素短缺直接卡产出,配上分层准入门槛,天然排除生产捷径,让供给冲击沿链条真实传播。

6. **AMM 同时当交易所和央行**。恒定乘积把稀缺性直接编码进价格斜率;铸造/销毁机制让货币供给与真实产出结构性耦合,避免了固定货币基数模拟的失真。

7. **分布分位数门槛能内生复现相对竞争**。$\widehat{H}_{\min} = \max(\text{floor}, q_{1-\pi})$ 这一行公式同时做到了:防文凭贬值、保持投资激励、复现位置竞争、维持长期稳定分层。极高的机制密度。

8. **消融要敢报负面结果**。Task 2 里 Default 输给 Without-OD,作者不但报了,还给出了机制层面的解释(教育无前置依赖结构 → 分解收益低于开销)。这比全胜的表格可信得多,也直接支撑了「分级激活规划复杂度」的设计主张。

9. **归一化维度决定结论**。Task 3 里按「每规划步」算 Without-Branch 更好,按「每分钟」算 Default 更好。**选对成本单位,否则会得出相反的结论。**

## 9. 一句话总评
