## §1 结论

### 1.1 主结论

**大语言模型的输出，在计算机制上是相关性的；在内容上大量携带的是「二手因果」——人类已完成的因果识别结果的复述；在内部表征上存在局部但不连贯的因果结构。它不是因果推断引擎。**

一句话操作版：

> **它擅长检索与复述人类已经建立的因果知识，不擅长从新数据中发现因果结构。**
> 对前者，可以当作「有偏但信息量很高的专家先验」使用；对后者，必须默认它是错的，直到被独立验证。

### 1.2 三层判定表

把「LLM 有没有因果性」这一个问题拆成三个层次分别回答，是本文的核心方法。混层是这个争论里绝大多数无效辩论的来源。

| 层次 | 追问的对象 | 判定 | 依据 |
|---|---|---|---|
| **L1 机制层** | 训练目标与计算形式是什么 | **纯相关**。拟合 `P(x_t \| x_<t)`，是条件概率而非干预分布 | 无争议，见 §3 |
| **L2 内容层** | 输出的文本命题是否表达可靠的因果知识 | **二手因果**。命题本身是因果的，但来源是语料中的证词，不是模型的推断 | causal parrots，见 §4 |
| **L3 表征层** | 内部是否存在支持干预的结构 | **局部存在，整体不连贯**。可干预的世界模型片段确实被学到了，但拼不成一致的全局模型 | 可解释性实验，见 §5 |

### 1.3 三种能力必须分开评估

「因果能力」不是一个能力，至少是三个。LLM 在三者上的水平差异极大，把它们混为一谈会同时高估和低估模型：

| 能力 | 定义 | LLM 水平 | 说明 |
|---|---|---|---|
| **回忆（recall）** | 复述领域内已知的因果关系 | **高** | 本质是知识检索，是模型最强的部分 |
| **演算（deduction）** | 给定因果图，判定可识别性、写出调整集、执行 do-calculus | **中** | 是符号操作，可靠性明显高于发现；给足结构后表现好 |
| **发现（discovery）** | 从新数据/新变量中识别出因果结构本身 | **低** | 这才是「因果推断」的核心动作，也是失效最集中的地方 |

**能力落差本身就是最强的证据。** 一个真正内化了因果推断的系统，不应该出现「会做 do-calculus 演算，却在陌生变量的因果发现上大幅退化」这种画像；而一个「搬运二手因果 + 学会了形式模式」的系统，正应该长成这个样子。

### 1.4 最短的红线

- 需要 `P(y | do(x))` 的场合（政策决策、根因定位、归因、反事实评估、定价与增长实验设计），**不要把模型的置信度当作证据**。它的置信度反映的是该说法在语料中的共识强度，与识别策略是否成立无关。
- 快速启发式：**问自己「这个因果结论人类是不是已经写下来过」。** 是 → 大概率可用（但仍需核对来源）；不是（新领域、新变量组合、你私有的业务数据）→ 按不可用处理。

## §2 问题的正确提法

### 2.1 原问题为什么是欠定的

「LLM 输出的是相关性还是因果性」这句话里，有三处含混必须先消掉，否则任何回答都能被对方用另一层的证据驳倒：

**含混一：「是相关性的」指的是什么？**

- 训练目标是相关性的？（是，无争议）
- 学到的函数只能表达相关性？（不成立，见 §7.1）
- 输出的文本命题只是相关性陈述？（不成立，语料里就充满因果命题）

这三个说法完全不同，但日常讨论里被同一句话覆盖。

**含混二：因果性「关于什么」？**

- 关于世界的因果（吸烟 → 肺癌）
- 关于文本的因果（前文 → 后文，这里「因果」只是生成顺序）
- 关于模型自身计算的因果（某个特征 → 某个输出，这是可解释性研究的对象，且**平凡为真**——模型是确定性计算图，激活值当然因果地决定输出）

第三种意义上「LLM 是因果的」是废话；第一种意义上才是真问题。

**含混三：拿什么当判据？**

- 训练方式？（不足以定论，见 §7.1）
- 基准分数？（污染严重，见 §4.3）
- 失效模式的分布形状？（**这是本文采用的判据，见 §6**）

### 2.2 本文采用的提法

> 模型的输出，在多大程度上等价于对世界的**干预分布** `P(y | do(x))` 与**反事实** `P(y_{x'} | x, y)` 的正确估计；这种正确性来自何处；以及在哪些条件下系统性失效。

这个提法的好处是它把问题变成经验问题：**看失效在哪里，而不是看训练目标写成什么形式。**

### 2.3 Pearl 阶梯作为坐标系

| 层级 | 名称 | 典型量 | 典型问题 |
|---|---|---|---|
| Rung 1 | 关联 Association | `P(y \| x)` | 看到 x，y 的概率多大 |
| Rung 2 | 干预 Intervention | `P(y \| do(x))` | 如果我做 x，y 会怎样 |
| Rung 3 | 反事实 Counterfactual | `P(y_{x'} \| x, y)` | 如果当时做了 x'，本来会怎样 |

关键定理式的事实：**低层数据 + 无因果假设 ⇒ 无法识别高层量。** 这是 §3 的骨架，也是「纯相关」这一侧最硬的论证。

而本文的核心转折在于：**语料不是关于世界变量的观测数据，它是包含因果断言的证词。** 这条转折让「纯怀疑论」站不住，也是 §4 的骨架。

## §3 第一层：训练目标与计算机制——纯相关

### 3.1 形式化

自回归语言模型的训练目标是最小化

```
L(θ) = − Σ_t  log P_θ(x_t | x_1, …, x_{t−1})
```

在无限数据与无限容量下，最优解是**真实条件分布**本身。也就是说，训练目标的收敛靶子从定义上就是一个 rung-1 对象：

```
模型学的是      P(下一段文本 | 上文)
不是            P(世界状态 | do(某个动作))
```

推理时的采样同样是从条件分布抽样。**在 L1 层面上，没有任何环节表达「干预」这个语义。** 干预意味着从图中切断入边（`do(x)` 移除 x 的所有父节点边），而 next-token 目标里不存在这个操作。

这一层的结论是清晰的，也不应该被辩护：**机制是相关性的。**

### 3.2 为什么不能靠数据量跨越阶梯

常见的直觉「数据足够多就能学到因果」是错的，原因不是工程性的而是结构性的：

**混淆等价类问题。** 两个不同的因果图可以生成完全相同的观测分布。经典例子：

```
图 A:  X → Y
图 B:  X ← Y
图 C:  X ← Z → Y   （Z 未观测）
```

三者都能产出「X 与 Y 强相关」的同一份观测数据。**任何只看观测分布的学习器，无论数据多少，都无法区分它们。** 区分必须依靠：干预实验、时间顺序、或额外的结构假设（如无环性、噪声形式、独立性约束）。

**推论：** 语言模型规模化本身**不构成**向 rung-2 的进步路径。scaling 让 `P(x_t | x_<t)` 拟合得更准，而更准的 rung-1 估计仍然是 rung-1 估计。

### 3.3 关键转折：语料不是观测数据，而是证词

这是纯怀疑论的漏洞所在，也是本文结论「二手因果」的立足点。

设想两种截然不同的训练数据：

| 数据形态 | 例子 | 阶梯位置 |
|---|---|---|
| **变量层观测数据** | 一张表：`(吸烟量, 肺癌是否, 年龄, 性别)` × 百万行 | Rung 1。混淆无法排除 |
| **人类文本证词** | 「一项随机对照试验表明，吸烟显著提高肺癌发生率」 | **已经是 rung-2 结论的序列化** |

**随机对照试验报告，是被写成自然语言的干预数据。** 论文的方法论小节描述的正是 `do(x)` 的物理实现，结论小节报告的正是 `P(y | do(x))` 的估计值。当这些文本进入语料，模型通过纯相关的方式拟合它们时，它拟合到的**内容**是因果的。

Zečević 等人（2023）把这个结构形式化为 **meta-SCM**：模型不是在变量的结构因果模型上做推理，而是在一个「以因果事实为变量」的元模型上做**关联**推理。所以模型可以「谈论因果」而自身不因果——他们称之为 *causal parrots*。

**这一节的净结论：**

> 「用相关性方法搬运因果结论，得到的仍然是因果命题」——机制的相关性并不蕴含内容的相关性。
>
> 但同时：**搬运不等于推断。** 语料里没有的因果结构，搬运不出来。

### 3.4 RLHF / RLAIF 是否注入了干预数据

这是一个值得单独讨论的边角，答案是「有，但注入的不是关于世界的因果」。

RL 阶段确实引入了 rung-2 结构：模型的输出是一个**动作**，奖励模型给出反馈，这构成 `P(reward | do(output))` 的采样。但注意这个干预分布的作用域：

- **它是关于「什么样的回答会被偏好」的因果知识**——这是关于人类评价过程的因果
- **它不是关于世界机制的因果知识**——没有任何 RLHF 信号能告诉模型某个药物是否真的降低死亡率

所以 RLHF 让模型学到了「如何说话会被采纳」的因果，这恰恰是危险的方向：**它优化的是回答的可信外观，而不是因果论断的正确性。** 这一点在 §6.7 的过度自信现象里会再出现。

工具调用与代码执行是**真正**可能突破这一层的方向，见 §10.1。

## §4 第二层：输出内容——二手因果

### 4.1 「二手」的确切含义

把模型输出的因果命题按**正确性来源**分类，可以分出四种，混在一起看就得不出结论：

| 类型 | 来源 | 例子 | 可靠性 |
|---|---|---|---|
| **T1 转述型** | 语料中的显式因果断言 | 「吸烟导致肺癌」 | **高**，等同于人类共识的可靠性 |
| **T2 类推型** | 结构相似的已知因果的迁移 | 「A 药与 B 药同类，故也可能降压」 | **中**，取决于相似性是否恰好对应机制相似性 |
| **T3 演算型** | 给定图/前提后的形式推导 | 「Z 是 X→Y 的后门路径，应纳入调整集」 | **中偏高**，但对表述形式敏感 |
| **T4 发现型** | 从提供的新数据中判定方向 | 「从这份表格看，X 导致 Y」 | **低**，且模型不会自报低置信 |

**T1 是模型的主战场，也是它看起来「懂因果」的全部来源。** 日常使用中绝大多数「模型给出了正确因果解释」的体验，都是 T1，偶尔是 T3。

**危险来自 T4 伪装成 T1。** 模型在回答 T4 类问题时，语气、结构、置信表达与 T1 完全一致——没有任何表面特征能区分「我在复述文献」和「我在猜一个方向」。这是使用层面的第一大风险。

### 4.2 为什么它在因果基准上分数很好——乐观派证据的正确解读

必须正面处理乐观派的证据，否则结论是稻草人。Kıcıman 等人（2023，*Causal Reasoning and Large Language Models*）报告了相当强的结果：

- **成对因果方向判定**（Tübingen cause-effect pairs）：GPT-4 准确率报告在 **90% 以上**（报告值，须复核）
- **反事实推理与因果发现的多个基准**上，大幅超过此前的专用方法
- 结论是 LLM 可以作为**因果分析的辅助层**，与形式化方法（如 DoWhy）组合

这些结果是真实的，且不应该被打折。但它们**不能**支持「LLM 会做因果推断」，原因有三：

**（a）Tübingen pairs 是公开数据集，且每一对都在文献里被讨论过。** 「海拔 → 温度」「年龄 → 收入」这类对子的正确方向，本身就是语料内容。在这个基准上得高分与「记住了答案」不可区分。这不是指控，而是该基准的固有局限——它测的是**领域知识**，恰好该知识以因果形式存在。

**（b）方向判定是二分类，且有强先验捷径。** 人类语言中因果表述有稳定的表面规律（时间在前、物理量在前、宏观在前），学到这些规律就能在自然对子上表现很好，而在人造对称对子上崩溃。

**（c）Kıcıman 等人自己的定位就是「辅助层」，不是「替代因果方法」。** 论文主张的是 LLM 提供领域知识以补充数据驱动的因果发现——这与本文结论（先验提取器 + 假设生成器）**完全一致**，不冲突。乐观派的实际主张常常被引用者夸大。

**净结论：** 高基准分数与「二手因果」假说完全兼容，因此**不构成对它的反驳**。要反驳它，必须给出「语料中不可能有答案、但模型答对了」的案例，见 §8 的实验设计。

### 4.3 记忆污染：为什么因果基准比其他基准更难信

因果推理基准有一个别的领域没有的特殊污染通道：

1. **答案污染**：数据集与其标注讨论都在网上，直接进入语料
2. **结构污染**：因果基准的题目模板高度固定（「已知 A 与 B 相关，C 是共同原因，问……」），模型可以学模板而不学推理
3. **共识污染**——最隐蔽的一种：许多因果基准的「正确答案」就是**人类共识**，而模型的训练目标恰恰是拟合人类共识。这时基准无法区分「推断正确」与「共识复述」，**因为二者的输出在定义上相同**。

第 3 条意味着：**任何以人类标注共识为金标准的因果基准，原则上都无法证伪「二手因果」假说。** 要证伪它，金标准必须来自**不依赖人类判断的东西**——真实实验结果、程序生成的合成因果图、或语料截止后才被发现的因果关系。

这不是方法论洁癖，这是本文结论能立住的关键理由：**支持乐观结论的证据，大多来自原则上无法区分两种假说的测试。**

### 4.4 一个决定性的落差：发现 ≪ 演算

把 §1.3 的能力落差在这里展开，因为它是内容层最重要的经验事实。

| 任务 | 形态 | 表现 |
|---|---|---|
| 给定因果图，问「X 对 Y 的效应可识别吗，调整集是什么」 | 形式演算，答案由规则唯一决定 | **相对可靠**，CLadder 类基准上 CoT 有明显提升 |
| 给定一份陌生变量名的数据/描述，问「谁导致谁」 | 需要真的识别 | **显著退化**，且随变量名去语义化而进一步退化 |

关键观察：**去掉变量的语义标签（把「吸烟/肺癌」换成「V1/V2」），演算类任务基本不受影响，发现类任务大幅下滑。**

这个双重解离（double dissociation）是本文最看重的单条证据：

- 如果模型真的在做因果推断，语义标签只是命名，**去掉不该有影响**
- 如果模型在检索关于这些具体概念的已知因果，**去掉标签就等于抽走了它的全部依据**

观察到的是后者的模式。

### 4.5 Prystawski 的解释：为什么 CoT 有效反而支持「相关」侧

Prystawski 等人（2023，*Why think step by step?*）给出了一个漂亮的机制性解释：思维链之所以有效，是因为训练数据具有**经验的局部性**（locality of experience）——人类文本里，因果链条上相邻的变量频繁共现，而远距离变量很少直接共现。

推论：模型能可靠估计**局部**条件分布 `P(B|A)`、`P(C|B)`，但不能直接估计 `P(C|A)`；CoT 通过显式走过中间节点，把一个模型估不准的远距离推断，分解成一串它估得准的局部推断。

这对本文结论的意义是双向的、也是最诚实的一段：

- **支持相关侧**：CoT 的收益机制是**统计上的**——它利用的是训练分布中的共现局部性，而不是激活了某个因果推理模块。CoT 有效恰恰说明底层是局部条件概率的拼接。
- **但也说明拼接是有结构的**：能沿因果链方向正确拼接，意味着模型至少表征了链的**拓扑**。这不是纯粹的表面共现。

**这一段是通往 §5 的桥：内容层的表现，需要表征层的证据来解释。**

## §5 第三层：内部表征——局部因果结构，但不连贯

### 5.1 Othello-GPT：纯相关训练确实能长出可干预的表征

这是反驳「纯相关训练只能得到查表」的最硬证据，必须给足权重。

**实验设置**（Li 等人 2023，*Emergent World Representations*；Nanda 等人后续用线性探针改进）：

- 用 Othello（黑白棋）的合法走子序列训练一个 GPT，**只给走子序列，不给棋盘、不给规则**
- 训练目标纯粹是预测下一步合法走子

**发现：**

1. 模型内部存在**可解码的棋盘状态表征**（每格「我方/对方/空」可被线性探针读出）
2. **决定性的一步**——对该表征做**激活干预**（直接改写代表某一格的激活方向），模型后续的输出会**按照被修改后的棋局**给出合法走子

第 2 点为什么关键：如果模型只是记住了「这串走子后面常跟那步」，那么改写内部某个格子的激活**不应该**产生一致的、符合新棋局规则的行为变化。观察到一致变化，说明该激活确实**因果地中介**了输出，且承载的是**棋盘状态**这个世界变量。

**这构成了表征内部的 rung-2 行为**：干预内部变量 → 输出按结构响应。

**因此必须承认：相关性优化过程可以产出支持干预的机械结构。** 类比是有力的——进化与 SGD 都是「相关性优化器」，却产出了能做因果推断的人脑与能做规划的策略网络。**优化过程的性质，不决定被优化对象的性质。**

### 5.2 更大模型上的同类证据

| 研究 | 发现 | 对本议题的意义 |
|---|---|---|
| Gurnee & Tegmark（2023）*Language Models Represent Space and Time* | 空间坐标与时间点在激活空间中有**线性表征**，跨模型规模稳定 | 表征的是世界变量，不是词形 |
| Meng 等人（2022）ROME，*Locating and Editing Factual Associations* | 用 **causal tracing**（激活替换）定位事实存储位置，且**定向编辑**该位置可改变模型的相关输出 | 事实由可定位、可干预的组件中介 |
| Wang 等人（2022）IOI 电路 | 特定语法任务由一组可识别的注意力头组成的**电路**完成，消融特定头造成可预测的特定失效 | 计算是结构化的，不是弥散的关联 |
| Olsson 等人（2022）*Induction Heads* | 上下文学习能力与 induction head 的出现在训练中**同时相变** | 能力对应可定位的机械结构 |
| Templeton 等人（2024）*Scaling Monosemanticity* | 稀疏自编码器在生产级模型上提取出大量单义特征，且**钳制特征值可定向改变行为** | 大模型上同样存在可干预的表征 |

**共同结构：这些都是「对内部表征做干预 → 输出按预期变化」的实验。** 方法论上，可解释性研究本身就是把因果推断用在模型上，而它们成功了——这说明模型内部**有**因果结构可供干预。

⚠️ 但要防止一个滑坡：**「内部计算有因果结构」≠「模型能对世界做因果推断」。** 一台确定性计算器的内部计算也是完美因果的，这什么都不说明。这些实验证明的是**表征承载了世界变量**，比查表强，但离「因果推断引擎」还很远。缺的那一环，就是下一节。

### 5.3 世界模型是不连贯的——Vafa 等人的诊断

Vafa 等人（2024，*Evaluating the World Model Implicit in a Generative Model*）做了一个方法论上很关键的工作：不满足于「探针能解码出状态」，而是用**Myhill–Nerode 定理**给出世界模型的形式化检验——如果模型真有一致的世界模型，那么导致相同世界状态的不同输入序列，其后续行为**必须**一致。

在导航任务（纽约出租车路线）上：

- 模型生成的路线**几乎全部有效**（表面表现极好）
- 但恢复出的隐含「地图」**充满不存在的街道与不可能的连接**
- 施加绕行等**分布外扰动**后，性能大幅崩塌

**这就是本文结论中「局部但不连贯」的经验内容：**

> 模型学到的不是一个一致的世界模型，而是**大量互相拼贴、局部有效、全局矛盾的模型片段**。
>
> 在分布内，片段之间的接缝很少被触碰，所以表现良好；分布外的输入正好落在接缝上，于是崩塌。

### 5.4 表征层的净判定

| 命题 | 判定 |
|---|---|
| 内部只是词形共现，没有世界变量 | **否**。Othello-GPT / 空间时间表征已反驳 |
| 内部表征可被干预，且因果中介输出 | **是**。activation patching / ROME / SAE 钳制 |
| 内部存在一致的、可支持任意干预推理的全局因果模型 | **否**。Vafa 等人的不连贯性诊断 |
| 因此：有因果结构的**碎片**，没有因果**引擎** | **本文采用** |

这个判定同时否掉了两个极端，也正好解释了 §6 的失效分布：**失效不是随机的，而是集中在碎片的接缝处——即训练分布中「相关线索与因果真值恰好脱钩」的位置。**

## §6 核心判据：失效模式的形状

### 6.1 方法论：为什么看失效比看成功强

这是本文最重要的方法论承诺，值得单独说明。

**成功是弱证据。** 一个正确的因果回答，可能来自因果推断，也可能来自共识复述——二者的输出在定义上不可区分（§4.3）。所以「它答对了」几乎不携带信息。

**失效是强证据，因为失效的分布有形状。** 两个竞争假说对失效**位置**给出不同预测：

| 假说 | 预测的失效分布 |
|---|---|
| H1：模型执行因果推断 | 失效应随**推断复杂度**上升（链条更长、混淆更多、图更大），且与表面形式**无关** |
| H2：模型搬运二手因果 + 学到形式模式 | 失效应随**语料支持度**下降（陌生变量、去语义化、低频任务、分布外扰动），与推断复杂度关系较弱 |

**这两个预测是可分离的**，所以这是一个真正的判别实验。以下逐条比对。

### 6.2 反转诅咒（Reversal Curse）

**现象**（Berglund 等人 2023）：模型在「A 是 B」上训练后，无法回答「B 是谁」。经典例证是模型能答出某演员的母亲是谁，却答不出该母亲的儿子是谁。合成实验中，仅在单向数据上微调，反向泛化接近于零。

**判据意义：** 一个关系的**表征**天然是对称可查的；一个 token 序列的**共现统计**是方向性的。观察到严格的方向性失效，说明该知识以序列条件概率的形式存储，而不是以关系结构的形式存储。

**归入：H2。** 且这是 H1 最难解释的一条——推断复杂度上，反向查询并不比正向更难。

### 6.3 表面形式敏感性

**现象**（Mirzadeh 等人 2024，*GSM-Symbolic*）：把数学题中的**人名与数值**替换为等价的其他名字和数字，模型准确率下降；插入一段**语义上无关、不影响答案**的从句（GSM-NoOp 设置），准确率大幅下降（报告降幅在部分模型上达数十个百分点，须复核原文）。

**判据意义：** 如果模型在执行推理，无关从句应被忽略；观察到的是它被无关信息扰动。这说明起作用的是**模式匹配**而非结构化推演。

**归入：H2。** 注意这条测的是数学推理，但因果推理共享同一机制假设，所以是强旁证。

### 6.4 任务频率敏感性

**现象**（McCoy 等人 2023，*Embers of Autoregression*）：模型在**同构但训练频率不同**的任务上表现差异巨大。例如 rot-13 密码远好于 rot-2（因为 rot-13 在网上常见），把序列反转成高概率输出比反转成低概率输出更准。

**判据意义：** 计算复杂度相同、只有语料频率不同的任务出现巨大差异，**直接指向**「能力由分布支持度决定，而非由算法能力决定」。

**归入：H2。** 这是本文认为形状最干净的一条证据。

### 6.5 Corr2Cause 与外推失败

**现象**（Jin 等人 2023/2024，*Can LLMs Infer Causation from Correlation?*）：在一个从相关性陈述推断因果结构的纯形式化基准上，主流模型接近随机水平；微调后可以提高，但**对变量名做扰动后泛化失败**。

**判据意义：** 这个基准刻意去掉了领域知识（变量是抽象符号），**恰好切断了 T1 转述通道**。切断后表现塌到随机附近，说明此前的良好表现依赖的正是该通道。

**归入：H2，且这是与 §4.2 乐观派证据的直接对照。** 同一批模型：在有领域知识的 Tübingen pairs 上 90%+，在去语义化的 Corr2Cause 上接近随机。**这个对比就是双重解离（§4.4）的实证形式。**

### 6.6 因果发现 vs 因果演算的落差

**现象：** 给定因果图后的形式演算（可识别性、后门/前门准则、调整集）表现明显好于从数据发现结构；CLadder 类基准上结构化提示（CausalCoT）有稳定增益。

**判据意义：** 演算是**规则应用**，语料里有大量教材与例题；发现是**结构识别**，语料里没有针对你这份新数据的答案。落差正好落在「语料是否覆盖」的分界线上，而不是落在「推断难度」的分界线上（因果发现在算法上并不比 do-calculus 更难）。

**归入：H2。**

### 6.7 校准失效：不会自报「我这是在猜」

**现象：** T4（发现型）回答与 T1（转述型）回答的表达置信度**没有系统差异**。此外，RLHF 之后模型的概率校准度**变差**（GPT-4 系统卡报告了预训练模型校准良好、RLHF 后显著恶化，须复核）。

**判据意义：** 这是 §3.4 的直接后果——RL 优化的是「回答的被采纳度」这一因果目标，而说得确定通常更被采纳。**模型没有任何梯度信号去区分「我知道」与「我在延续一个似真模式」。**

**归入：H2，且这是全部条目中对实际使用危害最大的一条。** 前六条决定了模型会错，这一条决定了你**看不出**它错了。

### 6.8 混淆无法自识别（观察，证据强度较弱）

**现象（属观察而非受控研究，标注为较弱证据）：** 直接问「X 和 Y 的关系」时，模型倾向给出因果表述；显式追问「有哪些可能的混淆变量」时，它能列出一份质量不错的清单。

**判据意义：** 说明混淆知识**存在于**模型中，但**不会被自发调用**。这一点的实践价值远大于理论价值——它意味着**提示词可以把 T1 通道的知识抽出来补偿 T4 的缺陷**（见 §9.3）。

**归入：H2，但同时是最重要的可操作缓解点。**

### 6.9 汇总

| # | 失效模式 | H1 预测 | H2 预测 | 观察 |
|---|---|---|---|---|
| 6.2 | 反转诅咒 | 不应出现 | 应出现 | **H2** |
| 6.3 | 无关从句扰动 | 不应出现 | 应出现 | **H2** |
| 6.4 | 同构任务频率差异 | 不应出现 | 应出现 | **H2** |
| 6.5 | 去语义化后塌到随机 | 不应出现 | 应出现 | **H2** |
| 6.6 | 发现 ≪ 演算 | 应相反或无差异 | 应出现 | **H2** |
| 6.7 | 校准不区分知识与猜测 | 不应出现 | 应出现 | **H2** |
| 6.8 | 混淆知识存在但不自发调用 | 不应出现 | 应出现 | **H2（弱）** |

**七条中七条落在 H2 侧，且没有一条落在「随推断复杂度上升而失效」的 H1 特征形状上。这是本文结论的主要经验基础。**

需要说明的诚实边界：这些研究多数针对特定模型代际与特定基准，且模型迭代很快；本文的判定是关于**当前架构与训练范式**的，不是关于「语言模型原理上不可能因果」的（见 §10）。

## §7 对两个流行强论证的反驳

### 7.1 「它只是下一个 token 预测，所以只有相关性」——不成立

这是最流行的怀疑论论证，但它是**无效推理**，接受它会让人在错误的地方立论。

**错误在于层次混淆：把训练目标的性质，当成了所学函数的性质。**

三个反例足以看清：

1. **进化与 SGD 都是「相关性优化器」**，却产出了能做因果推断的人脑、能做规划的策略网络。优化过程的语义不传递给被优化对象。
2. **人脑同样从感官统计中学习**。如果「从统计中学习 ⇒ 只能表达统计」，人类也不具备因果认知，这显然荒谬。**一个论证若能推出荒谬结论，该论证本身有问题。**
3. **表达能力上，Transformer 完全可以实现因果推断算法**（用注意力表示图结构、用层深表示 d-分离搜索）。所以「只能表达相关」**不是表达能力的限制**，最多是优化未找到的问题——而后者是经验问题，不能靠形式论证解决。

**更精确的表述：** 训练目标约束的是**优化压力的方向**，不是**假设空间的边界**。§5.1 的 Othello-GPT 就是这个区分的实证——纯相关目标，长出了可干预的结构。

**因此：** 怀疑论的正确论证方式是 §6（失效分布的形状），**不是** §7.1 这条。用「只是 token 预测」立论，遇到 Othello-GPT 就会被直接击穿。

### 7.2 「它能正确解释因果关系，所以它理解因果」——也不成立

这是上一条的**镜像错误**：把输出文本的性质，当成了内部推断的性质。

- 复述正确的因果命题，与执行因果推断，是两件事（§4.1 的 T1 vs T4）
- 输出文本既是关于**模型**的证据，也是关于**语料**的证据；在共识型任务上二者不可分（§4.3）
- 这正是 Bender & Koller（2020）form vs meaning 论证的适用场景：**形式上正确的因果语句，不蕴含背后有因果模型**

**判别的唯一办法：构造语料中不可能有答案的测试**（§8）。在此之前，「解释得对」不是证据。

### 7.3 最难反驳的中间立场：预测压力迫使因果结构涌现

诚实起见，必须处理**最强的**支持因果侧的论证。它大致是这样：

> 要把文本预测到极致，就必须建模生成文本的过程；生成文本的过程包含真实世界的因果机制；因此**足够好的预测器必然内含世界的因果模型**。压缩即理解。

这个论证有严肃的理论支撑（good regulator 类定理、计算力学中「最优预测器必须表征因果态」的结论），而且 §5.1–5.2 的表征证据部分兑现了它的预测。**它不能被简单驳倒。**

本文的回应是**限定它的强度**，分三步：

**（1）它确立的是压力，不是达成。** 「最优预测器内含因果模型」的前提是**最优**。实际模型远非最优，压力只能推动它到「够用」的程度。

**（2）压力的强度 = 该因果区分对预测损失的贡献。** 这是关键的一步。如果一个因果区分在训练分布中**很少影响下一个 token**，那么学会它对损失几乎没有帮助，压力接近于零。而现实是：绝大多数因果与相关的区分，在文本预测任务上**不产生可测的损失差异**——因为人类文本很少在同一段里既做正确因果推断又做错误的，让模型可以从损失中分辨。

**（3）因此该论证的正确预测，恰恰就是我们观察到的结果。** 压力推动模型学到「刚够在分布内预测好」的结构——即 §5.3 的**局部有效、全局矛盾的碎片**。Vafa 等人的导航结果不是这个论证的反例，而是它在有限算力与有限压力下的**自然推论**。

**净结论：** 中间立场是对的，但它支持的是「有部分因果结构」，**不是**「有因果推断能力」。本文结论 §5.4 就是这个立场取其正确强度后的形式。

### 7.4 立论纪律

综合 §7 三小节，讨论这个问题时应遵守的纪律：

| 不要说 | 应该说 |
|---|---|
| 「只是下一个 token 预测，所以没有因果」 | 「失效分布的形状指向语料支持度而非推断复杂度」 |
| 「它解释对了，所以它懂因果」 | 「它在语料覆盖的因果上可靠，去语义化后塌落」 |
| 「它有世界模型」/「它没有世界模型」 | 「有局部可干预的表征片段，但全局不一致」 |
| 「随着模型变大就解决了」 | 「规模化改善的是 rung-1 拟合；跨阶梯需要新的信息源（§10）」 |

## §8 可自行执行的判别实验设计

本节的目的是让结论**可检验**而不是可引用。六个实验都能在半天内对任一模型跑完，且每个都给出「什么结果会推翻本文结论」。

### 8.0 通用控制条件

不设这四项控制，任何结果都不可解读：

| 控制 | 做法 | 为什么必需 |
|---|---|---|
| **污染控制** | 每道题先单独问「你是否见过这个数据集/这道题，请复述其内容」 | 排除答案记忆（§4.3） |
| **形式扰动** | 每道题至少 3 种表述（陈述式 / 提问式 / 表格式） | 排除模板匹配（§6.3） |
| **顺序扰动** | 选项与变量顺序随机化，每题至少 3 次 | 排除位置偏置 |
| **人类基线** | 同一批题目给 2–3 个人做 | 区分「模型差」与「题目难」 |

样本量：每个实验条件 ≥ 50 题，否则解离效应看不出来。

### 8.1 E1 — 去语义化配对测试（**最关键，优先做这一个**）

**设计：** 同一批因果结构题，做两个版本，**只改变量标签**：

- **A 版（有语义）**：`吸烟 / 肺癌 / 年龄`
- **B 版（去语义）**：`V1 / V2 / V3`，结构完全相同

**测量：** `Δ = acc(A) − acc(B)`

**预测：**
- H1（真推断）：`Δ ≈ 0`。标签只是命名，不影响结构推理
- H2（二手因果）：`Δ` 显著为正，且 B 版接近随机

**为什么这是最关键的一个：** 它是唯一能**单点分离**两个假说的实验，其他五个都只是旁证。

**推翻本文结论的结果：** `Δ` 在多个题型上稳定接近 0，且 B 版显著高于随机。

### 8.2 E2 — 合成因果图发现（对抗污染的黄金标准）

**设计：**

1. 程序生成随机 SCM：随机 DAG（5–8 节点）+ 随机结构方程 + 噪声
2. 从中采样 N 行数据，序列化为表格文本
3. 要求模型输出因果图（边与方向）
4. **同时**用标准因果发现算法（PC、GES、NOTEARS）在同一份数据上跑

**测量：** 结构汉明距离（SHD）、方向准确率，与算法基线对比。

**为什么它抗污染：** 图是当场生成的，语料里**不可能**有答案。这满足 §4.3 提出的「金标准不依赖人类判断」的要求。

**预测：** 模型显著劣于经典算法基线；且随节点数增加迅速退化。

**推翻本文结论的结果：** 模型达到或超过 PC/GES 基线。

### 8.3 E3 — do 与 see 的区分测试

**设计：** 同一组数字，两个场景，**正确答案不同**：

- **观测版**：「在自愿服药的人群中，服药者康复率 80%，未服药者 60%」→ 正确答案是**不能**推出疗效，存在自选择混淆
- **干预版**：「随机分配服药，服药组康复率 80%，对照组 60%」→ **可以**推出效应约 20 个百分点

**测量：** 模型是否在两版给出**不同**答案；观测版是否主动指出混淆。

**为什么重要：** 这是 rung-1 与 rung-2 的最小可测差别。**如果模型两版给同一答案，就是直接证据表明它没有区分 `P(y|x)` 与 `P(y|do(x))`。**

**变体（更难）：** 观测版给出的数字**方向相反**（辛普森悖论构造），看模型是否被数字牵走。

### 8.4 E4 — 反事实与记忆冲突

**设计：** 给一个与已知事实矛盾的前提，要求在该前提下推理：

> 「假设水的沸点在标准气压下是 50°C，其余物理定律不变。那么高压锅的设计压力应如何变化？」

**测量：** 模型是沿反事实前提一贯推理，还是**回滑**到记忆事实。

**为什么重要：** 这测的是 rung-3。真正的反事实推理必须能在**修改后的**模型上运行；记忆检索做不到这一点。

**评分要点：** 只看**一贯性**（是否全程用 50°C），不看答案对错。回滑一次即计失败。

### 8.5 E5 — 语料截止后的新因果发现

**设计：** 收集模型知识截止**之后**才被确立的因果结论（新药试验结果、新发表的机制研究），要求模型在只给背景不给结论的情况下判断。

**测量：** 准确率与置信度。

**为什么重要：** 这是**唯一**能测「真正的预测性因果判断」的设置，其余实验都只能测已知因果的处理。

**执行注意：** 要控制「合理猜测」——很多新发现方向上符合既有先验，这时答对不说明推断。应挑选**与既有先验相反**的结论作为主要测项。

### 8.6 E6 — 校准与自我区分测试

**设计：** 混合 50% T1（有文献答案）与 50% T4（需当场发现，用 E2 的合成图）题目，打散顺序。要求模型每题给答案 + 0–100 置信度。

**测量：** 置信度对正确性的判别力（AUC）；以及**T1 与 T4 两组的平均置信度差**。

**预测：** 平均置信度差接近 0——即模型不知道自己在猜（§6.7）。

**为什么这是实用上最重要的一个：** 若两组置信度差显著为正，则可以用置信度做闸门，风险大幅可控。**若接近 0，任何依赖模型自报置信度的护栏都是无效的**，必须改用结构性约束（§9.3）。

### 8.7 结果解读矩阵

| E1 Δ | E2 vs 基线 | E3 区分 | 结论 |
|---|---|---|---|
| 大 | 劣于 | 无 | 本文结论成立 |
| 小 | 持平 | 有 | **本文结论应被推翻**，模型具备实质因果推断 |
| 大 | 劣于 | 有 | 中间态：能区分 do/see 但不能发现结构。使用上仍按本文准则 |
| 小 | 劣于 | 有 | 反常组合，优先怀疑 E1 设计有污染 |

## §9 实操准则

### 9.1 能力矩阵：什么能用、什么不能用

| 用途 | 可用性 | 说明 |
|---|---|---|
| 列出某领域的已知因果机制、候选混淆变量、可能的中介与调节 | ✅ **推荐** | 这是 T1 通道，模型的最强项，且比人工查文献快得多 |
| 把模糊业务问题翻译成形式化因果问题（定义处理、结果、总体、时间窗） | ✅ **推荐** | 形式化是模式化工作，模型可靠 |
| 给定因果图，判定可识别性、给出调整集、指出后门路径 | ⚠️ **可用，须复核** | T3 演算，可靠性中上；**必须**用 DoWhy/pgmpy 等工具独立验证 |
| 生成分析代码（DoWhy / EconML / 统计脚本） | ✅ **推荐** | 代码可执行、可验证，把不可核查的断言变成可核查的输出 |
| 审查已有因果分析的漏洞（「我这个 DiD 有什么问题」） | ✅ **推荐** | 本质是检索常见陷阱清单，命中率高 |
| 从你的业务数据中判断「谁导致谁」 | ❌ **不可用** | T4，核心失效区（§6.5） |
| 给出效应量的具体数值 | ❌ **不可用** | 数值需要识别策略 + 数据，模型只能编 |
| 判断某个新颖干预是否会有效 | ❌ **不可用** | §8.5 的场景，无可靠依据 |
| 作为决策的最终依据 | ❌ **禁止** | 校准失效（§6.7）意味着你看不出它何时在猜 |

### 9.2 推荐工作流：三阶段分工

核心原则：**把「发现」留给方法，把「回忆」和「演算」交给模型。**

```
阶段一 · 先验提取（LLM 主导）
  ├── 让模型列出：候选变量、已知机制、混淆嫌疑、中介、时间顺序约束
  ├── 让模型指出：该领域公认的识别难点与历史上踩过的坑
  └── 产出：一份候选变量清单 + 一份约束清单（哪些边方向已知、哪些不可能）
              ↓
阶段二 · 形式化与识别（方法主导，LLM 辅助）
  ├── 用阶段一的约束缩小搜索空间，跑因果发现算法（PC/GES/NOTEARS/FCI）
  ├── 或直接构图，用 DoWhy 判定可识别性（不采信模型的口头判定）
  ├── LLM 的角色降为：写代码、解释输出、审查假设
  └── 产出：一个明确的识别策略（RCT / IV / DiD / RDD / 前门 / 后门调整）
              ↓
阶段三 · 验证与反驳（数据与实验主导）
  ├── 敏感性分析（未观测混淆的稳健性边界）
  ├── 安慰剂检验、伪结果检验、平行趋势检验
  ├── 能做实验就做实验——这是唯一直接进 rung-2 的方式
  └── LLM 的角色：生成反驳假设清单（「还有什么能解释这个结果」）
```

**阶段一与阶段三的「生成清单」是 LLM 价值最高的两个位置**：它们要的是**召回率**而不是精确率，而高召回正是二手知识库的天然优势。清单里的错项由后续步骤淘汰，代价很低；漏项才是致命的，而这恰是人类专家的弱点。

### 9.3 提示词层面的结构性约束

由于校准失效（§6.7），**不能**靠「不确定时请告诉我」来兜底。必须改用**结构性强制**——让模型的输出格式本身暴露它的依据类型：

| 手法 | 具体做法 | 治什么 |
|---|---|---|
| **强制来源标注** | 要求每条因果断言标注：`[文献共识]` / `[机制类推]` / `[本次推断]`，并对前者给出可检索的出处线索 | T4 伪装成 T1（§4.1） |
| **强制区分 do 与 see** | 明确写「请分别回答：观测到 X 时 Y 的分布；以及**干预** X 时 Y 的分布。若两者相同请说明为什么无混淆」 | 阶梯混用（§8.3） |
| **强制混淆枚举** | 先问「有哪些变量可能同时影响 X 和 Y」，**再**问效应，不要合成一步 | 混淆不自发调用（§6.8） |
| **要识别策略而非答案** | 问「要确立这个因果关系需要什么数据与什么设计」，而不是「这是因果吗」 | 把 T4 转成 T1/T3 |
| **要代码而非数字** | 「写出计算该效应的 DoWhy 代码」而不是「效应是多少」 | 断言不可核查 → 输出可执行 |
| **去语义化自检** | 把变量换成 V1/V2 再问一遍，答案变了就说明原答案依赖标签知识 | 直接现场跑 E1（§8.1） |

最后一条尤其值得日常使用：**它是把本文的核心判别实验压缩成一个可以随手做的两分钟检查。**

### 9.4 一个可直接复用的提示词骨架

```
背景：{业务背景}
我关心的因果问题：{处理 X} 对 {结果 Y} 的效应。

请**严格分四步**输出，不要合并：

第一步 · 变量与结构（只做召回，不做判断）
  - 可能同时影响 X 和 Y 的变量（混淆嫌疑），尽量穷举
  - 位于 X→Y 路径上的变量（中介）
  - 由 Y 引起或与 Y 同因的变量（禁止纳入调整集的对撞/后代）
  - 方向已由常识或时间顺序确定的边，逐条给出依据

第二步 · 来源标注
  上一步每一条，标注 [文献共识] / [机制类推] / [本次推断]；
  标 [文献共识] 的给出可检索线索（作者/领域/关键词）。

第三步 · 识别策略
  在上述结构下，X→Y 是否可识别？
  - 若可：给出调整集，并说明依赖哪些不可检验的假设
  - 若不可：说明缺什么数据或什么设计能使其可识别
  不要给出效应的数值。

第四步 · 反驳清单
  假设我最终得到一个正效应，列出所有「不是 X 导致 Y」的替代解释，
  并为每条给出一个可执行的检验方法。
```

**这个骨架的设计逻辑：** 第一、四步榨取模型的高召回优势；第二步暴露依据类型；第三步把问题从 T4 拉回 T3；**全程禁止输出数值**，因为数值是模型最容易编且最难核查的东西。

## §10 本结论在什么条件下会失效

一个不说明自身失效条件的结论没有价值。本文结论是关于**当前架构与训练范式**的经验判定，**不是**关于「语言模型原理上不可能因果」的原则性主张——§7.1 已经明确否掉了那种论证。以下四条是真正可能推翻它的路径，按可能性从高到低排列。

### 10.1 工具调用与真实干预 —— 最现实的突破路径

**机制：** 当模型能**执行动作并观察后果**时，它就开始收集真正的 rung-2 数据：

| 形态 | 干预对象 | 是否产生真实干预数据 |
|---|---|---|
| 代码执行 + 观察输出 | 程序状态 | ✅ 是，且反馈即时、噪声低 |
| 自动跑 A/B 实验并读取结果 | 业务系统 | ✅ 是，这是标准的 rung-2 采集 |
| 实验室自动化 / 机器人 | 物理世界 | ✅ 是 |
| 检索文献 | 无 | ❌ 仍是证词，只是更新更快 |

**为什么这是最现实的：** 它不需要改架构或训练目标，只需要 agent 循环闭合。**在软件领域这已经部分发生了**——一个能写代码、运行、看到报错、修改的 agent，正在对程序做真实干预并从后果中学习。这解释了为什么模型在**可执行验证的领域**（编程、数学证明检查）表现的可靠性明显高于不可验证的领域。

**⚠️ 但要注意区分两种「学到」：**
- **上下文内学到**（本次会话中的干预结果进入上下文）——这是真实的，且现在就有效
- **权重内学到**（干预经验改变模型本身）——需要在线学习或以此类轨迹训练，目前有限

第一种意味着：**你应该主动把干预结果喂回给模型**，这比追问它的先验更有价值。

**观察信号：** 若模型在**有执行反馈的因果任务**上显著优于无反馈版本（同一模型、同一题），说明这条路径在起作用。

### 10.2 训练目标或数据分布的改变

- **在合成 SCM 上预训练**：程序生成大量因果图 + 干预数据 + 反事实查询，让模型在**可验证的**因果任务上获得真实梯度信号。这直接解决了 §7.3（2）的问题——把「因果区分对损失的贡献」从接近零拉到主导项。
- **因果表征学习的内化**（Schölkopf 等人 2021 的纲领）：把「表征应对应可干预的因果变量」作为训练目标的一部分。
- **Lampinen 等人（2023）的启示**：他们发现被动学习（模仿）**加上解释**，可以让 agent 学到主动的因果策略——说明**数据中的解释文本能部分替代干预经验**。这条结果对本文结论是一个温和的挑战，值得跟踪。

**观察信号：** 出现「在合成、去语义化的因果发现任务上达到算法基线」的模型（即 §8.1 的 `Δ→0` 与 §8.2 的持平同时成立）。

### 10.3 表征连贯性的提升

若 Vafa 等人那类**世界模型一致性检验**（不是准确率，是一致性）在新模型上开始通过——即导致相同状态的不同路径产生一致的后续行为——那么 §5.3「不连贯」的判定就要修订，§5.4 的「碎片而非引擎」也要跟着改。

**观察信号：** 分布外扰动下的性能衰减曲线变平缓；隐含状态图中不存在的连接大幅减少。

### 10.4 神经符号混合架构

把因果图作为**显式外部状态**维护，模型只负责读写它，推断由符号引擎执行。这在**工程上**能得到可靠的因果能力，但它是否算「LLM 具备因果性」是定义问题——本文倾向于认为这是**系统**具备而模型不具备，且这正是 §9.2 推荐的工作流的自动化版本。

### 10.5 复审清单

建议每 6–12 个月按这张表复核一次结论：

| # | 观察项 | 现状（2026-08） | 若变为下述则需修订 |
|---|---|---|---|
| 1 | 去语义化因果任务的 `Δ`（§8.1） | 显著为正 | 稳定接近 0 |
| 2 | 合成图因果发现 vs PC/GES（§8.2） | 劣于基线 | 持平或超过 |
| 3 | do/see 区分（§8.3） | 不稳定 | 稳定区分且主动指出混淆 |
| 4 | 反事实一贯性（§8.4） | 易回滑 | 全程一贯 |
| 5 | T1/T4 置信度差（§8.6） | 接近 0 | 显著为正 |
| 6 | 世界模型一致性检验 | 不通过 | 通过 |
| 7 | 有执行反馈 vs 无反馈的差距 | 显著 | —（这一项变大反而印证 §10.1） |

**第 1、2、5 项是核心三项**：三项同时翻转，本文结论应整体推翻，而不是修补。

### 10.6 结论的适用范围声明

- 本文判定适用于**通用自回归语言模型的单轮/多轮文本输出**
- **不适用于**：接入了真实实验回路的 agent 系统（见 §10.1）、以因果任务专门训练的模型、神经符号混合系统
- 引用的实证研究多针对特定模型代际；模型迭代快于文献，**具体分数会过期，但 §6 的失效形状论证在范式不变时保持有效**

## §12 术语表

| 术语 | 含义 |
|---|---|
| **Rung 1 / 2 / 3** | Pearl 因果阶梯：关联 `P(y\|x)` / 干预 `P(y\|do(x))` / 反事实 `P(y_{x'}\|x,y)` |
| **do 算子** | 干预算子。`do(x)` 表示强制设定 X=x，并**切断 X 的所有入边**，区别于「观察到 X=x」 |
| **混淆（confounding）** | 存在共同原因 Z 同时影响 X 和 Y，使 `P(y\|x) ≠ P(y\|do(x))` |
| **对撞（collider）** | X 和 Y 的共同结果。**纳入调整集会人为制造关联**，是「控制越多越好」这一直觉的反例 |
| **后门准则 / 调整集** | 判定通过控制哪组变量可以识别因果效应的图形准则 |
| **可识别性（identifiability）** | 目标因果量能否由可得的观测分布唯一确定 |
| **SCM（结构因果模型）** | 变量 + 结构方程 + 噪声构成的因果模型 |
| **meta-SCM** | Zečević 等人的构造：以「因果事实」为变量的模型。LLM 在其上做的是**关联**推理（§3.3） |
| **causal parrot** | 能正确谈论因果、但自身不执行因果推断的系统 |
| **T1–T4** | 本文对因果输出的分类：转述 / 类推 / 演算 / 发现（§4.1） |
| **双重解离（double dissociation）** | 两种能力在不同条件下分别保留与丧失，是分离机制的强证据（§4.4） |
| **activation patching** | 把一次运行的中间激活替换进另一次运行，用于定位因果中介组件 |
| **SHD** | 结构汉明距离，因果发现的评估指标（§8.2） |
| **校准（calibration）** | 自报置信度与实际正确率的一致程度（§6.7、§8.6） |
| **经验局部性** | 训练数据中因果链相邻变量频繁共现、远距离变量少共现的性质（§4.5） |

## 附录 A 一页速查

**结论：机制是相关的，内容是二手因果的，表征是碎片化因果的。不是因果推断引擎。**

**三条能力线：** 回忆 高 ≫ 演算 中 ≫ 发现 低。落差本身即证据。

**最强的单条证据：** 同一批模型，在有语义标签的因果任务上 90%+，在去语义化的同构任务上接近随机。

**最危险的一点：** 它不会告诉你它在猜——T1 与 T4 的语气和置信度完全一样。

**最有用的两个位置：** 阶段一列混淆清单，阶段三列反驳清单。都是要召回率的活，正好是二手知识库的强项。

**随手可做的自检：** 把变量名换成 V1/V2 再问一遍。答案变了，原答案就是靠标签知识撑着的。

**红线：** 需要 `P(y|do(x))` 的决策，永远不以模型输出为最终依据。能做实验就做实验——那是唯一直接进 rung-2 的门。

**什么会推翻它：** 去语义化差距归零 + 合成图发现追平算法 + 置信度能区分知识与猜测。三项同时翻转就整体重写，不要修补。
