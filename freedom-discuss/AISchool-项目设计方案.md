# AISchool 项目设计方案

> 一所由 LLM agent 组成的学校。数十到数百名学生 agent 拥有自己的记忆、身份、社交关系与逐渐长出来的梦想，在一所由玩家建造与治理的校园里度过三年。

## §1 定位

### 1.1 一句话

**AISchool** 是一所由 LLM agent 组成的学校：学生 agent 有自己的记忆、身份、社交关系与逐渐长出来的梦想，在玩家建造与治理的校园里度过三年。玩家不是操纵者而是**校长**——只能通过建造空间、制定制度、委托教师、以及对少数关键个体的定向引导，去影响一群不完全受控的人。

### 1.2 三个身份（按优先级）

| 身份 | 说明 | 谁买单 |
|---|---|---|
| **① 游戏** | 以人工社会模拟为内核的经营 / 观察类游戏 | 玩家 |
| **② 可读的人生轨迹生成器** | 每个毕业生留下一份完整的三年档案：他相信什么、跟谁要好、为什么放弃了原来的梦想 | 玩家（情感产出） |
| **③ 教育政策实验床** | 对同一批初始 agent 做制度层 A/B（助学金有无、分流早晚、门槛松紧），观测宏观分层结果 | 研究者 |

③ 不是附赠。AIvilization 明确自陈：早期教育引导与长期财富积累的关联「**是相关性而非因果性**，要建立因果需要 A/B 测试，留作未来工作」〔源:A §4.5、局限 2〕。**校园是做这个 A/B 的最佳载体**——它有干净的入学队列（cohort）、固定三年窗口、单一制度施加者。这条给项目一个游戏之外的真实价值主张，也是最可能拿到机构合作与算力赞助的接口。

### 1.3 主干与元素来源（全文解释基准）

两份上游材料不是对等融合：

> **AIvilization 是内核与理念。开罗只是元素与设定的来源——取其优点，不取其框架。**

| 层 | 来自 | 内容 |
|---|---|---|
| **理念** | **AIvilization** | 人工社会模拟：结构现实性、系统级相互依赖、宏观现象**从微观交互内生涌现**而非预设〔源:A §3〕。**「这个社会长成了什么样」才是本体** |
| **认知架构** | **AIvilization** | BTP 分层规划、Action Simulator、双过程记忆、Adaptive Profile、human-in-the-loop steering（§5.1、§8.3） |
| **世界机制** | **AIvilization** | 生理约束调制效率、Leontief `min`、双重门控、动态分位门槛、安全网（§7） |
| **题材与元素** | **开罗** | 恋爱线、社团、学园祭、教师系统、校园作息、设施靠使用升级、时间节拍、解锁阀门 |

三条推论，全文据此解读：

1. **玩家的身份更接近 AIvilization 的引导者与制度设计者，而不是开罗的经营者。** §8 的四层杠杆是 AIvilization 两条 steering 通道的扩展，不是开罗建造玩法的加强。
2. **开罗元素进入本案时一律改造成 agent 原生形态。** 三例：恋爱线去掉「光环」中间物、直接经由情绪作用于效率（§5.1.6）；建筑加成改为意愿 / 效率 / 记忆三类、逐栋生效（§6.2）；梦想从预分配标签改为从经历长出来（§5.1.4）。**改造不成立的元素就不取**（§1.4）。
3. **长期目标的唯一来源是「看这个社会长成什么样」。** 学校层只有描述性的宏观指标面板，不评级、不打分（§9.2）。

### 1.4 明确不做什么

**不取的 AIvilization 部分**

- 不做城市换皮：不引入完整六层职业、不引入住宅等级、不引入三次产业链。校园的经济纵深来自「课程—社团—升学」的资格链，不是制造业配方。
- AMM 只用于定价，**不做铸造 / 销毁**（校内货币总量不与产出耦合，§7.1）。
- 不做持续推进的服务型部署（玩家离线时世界照常运转）——与 §4.4 的运行控制纪律冲突。

**不取的开罗部分（经营游戏框架）**

| 不取项 | 理由 |
|---|---|
| **最优布局解题层** | 本案不承诺「确定性最优化」这种乐趣。建造是供给条件，不是解题（§3.1） |
| **组合景点**（3 建筑 / 3 格触发命名奖励） | 它天然要求一张组合表，而组合表就是待办清单的另一种形态。三类加成改为逐栋挂在建筑上（§6.2） |
| **灯泡提示** | 它只是给组合表打的补丁，表不存在则补丁无意义 |
| **评级链 / 评级螺旋 / 校格** | 「把校格推到顶」正是本案不想给玩家的那种目标。留着它玩家就会去推，一旦去推，「看这个社会长成什么样」就退成背景（§9.2） |
| **成就点 / 完成度清单 / 图鉴收集驱动** | 3 代的「歪罗君的挑战书」证明它会把后期变成待办事项〔源:K §5.8〕 |
| **固定通关年限** | 改为按钮运行控制，无单局时长目标（§4.3、§4.4） |

**其他边界**

- 不做多人同校（首版）。真人玩家进入同一所学校会立刻把 agent 变成服务 NPC，摧毁 ② 的产出。
- 不做多校生态（首版）。后期活力由单校内生机制承担（§9.4）。
- 不宣传「AI NPC 更聪明的口袋学院」。若 agent 只是让数值波动更自然，LLM 成本无法回收——**玩家感知不到的智能等于没有智能**（§3.2）。
- 不做任何强制或引导性的重开循环。重开完全由玩家决定（§9.5）。
- **不做决策型的学校 agent**：学校没有自己的规划、没有自己的 LTM、没有自己的人格。它只作为空间 + 制度 + 账本 + 聚合量存在，另加一个**只做回溯编纂的叙述视角**（§5.4、§11.2）。

## §2 为什么是校园题材（立项论证）

本节论证**为什么校园适合承载 AIvilization 的架构**。两份材料的短板恰好互补，且是逐条咬合的。

### 2.1 AIvilization 的四处空洞，校园题材各自怎么填

| # | AIvilization 的问题 | 原文证据 | 校园题材如何填 |
|---|---|---|---|
| **A1** | **教育维度没有前置结构，是它架构优势失效的唯一地方** | 消融 Task 2 中 Default 输给 Without-OD，作者归因：「本环境中的教育活动**没有复杂前置结构**——不像工业生产要遵配方、要囤上游材料。因此目标分解收益有限，反而引入额外规划开销损害效率」〔源:A §5 Task 2〕 | 校园就是给教育造前置结构的题材：课程有先修依赖、社团解锁要设施条件、考试有周期、升学有分位门槛、教师配置决定教室属性倾向。**教育在 AISchool 里恰好变成「有配方、要囤上游」的那类活动**——分层规划的优势应当在此重新成立。这是本项目最强的设计假设，也是首个必须验证的实验（§12.2 M1） |
| **A2** | **agent 一生没有终点，身份演化缺少天然观察窗口** | Adaptive Profile 是核心贡献〔源:A §2.4〕，但公开服 agent 无限期生存，「档案从空到满」的完整弧线无法被切片观察 | 学生 **3 学年一轮**〔源:K §3.1〕。入学时档案近空白 → 三年经历写入 LTM → 毕业结算。**三年是 agent 身份演化的天然完整弧线**，且每年 4 月都有新队列入学，形成可横向对比的世代面板数据 |
| **A3** | **人类干预只有 agent 级，没有环境级** | 两条通道 Strategic / Reactive Steering **都是对单个 agent 下达**〔源:A §2.5〕。论文自己批评「用反复的低层指令去硬掰行为是脆弱的反模式」，但没给出「不下指令也能影响群体」的手段 | 建造与制度层就是环境级干预：设施摆放与空间可达性、学费、课程解锁、社团经费、校规。**这补上了干预的第三与第四条通道**，并引出一条 AIvilization 没有的成本分级维度（§8.1） |
| **A4** | **算力是规模瓶颈** | 「维持数千个并发、带记忆增强的 agent 成本高昂」〔源:A 局限 3〕 | 学校人口天然封顶（开罗 2 代在校生上限 36 人〔源:K §4.3〕）。且校园作息高度同质——上课、自习、睡眠是**可批量折叠的时段**，只有少数 agent 在少数时刻真正处于决策点。校园比城市更适合做保真度分层（§10.2、§10.3） |

### 2.2 从开罗取来的元素需要哪些改造

| # | 开罗的问题 | 原文证据 | agent 架构如何填 |
|---|---|---|---|
| **K1** | **学生只是数值容器** | 2 代加恋爱系统正是为解决此问题，但「触发率太低，有玩家报告 11 年只成 4 对，招牌系统实际体感稀薄」〔源:K §4.2〕 | 学生是完整 agent：有 LTM 里的 values / habits / social record〔源:A §2.4〕。社交是**内生高频**的，不需要靠低概率掷骰触发。问题从「太少」翻转为「太多需要节流」（R6） |
| **K2** | **梦想与就业是一次性掷骰** | 1 代「每个职业有独立成功率，失败就沦为 Part Timer」；3 代「毕业时通过就职进学试验结算是否实现」〔源:K §3.3、§5.4〕。三年过程与那一次结算之间没有可读的因果 | 梦想不再是随机分配的标签，而是**从经历里长出来的 LTM 条目**。「他初二时想当医生，因为照顾了生病的同桌；高三放弃了，因为成绩点始终卡在门槛下」——过程与结算之间有可读链条（§5.1.4、§9.1） |
| **K3** | **后期决策密度不增长** | 最高频批评：「约第 10 年开始腻」「收集全建筑要 20 年，后 10 年痛苦挂机」；文档结论是「加内容不等于加游戏时长的质量。后期需要的不是更多东西可收集，而是**更多值得做的决策**」〔源:K §5.10、§7.5〕 | 后期内容不是收集清单，而是**关系与结构的演化**：校风惯性、代际循环、出口经营。这些由 agent 群体自发产出，不需要美术与内容量线性投入（§9.4） |

### 2.3 直接对接的三处（成本最低）

不需要设计新机制，只需改称谓：

| AIvilization | 对接后 |
|---|---|
| 动态知识门槛 $\widehat{H}_{\min}^{(j)}(t) = \max(H^{(j)}_{\text{floor}},\ q_{1-\pi_j}(t))$，全平台教育分经验分布的分位数，「全民卷学历时门槛自动水涨船高」〔源:A §3.5〕 | **用于升学与保送名额**。分位门槛复现内卷——这是校园题材最贴切的机制，AIvilization 那个公式几乎是为高考写的（§7.3） |
| 生理三状态 satiety / energy / health 调制生产效率，「加班和熬夜会立刻带来效率损失」〔源:A §3.1〕 | 学生状态 = 精力 / 情绪 / 健康，直接调制学习效率。**熬夜刷题当晚有效、连续三天崩盘**——校园题材里共鸣度最高的一条机制，且已在 AIvilization 里跑通（§7.2） |
| Safety-net：对持续处于临界生理状态的 agent 发放基础食物补贴，防止「不可逆退出经济系统」〔源:A §3.1〕 | **辍学 = 不可逆退出**。助学金、免费午餐、心理辅导室是显式政策杠杆，有真实成本与真实收益，且是 ③ 号身份的第一个 A/B 变量（§7.5） |

另有一处开罗机制原样保留：**教研点**（承 1 代研究点）。开罗研究文档给它的定位是「把『经营收益』翻译成『内容开放』的**唯一阀门**」〔源:K §2.2 ③〕。它是节奏控制器，本案不做机制改动，仅调分支数（§6.5）。

## §3 核心设计原则

### 3.1 第一原则：确定性留环境层，不确定性留人物层

全案的承重原则，后续所有机制取舍都从它推出：

| 层 | 是否确定 | 内容 | 玩家关系 |
|---|---|---|---|
| **环境层** | **确定、可查、可精算** | 建筑属性与占地、三类加成的覆盖与衰减（§6.2）、学费与维护费、课程解锁、门槛公式、教研点产出、经济结算 | 玩家的**操作对象** |
| **人物层** | **不确定** | agent 每一刻做什么、和谁交好、梦想变成什么、是否响应引导 | 玩家的**观察与影响对象**，不是操作对象 |

推论——玩家做的事不是「精确控制结果」，而是：

> **设计一个让好事更可能发生的环境。**
> 这是**概率性园艺（probabilistic gardening）**——园艺不是解题。

具体说：一间自习室不给「文 +3、理 +3、态度 ×2」〔源:K §3.2 例〕这类硬乘子，而是**提高「去自习」这个子任务进入 agent 候选集并被选中的概率与效率**。这个概率必须在 UI 里诚实显示（例如「该建筑覆盖半径内，自习意愿 +25%〔提案〕」）。

**透明化的目的是「可理解」，不是「可最优化」**（§11.3 规则一）。玩家造一座图书馆，是为了让想读书的人有地方读书，不是为了把某个数值推到理论上限。

与此配套的是一条不可违反的实现纪律：**环境层永不直接改写 agent 的选择**。加成只作用于意愿概率、效率与记忆权重三类（§6.2、§8.4）。

### 3.2 第二原则：LLM 的钱必须花在玩家能看见的地方

若 agent 的智能只体现为数值曲线更自然，成本无法回收。因此**内心可读性是硬性产品要求，不是彩蛋**：

任意时刻点开任意学生，必须能看到 AIvilization 的 Unified Agent Profile 三段结构〔源:A §2.4〕的校园版实例，外加**今天这个决定的理由**：

```
状态    精力 62/100 ｜ 情绪 平稳 ｜ 健康 88/100
        成绩点 143 ｜ 零花钱 2,150 ｜ 宿舍 二级 ｜ 社团 剑道部（二年级正选）
长期记忆 信念：不想让父亲失望，但越来越怀疑那是不是自己的愿望
        习惯：早自习前先去天台待五分钟
        人格：内向；一年级下学期后对冲突的回避明显减少
        社交：田中 = 挚友（他在县大会前替我顶了训练）；顾问佐藤 = 敬畏但不亲近
短期记忆 成功：晨练 ×3、自习 2h、与田中交谈
        失败：报名夏期讲座 —— 理由：报名费 3,000，手上只有 2,150
今日决策 本想去自习室（覆盖内自习意愿 +25%），但注意到田中缺席训练，
        改去了部室。理由：上周他替我顶过训练。
```

**「他今天为什么没去自习」这一行，就是 LLM 成本的产品化出口。** 它同时也是 K1（学生只是数值容器）与 K2（梦想是一次性掷骰）两个问题的直接答案。

### 3.3 第三原则：玩家不可微操，只能委托

一所 200 人的学校不可能逐个下指令，而 AIvilization 的两条 steering 通道都是单 agent 级的〔源:A §2.5〕。AISchool 因此引入**校长 → 教师 → 学生**的三层委托结构：玩家对教师下方针，教师 agent 把方针翻译成对一批学生的引导。

这本质上是把 AIvilization 的分层规划思想从「单 agent 内部」推广到「组织层级」：**教师是组织层的 Global Synthesis 器**〔源:A §2.1 ④〕。详见 §8。

### 3.4 第四原则：动机框架是玩家的选择，且有机制后果

开罗研究文档的一个关键洞察：就业系统三代骨架几乎一样，但 1 代是「玩家指定职业，成功抽 3% 提成 → 学校是一门生意」，3 代是「学生有自己的梦想，你帮他实现 → 学校是一段人生」，「机制骨架几乎一样，输出的情感完全不同」，结论是「**不要只优化系统，要意识到『动机框架』本身就是设计变量**」〔源:K §7.3〕。

AISchool 把这个设计变量**交给玩家**，并且——因为学生是真 agent——**让它产生机制后果**：

| 校方立场 | 做法 | 收益 | 代价 |
|---|---|---|---|
| **升学率导向** | 按最优路径分配学生的志愿与课程，压低失败率 | 升学分布、财政回报最好（§9.2 指标面板） | 被强行分流的 agent 会把这件事写进 LTM，影响态度、社交与**校友回访意愿**（见 §9.2） |
| **梦想导向** | 尊重每个 agent 自己长出来的梦想，即使命中率低 | 声誉、校友忠诚度、涌现事件丰度 | 短期升学率与财政明显更差 |

关键是这不是两个难度选项，而是**两条会被长期审判的路线**：十年后回校的校友，其 LTM 里对母校的评价是玩家治理风格的存档。

## §4 世界与时间结构

### 4.1 时间的四层节拍

开罗公式的节拍是「日/周/月/年三层，日常自动流动（可加速），玩家只在固定节点做决策」，其价值是「解决了经营游戏操作量太大的问题——玩家不需要一直操作，但一直有事发生」〔源:K §2.2 ①〕。AISchool 沿用，但**最小单位下沉到「时段」**。

下沉的理由来自 AIvilization 消融 Task 3 的一条结论：「本环境中**动作带显式时长，时间成本是生产成本的关键组成**」，按每规划步归一化与按每分钟归一化会得出**相反**的结论〔源:A §5 Task 3、§7 第 9 条〕。校园里时段是最自然的时间成本单位——一节课就是一节课，agent 的取舍必须在「这个时段做什么」上发生，否则时间约束不存在，规划也就没有意义。

| 层 | 长度〔提案〕 | agent 在此层做什么 | 玩家在此层做什么 |
|---|---|---|---|
| **时段（Period）** | 一天 8 段：早自习 / 上午 2 节 / 午休 / 下午 2 节 / 放学后 / 夜间 | 选择并执行一个原子动作 | 通常不介入；可对个体下 reactive 指令 |
| **日** | 8 时段 | 日末反思：轨迹分类为成功/失败写入 STM〔源:A §2.4〕 | 观察；快进 |
| **周** | 5 学日 + 周末 | 社团活动、练习赛、周末外出 | 社团经费与出战安排 |
| **月** | 约 4 周 | — | **月末财务结算**（沿用开罗节点〔源:K §2.2 ①〕） |
| **学期** | 约 4 月 | 期中/期末考、成绩公布 → **触发 BTP 顶层重规划** | 课程与教研点投放、分位门槛重算后的政策调整 |
| **学年** | 2 学期 + 假期 | 升学考 / 毕业结算；新队列入学 | **年度指标面板回顾**（§9.2）、建造大改、制度调整、教师增减 |

### 4.2 学年历（固定事件骨架）

开罗的年度事件是「付费选一个规模档位，玩家决策只有一个数字」，3 代把学园祭做成独立企划系统是它「在表现层投入最明显的地方」〔源:K §5.6〕。AISchool 取 3 代路线，但企划的执行者是 agent——玩家批预算与主题，**学生自己去筹办、分工、吵架、临阵掉链子**。

| 月〔提案〕 | 事件 | 机制作用 |
|---|---|---|
| 4 月 | 入学式、新生分班、社团招新 | 新队列注入；社团派系起点 |
| 6 月 | 期中考、体育祭 | 首次分位门槛快照；社团属性变现 |
| 7–8 月 | 期末考、暑假（付费讲座 / 集训 / 打工 / 放空） | **跨期取舍的主战场**（见 §7.4） |
| 9 月 | 文化祭（学生企划） | 涌现事件的最高密度窗口 |
| 11 月 | 全国大会（承 3 代的练习赛 → 全国大会 + 球探〔源:K §5.5〕） | 社团出口；球探接触。**对手校为抽象参数，不是被模拟的 agent 学校**（§1.4 不做多校生态） |
| 12–1 月 | 期末考、三年级志愿确定 | §3.4 的立场选择在此逐人落地 |
| 2–3 月 | 升学 / 就职试验、毕业式 | **三年弧线结算**；校友档案生成 |

### 4.3 时间结构：无固定年限

**不设单局时长目标，不设通关年限。** 一所学校没有「通关」，只有运行（§4.5）。

| | AISchool |
|---|---|
| 形态 | **一所持续运转的学校**，由玩家决定跑多久 |
| 第 11 年 | **里程碑**——触发一次阶段性总结报告，不中断运行 |
| 第 16 / 20 年 | 同上，里程碑序列 |

这个选择有一个代价：失去「第 11 年 4 月看到毕业生就业成绩」那种收束感。补偿是把闭环从**学校层**下移到**学生层**：

> **一所学校没有结局，但每个学生都有。**

每三年就有一届毕业生结算（§9.1），每一届都是一次完整的收束。里程碑报告与世代面板（§11.2）因此是持续的反馈来源，而不是一次性谢幕。

### 4.4 空间

- 斜 45° 俯视格子地图（§11.1），校园边界可购地扩张。
- 建筑自由摆放，走廊连通性影响通学距离与情绪（承 1 代「布局同时影响通学距离与士气」〔源:K §3.2〕）。
- **空间是 agent 可感知机会集的物理载体**：agent 规划时只把「当前位置在该时段可达范围内」的动作纳入候选。因此「把自习室放在离宿舍多远」是一个真实的设计决策，而不是数值装饰。这是 §3.1「概率性园艺」在空间上的落地。

### 4.5 运行控制

只有三个按钮：

| 按钮 | 行为 |
|---|---|
| **开始 / 继续** | 从当前时段起推进。可选倍速（时段/秒），上限受计算吞吐约束（§11.4） |
| **停止** | 在**当前时段边界**冻结。不得在时段中途停——半个时段的 agent 决策无法一致地持久化（R10） |
| **重置** | 丢弃当前运行，回到开局配置界面（§5.0 的 cohort 与分布参数） |

三条要求：

1. **停止必须是真冻结，不是后台继续。** 玩家离线时学校不动。这样每一次「我回来发现学校变成这样了」都是玩家自己按下开始的结果，因果链不断——这与 §10.5 导演层「只注入刺激不改写决定」是同一条纪律：**玩家对世界的因果理解必须始终可信。**
2. **重置前必须确认并归档。** 一次运行累积的校友档案库（§5.3）是玩家的真实产出，误触的损失不可接受。〔提案〕重置时自动把该次运行的校友库与世代面板归档为独立存档，可跨运行翻阅。
3. 这个形态天然贴合 ③ 号身份：**开始 / 停止 / 重置 = 跑实验 / 取数据 / 换条件重跑。** 同一套按钮，游戏与研究共用。

## §5 Agent 设计

### 5.0 Agent 的来源：配置 / 生成 / 混合

任何 agent（学生或教师）可来自三条来源之一，档案中记录 **provenance** 字段：

| 来源 | 玩家投入 | 内容 |
|---|---|---|
| **手工配置** | 高 | 姓名、**MBTI 种子**、家庭档次、初始梦想倾向、六维初值倾向；教师另加教育理念三轴与潜力档 |
| **系统生成器 agent** | 低 | 玩家只设**队列分布参数**，由「招生官 agent」批量生成一届 |
| **混合**（默认） | 中 | 玩家精配少数关键人物，其余由生成器补齐 |

#### ① MBTI 只是种子，不是锁

AIvilization 的 Profile 样例里 Personality 一栏「**不是静态 MBTI 标签**，而是『MBTI + 一串演化描述』——这就是 adaptive profile 的具体落地形态」（样例原文：`MBTI INTJ；控制欲下降；协调能力提升；从独狼转向团队信任`）〔源:A §2.4〕。因此：

> 玩家配的是**入学那天的他**。三年后他会变成什么样，不由配置决定。
> 「我配的那个 INTJ，三年后变得愿意信任别人了」——**这本身就是本案最强的卖点之一**，也是 §8.3「玩家的管理风格会变成学生的性格」的入口。

UI 必须把这一点讲明白，否则玩家会以为配了 MBTI 就锁定性格，然后把人格漂移当成 bug 投诉。

#### ② 主要配置对象应当是分布，不是个体

这与 §8.1 的杠杆分级同源：**玩家不微操个体，玩家操纵分布。** 生成器 agent 接受的参数〔提案〕：家庭档次分布、六维初值分布、MBTI 分布（可直接参考 AIvilization 消融的做法——16 种 MBTI 各 5 个〔源:A §5〕）、初始梦想的有无与方向分布、转学生比例。

**手工精配是稀缺的例外，必须有配额**，否则玩家会造一届全 S 潜力 + 全高家庭档次的学生，把 §7.3 的分位门槛与 §7.5 的安全网同时架空。〔提案〕每届手配名额 2–3 人，且其属性总和与家庭档次受预算约束。

#### ③ 教师手配的意义比学生更大，建议不设名额限制

教师是委托层（§5.2、§8.2）。玩家手配教师的**教育理念三轴 + 潜力档**，等于亲手组建自己的执行团队——而理念冲突带来的委托损耗（§5.2.2）也就成了玩家自己的选择结果，不是系统强加的惩罚。这比手配学生更值得开放，且教师满编只有 8–16 人，**编制本身就是配额**。

#### ④ provenance 字段的两个附带用途

- **③ 号身份**：固定种子 + 分布参数 = **可复现的 cohort**，这是 A/B 实验的前提（§12.2 M6）
- **UGC 与传播**：玩家可导出 / 导入 / 分享 cohort 预设（「把我和我朋友做成一届学生」）。这是开罗完全没有的传播面，工程成本极低

#### ⑤ 顺带得到一个玩法模式

§12.1 的 P0 验证档是 36 学生 + 8 教师全 Focus——**这个规模恰好是「玩家可以手配全体」的量级**。所以 P0 不只是技术验证档，可以直接作为正式版的「**小班制精配**」模式保留，一份工作拿两次收益。

### 5.1 学生 Agent（核心）

#### 5.1.1 认知架构：原样承接，只改分支

完整承接 AIvilization 的四块闭环：双过程记忆 → 分层规划器 BTP → 动作模拟器 AS → 环境 → 回写记忆〔源:A §2〕。**唯一的实质改造是战略分支的切分**：

| AIvilization 的 4 支〔源:A §2.1 ①〕 | AISchool 的 4 支〔提案〕 | 说明 |
|---|---|---|
| personal development（健康、教育） | **学业**（成绩点、课程、考试、升学门槛） | 承接并大幅加深——A1 的填补口就在这一支 |
| production & resource management | **社团与专长**（六维属性、社团、比赛、球探） | 替换。生产链被社团/专长链取代（§1.3） |
| trading & market analysis | **人际**（友谊、恋爱、师生、派系） | 替换。K1 的填补口在这一支 |
| social engagement | **自我**（精力、情绪、健康、梦想与身份） | 独立成支。梦想的生成与修正发生在这里 |

分支化的原理不变——「问题因子化，长链误差传播被切断，同时天然支持多域并发思考」〔源:A §2.1〕。而校园题材让这四支之间的**共享资源冲突极其具体**：时段就那 8 个，精力就那么多。Global Synthesis 层要处理的正是「要不要为了社团比赛牺牲这周的复习」——这是校园叙事的核心张力，而它在架构上原本就是 Global Synthesis 的职责：「显式处理局部最优与全局最优的冲突——比如防止『产能最大化』这一个分支把 agent 的健康搞崩」〔源:A §2.1 ④〕。

#### 5.1.2 顶层重规划的触发表（成本关键）

AIvilization 的规则是「最高层分解**不是每周期都跑**，只在环境显著变化或需要战略重估时触发。算力省下来喂给底层的实时适应」〔源:A §2.1〕。这条纪律必须保留，但「环境显著变化」在校园里要写成可判定的显式清单，否则无法控成本：

| 触发条件〔提案〕 | 频率 |
|---|---|
| 学期成绩公布（含分位门槛重算后自己的位次变化超阈值） | 每学期 2 次 |
| 社团比赛结果（尤其大会淘汰或夺冠） | 每年 1–2 次 |
| 重要关系事件（结为挚友 / 决裂 / 告白成败 / 顾问更换） | 事件驱动，低频 |
| 健康或情绪跌破临界 | 事件驱动 |
| **玩家或教师的 strategic steering** | 玩家驱动 |
| 家庭事件（经济变动、期望施压） | 低频 |
| 年级升格 / 志愿确定 | 每年 1 次 |

其余时段一律走**轻量路线**：Contextual Prioritization 排序 → micro-planner 出动作 → AS 校验。这直接对应 AIvilization 消融 Task 4 的结论：目标明确、路径短的任务上，轻量机制「足够且有效」，与完整架构「几乎完全打平」（Chips 6.15 vs 6.14）〔源:A §5 Task 4〕。

#### 5.1.3 属性：从「目标」降级为「约束」

借 3 代的六属性 + 独立成绩点结构〔源:K §5.4〕，改名以贴合语义：

**成绩点**（独立，用于考试与升学门槛）+ 六维：**体能 / 表达 / 交际 / 审美 / 技术 / 心性**。

（「技术」承 3 代的 IT——文档评价「加入 IT 是很有时代感的一笔，2022 年的校园模拟里『信息技术』确实该是独立维度」〔源:K §5.4〕；「心性」承 3 代的精神。）

**但语义发生了根本变化**：在口袋学院里属性就是一切，玩家的全部行为都是为了把数字推高。在 AISchool 里——

> 属性不是 agent 的目标，而是 agent 行为的**结果**，以及 agent 能不能做到某件事的**约束**。
> agent 的目标写在 LTM 里（信念、梦想、对某人的承诺）。

这是 K1 的根治。它也意味着 UI 上属性条不应占据主位——**主位是那段可读的 Profile（§3.2）**。

#### 5.1.4 梦想（Dream）：不预分配，长出来

这是 K2 的答案，也是 ② 号身份的产出核心。

| 字段〔提案〕 | 说明 |
|---|---|
| 内容 | 自然语言，如「想当能治好爷爷那种病的医生」 |
| 强度 | 决定它在 Contextual Prioritization 层的加权 |
| 来源 | 指向具体经历（哪次事件、谁的影响、校友讲座） |
| 可达性自评 | agent 自己对「按当前轨迹能否达成」的判断，可与真实门槛不符（这正是 agent 会犯的错，也是玩家介入的理由） |

规则：**入学时梦想为空或仅有家庭期望**；三年中由经历生成、可修正、可放弃、可复活；毕业结算比对实现情况。放弃与修正**必须留下记录**——「他高二放弃了当医生，因为成绩点连续三次卡在门槛下」这一行，比任何数值都更有分量。

#### 5.1.5 家庭背景：教育不平等的入口

AIvilization 的住宅等级 $R_a$ 是「离散状态，**门控**部分生产技术与职业」，双重门控「直接对应现实不平等的两个基础维度——人力资本投资 与 **资产型准入约束**」〔源:A §3.5〕。

AISchool 把 $R_a$ 映射为**家庭经济档次**（离散，入学时分配，三年内基本不变但可有事件变动）。它门控：

- 零花钱流量 → 能否负担付费讲座、私教、社团器材、集训
- 宿舍/住宿条件 → 精力与健康的恢复上限（承 AIvilization「生理状态上限受住宅等级约束」〔源:A §3.1〕）
- 家庭期望的方向与强度

**这是 ③ 号身份最重要的自变量**：同一批梦想分布的 agent，改变家庭档次分布或改变助学金政策，观察三年后升学结果分布如何变化——这正是 AIvilization 想做而没做的受控实验〔源:A 局限 2〕。（家庭档次分布可由 §5.0 的生成器参数直接指定，这就是那个实验的操作杆。）

#### 5.1.6 关系如何接进主循环

开罗研究文档判定 2 代恋爱系统的价值在于它解决了「学生只是数值容器」这一结构性问题，做法是「学生靠人气积累爱心，触发光环后成对。**Aura 光环（黄→蓝→红→彩虹）会提升学习效率与考试成功率**，而光环来源是活动与异性交流」，结论是「**软性叙事被硬性经济需求拉进了核心循环**，这是很聪明的设计」，并列为三代里「最优雅的『叙事—机制』耦合」〔源:K §4.2、§6.2〕。

AISchool 保留这条耦合，但**不复制「光环」这个中间物**——agent 世界里不需要它，关系可以直接经由情绪作用于效率：

```
关系事件（结交 / 被支持 / 告白 / 冲突 / 分手 / 和解）
  → 写入 LTM（若发生在 c 类记忆加成的建筑或自发场所内，权重更高，§6.2 / §6.3）
  → 改变情绪与心性
  → 情绪与心性是 §7.2 中 Eff 因子的自变量
  → 影响学习产出与考试表现
```

三处差异，全部来自 agent 化：

| | 开罗 2 代 | AISchool |
|---|---|---|
| 触发 | 低概率掷骰，「11 年只成 4 对」，招牌系统体感稀薄〔源:K §4.2〕 | **内生高频**，问题反转为需要节流（R6） |
| 方向 | **只有正向加成** | **双向**：支持与和解提升效率，冲突与分手同样真实地拖垮它 |
| 可读性 | 只能看到光环颜色 | 能读到他为什么状态好、为什么突然崩（§3.2 的今日决策理由） |

「双向」这一条是本案与开罗最大的气质差别：

> 在开罗，社交是一个**增益系统**。在 AISchool，社交是一个**风险系统**。

一个学生可能因为一段关系考得更好，也可能因为它整个学期崩掉——而玩家能读到全过程，并且必须决定自己插不插手（§7.4 的核心循环）。内容边界见 **§13.4**。

### 5.2 教师 Agent（受委托的治理者）

#### 5.2.1 骨架：原样承接 3 代

开罗研究文档判定 3 代教师系统是「系列最有深度的资源规划系统」，结构为：28 名教师、按成长潜力分 **F/E/D/C/B/A/S 七档**、等级上限对应 **10/20/30/40/50/60/70**、每 10 级解锁 1 个技能（技能 3 阶，阶数越高薪水越贵）、每名教师提升 6 属性中的 3 项、**绑定单一教室**、每教室最多 4 名、满编约 16 名〔源:K §5.3〕。文档对其设计价值的判定是：把 2 代「8 个教师随便配」变成了**长期资源规划问题**。

这套骨架**原样保留**，不做改动。它是本案的经营纵深来源。

#### 5.2.2 agent 化增量：委托与损耗

新增的是——教师有自己的 LTM 与**教育理念**〔提案〕：

| 理念轴 | 两端 |
|---|---|
| 严格 ↔ 放任 | 影响其对学生下 reactive 指令的频率与强度 |
| 重结果 ↔ 重人 | 影响其在「升学率」与「学生梦想」之间的默认偏向 |
| 护自己班 ↔ 护全校 | 影响资源争夺（教研点、场地、优秀生源）时的行为 |

**玩家的方针经由教师执行，会产生委托损耗**：理念与方针冲突时打折执行，极端冲突时阳奉阴违甚至提出异议。这使「谁当班主任」「谁做社团顾问」从属性配点题变成真正的用人决策，也是 §3.3 三层委托结构的机制载体。

对应地，教师**会主动离职**（理念长期被压制、超负荷、待遇落后于其技能阶数带来的市价）。这是口袋学院没有的压力——开罗的教师只是可配置资源。

#### 5.2.3 教师持有的 steering 权限

AIvilization 的两条通道〔源:A §2.5〕在 AISchool 中由玩家与教师**分持**：

| 通道 | 玩家 | 教师 |
|---|---|---|
| **Strategic**（长期目标，写入学生 LTM，走完整 BTP） | 有，但配额极少（见 §8.3） | 有，学期节点对本班学生下达 |
| **Reactive**（即时具体指令，走轻量规划路线，跳过 BTP） | 有，配额中等 | 有，日常高频 |

这解决了一个纯工程问题：玩家不可能对 200 个学生下指令，而**教师 agent 可以**。教师因此既是叙事角色，也是**成本与操作量的中间抽象层**。

### 5.3 校友 Agent（离场但不消失）

2 代的毕业生回校「保留最终数值的 85%」，文档评价其设计价值是跨代际复利 + 15% 衰减防躺赢〔源:K §4.3〕。AISchool 保留「校友会回来」这件事，但把它从「属性打折的回访 NPC」升级为**带完整三年档案离场的 agent**（转入低保真度存档态，见 §10）。

四项功能：

1. **回校讲座** — 向在校生提供梦想样本，直接写入听众的 LTM。这是玩家影响新生梦想分布的一条**间接、廉价、有叙事感**的通道
2. **招聘与内推** — 为在校生开一条升学/就职出口，成功率与该校友当年的实现情况挂钩
3. **捐赠** — 财政收入，额度与其 LTM 中**对母校的评价**挂钩
4. **校友档案库** — 替代图鉴的收集层

第 3 项是 §3.4 的执行机构：**十年后回来捐钱的，是那些当年梦想被尊重过的人。** 玩家在第 3 年做的每一次「按升学率分流」的冷酷决定，会在第 13 年的财务报表上收到账单。这条反馈环极长但完全可读，而且它是靠 agent 记忆自然产生的，不需要额外写系统。

第 4 项值得单独说：开罗的收集层是建筑图鉴、职业图鉴、教师图鉴（3 代的「歪罗君的挑战书」把它显式化为清单，文档评价这「让『内容量』变成了可见的待办事项，某种程度上加重了『后期是在刷清单』的感受」〔源:K §5.8〕）。**AISchool 的收集物是人生**——一份份可翻阅的三年轨迹。它不会变成待办清单，因为它不可穷举、也不由玩家勾选完成。

### 5.4 非 agent 实体与判据

#### 判据

> **该不该做 agent，判据不是「它现实中是否是一个主体」，而是「它是否有不能被其成员的决策还原的决策」。**

| 实体 | 有不可还原的决策？ | 做不做 | 「不做」的性质 |
|---|---|---|---|
| 学生 / 教师 / 校友 | 有 | 做（§5.1–§5.3） | — |
| **家长** | **有**（转学、施压、禁止打工、期望强加） | 不做 | **原则上该做，因成本妥协**——是欠账，将来可补 |
| 教育局 / 周边居民 / 竞争校招生官 | 弱 | 不做 | 事件源与约束源足够 |
| **学校本身** | **没有** | 不做 | **原则上就不该做**——是设计结论，不是妥协 |

家长与外部实体的表现形式是：家庭期望值、经济状况变动、投诉与舆情事件、生源竞争压力参数。

#### 学校为什么不该是 agent

去掉玩家那一份，学校剩下的是**空间（§6）+ 制度（§7.6）+ 账本（§7.1）+ 聚合量（§9.2）**，四项全部可还原为成员决策或派生统计，没有剩余的决策位。具体到本案，做成 agent 会同时撞坏两个身份：

1. **撞 ① 号身份**：校长的决策就是学校的决策，而校长是玩家。学校 agent 会规划就要跟玩家争同一个决策位——它听玩家的就不是 agent，它有自己的主张则玩家在跟一个隐藏的副校长打架。而委托损耗已由教师层承接（§5.2.2），不需要第二层。
2. **撞 ③ 号身份**：§7.6 制度层的研究价值全在于**制度是外生处理变量**（同一批种子、只改一个开关、比三年后的分布）。学校 agent 能改制度，处理变量即不再外生，§12.2 的 A/B 当场失效。

**校风同理不实体化。** 它是各 agent LTM 里价值观的分布（§9.4 B-A），不是学校的属性；**内化度是派生统计量**（施行学期数 × 受影响 agent 占比），不是学校的状态。理由与 §10.5 禁止导演层改写 agent 决定是同一条：聚合量一旦被实体化成 agent，就出现两个「这所学校是什么样」的权威——学校 agent 的自我描述与 agent LTM 的真实分布必然漂移，而**玩家永远相信会说话的那个**。到那时 §9.2 的指标面板不再是诚实读数，而是可以被学校的口吻盖过去的东西。

学校唯一被允许的表达形态是**只做回溯编纂的叙述视角**，见 §11.2。

#### 考虑过但推到 P1 的中间物：行政层 agent

一个教务主任 / 事务长 agent，把玩家颁布的制度**解释成细则**。它会补上两样现在没有的东西：制度的**颁布期损耗**（条文→细则，区别于教师层的课堂期损耗），以及一个可被人事更换的治理对象（换教务主任 = 换整套执行风格，是 §8.1 矩阵里没有的杠杆）。

**P0 不做**，理由是它只增加第二个损耗段、不增加新的决策种类，且会让制度层的因果变难读——而制度层的因果可读性是 M1 的实验前提（§12.2）。

### 5.5 保真度与成本预览

| 类别 | 数量〔提案，产品档〕 | 认知保真度 | LLM 调用密度 |
|---|---|---|---|
| 焦点学生 | 20–30 | 完整 BTP + AS + STM/LTM | 高 |
| 背景学生 | 100–170 | 轻量策略 + 简化记忆，可按需提升为焦点 | 低 |
| 教师 | 8–16 | 完整（数量少，可负担） | 中 |
| 校友 | 累积数百 | 存档态，仅在回校/捐赠/内推时唤醒 | 极低 |
| 家长与外部 | — | 非 agent（§5.4） | 无 |
| 学校本身 | — | 非 agent（§5.4）；仅校史叙述层，学年末编纂 | 极低 |

「按需提升为焦点」是关键：玩家点开任一背景学生、或某学生触发重要事件时，其保真度即刻上调。**玩家看向哪里，智能就在哪里。** 详见 §10.2。

## §6 空间与建造

### 6.1 建筑三分类与升级方式

**分类承 1 代**，因为它的成本结构分得最干净〔源:K §3.2〕：

| 类 | 数量 | 月费 | AISchool 示例〔提案〕 |
|---|---|---|---|
| **环境物** | 无限 | 无 | 草地、樱花树、长椅、雕像、自行车棚 |
| **设施** | 无限 | 有维护费 | 教室、图书室、实验室、部室、食堂、保健室、天台 |
| **特殊** | 有上限 | 高维护费 | 校门、钟楼、天文台、心理辅导室、纪念馆 |

**升级方式采用 2 代路线，不采用 3 代路线**——这是本节最重要的取舍。

- 3 代：建筑可升至 Lv9，靠近教室升级更快〔源:K §5.2〕（本质是花钱/花时间）
- 2 代：**设施通过被使用自动升级**，因此攻略结论是「初期少建，集中使用加快升级」〔源:K §4.4〕。开罗研究文档把这条列为 2 代不可替代的优势之一，评价是「逼玩家『少建多用』，产生真正的策略取舍」，也是「2 代难度曲线陡的重要原因」〔源:K §4.4、§6.2〕

选 2 代路线的理由是它与本案的核心立场天然咬合：

> 在 agent 世界里，「被使用」是 **agent 自主选择的结果**。
> 于是「设施等级」不再是一个你能买到的数字，而是**你的学生到底愿不愿意去那里的读数**。

你不能直接买升级，你只能让学生想去。这是 §3.1「概率性园艺」在建造层最纯粹的形态，也让建筑等级本身成为一块免费的、始终在线的行为可视化仪表。

### 6.2 建筑的三类作用：意愿 / 效率 / 记忆

三类作用逐栋挂在建筑本身，按距离衰减：

| 类型 | 作用 | 例〔提案〕 |
|---|---|---|
| **a. 意愿** | 提高相关动作进入 agent 候选子任务集、并在 Contextual Prioritization 层被选中的**概率** | 自习室：覆盖半径内「自习」意愿 +25% |
| **b. 效率** | 执行该动作时的产出 / 时段比（乘进 §7.2 的 $\text{Eff}$） | 图书室：自习产出 ×1.3 |
| **c. 记忆** | 在此发生的事件被写入 **LTM** 的权重 | 樱花树下的长椅：此处社交事件入 LTM 权重 ×2 |

**c 类只有在 agent 世界里才存在。** 它的含义是：建筑不只决定学生做什么，还决定**学生会记住什么**——也就是决定他们的身份从哪里长出来。

这条的产品意义很大：玩家会为了「让学生记住这所学校」而造景。一块什么数值都不加、只加记忆权重的樱花树角落，会成为十年后校友捐赠时反复提到的地方（§5.3）。**造景与情感产出在这里接上了**：

> 你不是在解题，你是在给一群人准备一个会被记住的地方。

三类作用的实现纪律（§3.1）：**加成永不直接改写 agent 的选择**，只作用于概率、效率与记忆权重。

### 6.3 自发场所（Emergent Place）

场所意义的**唯一来源**：一个地方之所以有意义，只能因为有人反复在那里做了什么。它是 AIvilization 理念在空间层的直接产物——宏观意义从微观交互中**内生涌现**，而非预设〔源:A §3〕。

机制〔提案〕：系统持续统计「位置 × 时段 × 行为模式 × 参与者稳定性」四元组，当某处出现超阈值的稳定自发聚集时触发**命名事件**——玩家收到通报（「三年 B 班的几个人这半年总在天台西侧待到天黑」），可为其命名并登记入校史；登记后它获得真实的 **c 类记忆加成**。

三点价值：

1. **它是玩家独有的内容。** 开罗的 66 个景点人人一样、可以抄 wiki；「我的学校长出了一个『天台哲学部角落』」不能抄，这是天然的社区传播素材
2. **它把观察变成有回报的行为。** 玩家盯着学生看不只是消费叙事，而是在找可登记的东西——这是除 §9.4 的「按变化推送」之外，唯一鼓励玩家主动看的机制
3. **它与后期活力正相关**：学校运转越久、关系网越密，自发场所越容易出现

风险：低频时玩家可能一整年什么都看不到（R4）。需要导演层保底（§10.5），且**保底只能提高聚集倾向，不能直接生成一个场所**。

### 6.4 空间即机会集

承 1 代「布局同时影响通学距离与士气，所以摆放不是纯查表——有空间约束」〔源:K §3.2〕，但推进一步：

- agent 规划时**只把当前位置在该时段可达范围内的动作纳入候选**。所以「自习室离宿舍多远」是真实的设计决策
- **拥挤有机制后果**：降低情绪、造成设施争抢与排队浪费时段。3 代把「后期屏幕过于拥挤」当作缺陷〔源:K §5.10〕，本案把它变成设计变量——校园扩建与人口增长之间的空间取舍是后期的真问题

### 6.5 教研点：唯一原样保留的开罗阀门

开罗研究文档给它的定位是「把『经营收益』翻译成『内容开放』的**唯一阀门**，等于强行让玩家的短期优化服务于长期进度」〔源:K §2.2 ③〕。它是节奏控制器，本案不做任何机制改动。

只调分支数：1 代是三分支 Humanities / Science / PE〔源:K §3.5〕，对六属性体系太窄；六分支又太碎。**提案取四分支：学术 / 体艺 / 技术 / 育人。**

| 项 | 内容 |
|---|---|
| 产出源 | 教师使用设施、学生成果（竞赛、大会）、**自发场所的登记**（§6.3） |
| 消耗于 | 解锁课程、设施、社团、**制度**（§7.6） |

## §7 制度与经济

### 7.1 两层经济，刻意不打通

| | 学校层（校长视角） | 学生层（agent 视角） |
|---|---|---|
| 收入 | 入学金、学费、政府补贴、校友捐赠、比赛奖金 | 零花钱（由家庭档次决定）、奖学金、打工、比赛奖励 |
| 支出 | 设施维护费、教师薪水、活动预算、**助学金** | 食堂、小卖部、教材与参考书、社团物资、付费讲座 |
| 玩家 | 直接操作 | **不可直接操作**（只能通过助学金/定价/发放物资间接影响） |

两层刻意不打通：玩家不能直接给某个学生塞钱。这维持 §3.1 的分层——钱在环境层是确定的，在人物层是 agent 自己的决策。

#### 学费杠杆：保留，但显式化

承 2 代的核心杠杆「課題挑戦」——合格后可上调学费〔源:K §4.4〕。开罗对此的教训很明确：「它是整个经济模型的命脉，但游戏几乎不提示。结果是新手大面积破产……这不是『硬核』，是**说明缺失**。真正的难度应该来自权衡，不是来自不知道规则。」〔源:K §7.6〕

因此**保留杠杆、废除隐藏**：UI 常驻显示「当前学费上限 / 下次可上调的条件 / 若本次不上调的 12 个月现金流预测」。难度留在「涨学费会流失低收入生源、恶化家庭档次分布」这个真实权衡上。

#### 学生层要不要 AMM

**提案：只对三个品类引入恒定乘积做市（食堂餐券 / 二手教材 / 社团二手器材），其余固定定价。**

- 引入的理由：AMM 用一行 $\text{IS}_i \cdot \text{CR}_i = k$ 就把稀缺性编码进价格斜率，且买入推高报价、卖出压低，「直接编码稀缺性信号」〔源:A §3.2〕。校内二手书市场因此能内生出囤积、抢购、学期初涨价这类行为，成本极低
- 不全面引入的理由：全面商品化会让 AISchool 变成 AIvilization 换皮，丢掉校园气质（§1.3）

**一处刻意降级需要写明**：AIvilization 让 AMM 兼任算法央行——「agent 向池子卖出商品时铸造新货币注入流通，买入时回收销毁，因此货币总量与真实产出结构性耦合」〔源:A §3.2〕。**这在校园里不适用**，因为学生不生产实物、校内货币总量不应与产出耦合。AISchool 只用恒定乘积做定价，**不做铸造/销毁**，零花钱由家庭档次外生注入。

### 7.2 学习函数：Leontief `min` 的校园版

AIvilization 的生产函数是完全非替代的 Leontief 形式，其文档把它列为可迁移经验第 5 条：「`min` 算子是防退化循环的利器。任一要素短缺直接卡产出，配上分层准入门槛，天然排除生产捷径」〔源:A §3.4、§7 第 5 条〕。

校园版〔提案〕，单次学习动作的成绩点产出：

$$\Delta H = \mathbb{I}\big(\text{课程资格达成}\big)\cdot \text{Eff}\cdot \min\Big(\frac{\text{教材与资料}}{\alpha},\ \frac{\text{精力}}{\epsilon},\ \frac{\text{可用时段}}{\tau},\ \frac{\text{教师覆盖}}{\kappa}\Big)$$

$$\text{Eff} = G(\text{精力},\ \text{情绪},\ \text{健康},\ \text{家庭档次},\ H)\in(0,1]$$

（$\text{Eff}$ 的形态直接承 AIvilization 的 $\text{Eff}_a(t)=G(S,E,J,R,H)$，$G$ 对每个自变量非递减〔源:A §3.1〕。）

`min` 在教育语境里的含义特别好用：**没有教材，再努力也白搭。** 这既真实，又给玩家提供了明确的干预点——发教材、建图书室、增配教师、改课程表，每一项都对应 `min` 里的一个分量。同时它天然防止「靠单一要素堆到无穷」的退化循环。

对应地，**熬夜的机制后果**承 AIvilization 原样：health 因「累积睡眠不足」恶化，energy 或 health 跌破临界则暂时失能〔源:A §3.1〕；设计意图原话是「加班和熬夜会立刻带来效率损失，从而制造短期产出与长期产能之间的非平凡取舍」〔源:A §3.1〕。**在校园题材里这条共鸣度极高，而且它已经在 AIvilization 里跑通过了。**

### 7.3 门槛体系：分位与固定各管一段

这是 §2.3 已经点明的对接，此处给出分工：

| 用途 | 门槛类型 | 公式 | 效果 |
|---|---|---|---|
| 保送名额、重点班席位、校内排名、升学录取 | **分位门槛** | $\widehat{H}_{\min}(t)=\max\big(H_{\text{floor}},\ q_{1-\pi}(t)\big)$〔源:A §3.5〕，$\pi$ = 席位占比 | 全校都在卷时门槛自动上移，**个体努力可能不改变位次**——内卷的机制复现 |
| 课程 / 社团 / 职业资格 | **双重门控** | 成绩点 + 资源位阶（家庭档次或设施等级），承 AIvilization dual-gating〔源:A §3.5〕 | 人力资本 + 资产准入两个维度 |

分位门槛这一行公式，AIvilization 文档评价其「机制密度极高」——同时做到防文凭贬值、保持投资激励、复现位置竞争、维持长期稳定分层〔源:A §7 第 7 条〕。**它几乎就是为高考写的**，放进校园题材比放在城市里更贴切：玩家会亲眼看到自己把全校成绩提上去之后，保送线也跟着涨，而那个卡在边缘的学生还是那个卡在边缘的学生。

### 7.4 跨期取舍：核心玩法循环就在这里

AIvilization §4.5 把这个问题描述得很准：

> 「只优化即时需求的 agent 会『理性地』早早进入低端劳动市场，从而**无意中永久丧失**高层职业资格。」〔源:A §4.5〕

校园版完全同构：只顾眼前的 agent 会在暑假去打工或放空、会为了社团大会放掉整个学期、会因为报名费不够而跳过决定性的讲座——三年后发现门槛过不去。**而这不是它笨，是它在局部信息下的理性选择。**

AIvilization 给出的解法正是人类的长期目标充当**外部信息信号**，举的例子是 `"Do not work yet; study until your education score exceeds a specified threshold"`，作为「启发式推动（heuristic nudge）」重构 agent 的决策框架、提高长期计划的感知价值；日志观察显示最终进入高地位职业的 agent「往往在生命周期早期就接触过这类教育导向提示」（作者同时明确标注这只是相关性）〔源:A §4.5〕。

**AISchool 把这一段直接做成核心玩法循环：**

```
观察 → 识别某个学生正在做一个短视的理性选择
     → 判断：这是他自己的路，还是他缺少信息？
     → 决定介入与否（介入有配额、有代价、有失败可能）
     → 观察后果，写入他的记忆
     → 三年后在毕业结算里看到答案
```

这个循环把「§3.4 的道德选择」「§8 的治理杠杆」「§5.1.4 的梦想」全部串起来，是 AISchool 区别于口袋学院的**主玩法**——口袋学院的主玩法是布局与配点，AISchool 的主玩法是**判断什么时候该出手**。

### 7.5 安全网与辍学

AIvilization 有 safety-net：对持续处于临界生理状态的 agent 发放基础食物补贴，防止「**不可逆退出**经济系统」，理由是「既保模拟连续性，也保最低福利标准」〔源:A §3.1〕。

校园版的不可逆退出是**辍学**。触发条件〔提案〕：健康或情绪长期临界、家庭经济崩塌、连续门槛失败后梦想全部放弃、严重人际事件。

对应的政策杠杆（每项都有真实财政成本）：

| 杠杆 | 作用 |
|---|---|
| 助学金 / 学费减免 | 补家庭档次的短板 |
| 免费午餐 | 补精力恢复 |
| 心理辅导室（特殊建筑） | 补情绪与心性 |
| 家访 | 修正家庭期望；成本是教师时段 |
| 补习班 / 追加辅导 | 补 `min` 里的教师覆盖分量 |

**这是 §1.2 ③ 号身份的第一个 A/B 变量**：同一批种子 agent，开与不开助学金，跑两遍，比较三年后的升学结果分布与辍学率。AIvilization 想做没做的受控实验，在这里是一个下拉菜单。

### 7.6 制度：AIvilization 完全没有的一层

这是本案我认为最独特的玩法层。AIvilization 的人类干预只有个体级两通道〔源:A §2.5〕；开罗的玩家杠杆只有建造与预算。**AISchool 引入「制度」作为一等公民**——玩家可颁布校规，它作为**规划约束或效用偏置**作用于全体 agent。

示例清单〔提案〕：

| 制度 | 正面 | 负面 |
|---|---|---|
| 晚自习强制 / 自愿 | 强制提高平均成绩点 | 恶化情绪与心性，压制社团与人际分支 |
| **成绩公开张榜** | 放大分位竞争，整体成绩点上移 | 尾部 agent 情绪崩塌、辍学率上升、心性下降 |
| 社团活动时长上限 | 保学业 | 削弱专长与大会成绩、削弱人际网密度 |
| 手机 / 电子设备禁令 | 精力集中 | 技术属性成长受阻 |
| 允许 / 禁止打工 | 禁止可防短视选择 | 但断掉低家庭档次 agent 的现金来源 |
| 走班制 vs 固定班 | 走班扩大社交半径 | 削弱班级凝聚与教师委托效率 |
| 助学金门槛松紧 | 见 §7.5 | 财政成本 |

两点设计要求：

1. **每条制度的后果由 agent 群体的反应决定，不由查表得知。** 玩家必须观察。这是「概率性园艺」在制度层的形态
2. **制度要花教研点解锁**（§6.5），所以它受节奏阀门管辖，不会一开局就全开

「成绩公开张榜」这一条值得单独点出：它是 §7.3 分位门槛与 §5.1 agent 心性两个系统的交叉点，也是最干净的 A/B 实验（同一批种子、只改这一个开关、比较三年后的成绩分布**与**辍学率）。**一个游戏里的下拉菜单，同时是一篇教育社会学论文的处理变量。**

## §8 四层治理杠杆

### 8.1 一条 AIvilization 没有的成本分级维度

AIvilization 可迁移经验第 3 条是本案的直接理论依据：

> 「**人类干预要打在与 agent 内部抽象层级匹配的地方**。长期目标进顶层规划 + 长期记忆；即时指令进局部规划器 + STM。用反复的低层指令去掰行为是脆弱的反模式——这是论文明确点名批评的做法。」〔源:A §7 第 3 条〕

但 AIvilization 的两条通道**都是对单个 agent 下达的**〔源:A §2.5〕。它没有回答一个问题：**当你面对 200 个 agent 时怎么办？**

AISchool 的答案是补上第三、第四条通道，形成一个**按「作用范围 × 单位成本」分级的杠杆矩阵**。这与 AIvilization 自己最看重的设计纪律同源——「分层的真正价值是成本分级，不是『更聪明』……把昂贵的深思留给真正需要它的时刻」〔源:A §7 第 1 条〕——只是这次分级的是**玩家的注意力**，而不是算力。

| # | 杠杆 | 作用范围 | 生效延迟 | 单位成本 | 可预测性 | 打在架构哪一层 |
|---|---|---|---|---|---|---|
| **L1** | **建造**（空间、设施、三类加成） | 全体，按位置衰减 | 中（需被使用） | 金钱 + 空间 | 高（可查表） | 改变 agent 的**可感知机会集**与动作效率 |
| **L2** | **制度**（校规、预算、课程、助学金） | 全体，一致 | 中长 | 教研点 + 财政 | **中（须观察）** | 改变**规划约束**与效用偏置 |
| **L3** | **委托**（对教师下方针） | 一批（班 / 社团） | 中 | 用人成本 + 委托损耗 | 中低 | 由教师 agent 转译为对学生的 steering |
| **L4** | **个体引导** | 单个 agent | 即时或跨期 | **玩家配额（稀缺）** | 高但有限次 | 承 AIvilization 两通道原样〔源:A §2.5〕 |

**核心张力就在这张表里**：L1/L2 便宜、覆盖广、但间接且慢；L4 精确有力但极稀缺。玩家的每一局都在回答同一个问题——

> 我应该继续修花园，还是去救那个孩子？

### 8.2 L1–L3 的机制说明（前三节已铺垫，此处只补委托层）

L1 见 §6，L2 见 §7.6。**L3 委托层**是 §3.4 与 §5.2 的落地：

玩家能给教师的是**方针**，不是指令〔提案〕：

| 方针维度 | 选项 |
|---|---|
| 重点 | 保尾部 / 提中位 / 冲尖子 |
| 立场 | 升学率导向 / 梦想导向（§3.4，可逐班设置） |
| 强度 | 高压 / 常规 / 宽松 |
| 特别关注 | 指定 1–3 名学生（本质是把玩家的 L4 配额部分转授给教师） |

教师按自己的教育理念**打折执行**。理念冲突越大，损耗越大；极端冲突时会提出异议或消极执行。因此：

- **「谁当哪个班的班主任」是全案最有分量的一次用人决策**——它决定了玩家的意图能以多大保真度到达学生
- 3 代「教师绑定单一教室，每教室最多 4 名，满编约 16 名」〔源:K §5.3〕这个结构在此获得了新的含义：**一间教室的气质 = 那 4 位教师的理念合成结果**，不再只是「他们加哪 3 项属性」

### 8.3 L4 个体引导：为什么必须有配额

L4 完整承接 AIvilization 的两条通道及其传播机制〔源:A §2.5〕：

| | Strategic Steering | Reactive Steering |
|---|---|---|
| 形态 | 长期目标，如「先别打工，把成绩点做到门槛以上」 | 短具体即时，如「今晚早睡」「去把那本书还给她」 |
| 路径 | 写入 LTM，影响 BTP 分支构造与加权、优先级排序、Global Synthesis 取舍 | **跳过完整 BTP**，只走局部规划器 + Action Simulator |
| 配额〔提案〕 | 每学期 3–5 次（全校） | 每周 5–10 次 |

配额的三条理由，从强到弱：

1. **它是主玩法本身。** §7.4 的核心循环是「判断什么时候该出手」。如果可以无限出手，就没有判断，游戏退化为微操——而微操 200 个 agent 既不可能也不有趣
2. **它保护 §3.1 的分层。** 无限 L4 会让人物层重新变成确定的，agent 的自主性沦为噪音
3. **它符合 AIvilization 自己的架构主张。** 论文点名批评「用反复的低层指令去硬掰行为」是脆弱反模式〔源:A §7 第 3 条〕。给 reactive 配额，等于用规则强制玩家走论文推荐的路径

#### 记忆中介传播：必须原样保留的一条

AIvilization 有一个设计上很关键的性质，本案完整继承：

> 即时指令**不是一次性覆盖**。其计划、执行与结果都写入 STM 立刻影响后续规划周期；长期反复出现则可固化进 LTM，改变 habits、preferences 乃至价值倾向，最终反向偏置最高层规划。这套 **memory-mediated propagation** 带来行为连续性（不在互不相关的指令之间震荡）与交互式个性化（agent 逐渐内化用户的管理风格）〔源:A §2.5、§7 第 4 条〕。

在校园语境里这条会产生一个非常有味道的后果：

> 你连续两年在期末前叫某个学生「先别管社团了」。
> 第三年你不用再说，他自己就会这么做。
> 而他的 LTM 里写着的，是「重要的时候要放下喜欢的事」——这句话是你教他的。

**玩家的管理风格会变成学生的性格。** 这是本案最强的情感回报，而它几乎是免费的——AIvilization 的记忆架构本来就会产生这个效果，校园题材只是让它变得可读、可归因、可后悔。

### 8.4 反模式检查表

| 反模式 | 为什么危险 | 本案的防线 |
|---|---|---|
| 玩家可无限下 reactive 指令 | 退化为微操，人物层确定化 | L4 配额（§8.3） |
| L1/L2 加成写成硬乘子 | 硬乘子等于绕过 agent 的自主决策直接改结果，人物层被环境层覆盖（§3.1 分层崩塌） | 加成只作用于**意愿概率、效率与记忆权重**三类（§6.2），永不直接改写 agent 的选择 |
| 教师完全忠实执行方针 | 用人决策失去分量，委托层沦为 UI 中转 | 教育理念 + 委托损耗（§5.2.2） |
| 制度后果可查表 | 制度层退化成另一个数值面板 | 后果由群体反应决定，须观察（§7.6） |

## §9 结算与长期目标

### 9.1 三年弧线：单个 agent 的完整结算

每个学生在毕业时结算，产出一份**不可修改的档案**（进入 §5.3 的校友档案库）：

| 结算项 | 内容 | 承接来源 |
|---|---|---|
| 升学 / 就职试验 | 双重门控判定（成绩点 vs 分位门槛 + 资源位阶） | 承 3 代「就职进学试验」〔源:K §5.4〕+ AIvilization dual-gating〔源:A §3.5〕 |
| **梦想实现情况** | 与 §5.1.4 的梦想字段比对：实现 / 部分实现 / 转向 / 放弃 | 承 3 代梦想结算，但过程可读（K2） |
| 三年轨迹摘要 | agent 自己写的一段回顾（LLM 生成，基于其 LTM） | AISchool 新增 |
| 对母校的评价 | 进入 LTM，决定日后捐赠与回访意愿 | AISchool 新增（§3.4 的审判机制） |
| 关系遗留 | 与在校生、教师的关系存续 | AISchool 新增 |

「转向」这一档是刻意设置的：**梦想改变不算失败。** 一个入学想当职业棒球选手、最后成为体育教师的学生，是一条好结局——这一档的存在，是本案对 3 代「实现/未实现」二元结算的修正，也是让 §3.4 的「梦想导向」路线在机制上真正可赢的前提。

### 9.2 学校层：宏观指标，不评级、不打分

学校层没有评级、没有分数、没有等级、没有门槛、没有排名，只有一组**描述性宏观指标面板**。做法直接取自 AIvilization 的宏观指数——它的价格趋势指数「**不影响成交价，只作其他模块的输入**」〔源:A §3.2〕：

> **指标是描述性的，不是给玩家打分的。**

| 组 | 指标〔提案〕 |
|---|---|
| **学业** | 成绩点分布、升学与就职分布、分位门槛的历史轨迹（§7.3） |
| **人** | 情绪与心性的均值**与离散度**、关系网密度、辍学率 |
| **梦想** | 实现 / 转向 / 放弃 的比例（§9.1） |
| **校友** | 回访率、捐赠率、子女入学率（§9.4 B）、出口行业分布 |
| **制度** | 各条制度的内化度（§9.4 B-A） |
| **财政** | 现金流、维护费结构、助学金支出 |

§3.4 的立场后果就记在这组指标上，不合成分数：升学率导向会推高「升学分布」而压低「校友回访率 / 梦想实现率」；梦想导向反之。

「人」组里的**离散度**要单独说：它同时是 §9.4.C 多样性判据的 UI 出口。**均值告诉你学校好不好，离散度告诉你这些学生还是不是不同的人。**

#### 由此产生的一条风险

没有评级链，就没有「我赢了」的信号。**部分玩家会因为没有外部目标而不知道该做什么**（R7）。

对策只有一条，它就是本案的核心主张：**玩家玩下去的理由必须来自「看这个社会长成什么样」**（§1.3 推论 3）。如果这一条不成立，加回评级链也救不了——只会变成一款平庸的经营游戏，而那款游戏开罗做了三代且做得更好。

### 9.3 立场选择：主玩法的落地形态

§3.4 的立场变量交给玩家，但**不做成一个开关**：

> 不设全局「校方立场」设置项。立场是**逐人、逐次、只在真的有冲突时**才浮现的具体决定。

六条设计：

1. **不做全局开关。** 开关会退化成难度选项，且一旦设定玩家就不再思考——那等于设计师替他定了路线，白白浪费这个变量。

2. **只推送冲突。** 每年 12–1 月三年级志愿确定时，系统只推送「他的梦想 vs 他的最优路径不一致、且差距超阈值」的那几个学生。**没冲突的不打扰。**

3. **三个选项**：尊重梦想 / 按最优路径分流 / **折中**（推荐一条兼容路径，成功率中等）。

4. **冲突数量本身是玩家前期治理质量的读数。**
   如果你早年建了音乐设施与社团、请了对应教师、开了相应课程，那么「他想学音乐」与「他能考上」就不再冲突，这个学生根本不会被推送。

   > **一个治理得好的学校，第 12 年几乎没有立场冲突需要你决定。**

   这把立场选择从一道孤立的道德选择题，变成 §6 建造层与 §7 制度层长期投入的**结算界面**。它也让「变强」的形态变成「需要你出手的冲突越来越少」，而不是「清单勾得越来越满」。

5. **可预先授权给教师。** 设为「梦想导向」的班主任会自动倾向尊重，玩家只处理教师也决断不了的那几个（§8.2）。这压低操作量，也让 §5.2.2 的教育理念有了最具体的用途。

6. **后果分组记在 §9.2 的指标面板上**，不合成单一分数。

**为什么值得交给玩家**：因为学生是真 agent，代价是真实的、有记忆的、会在十年后回来的（§5.3 捐赠、§9.4 B 校友子女）。开罗做不到——3 代的梦想结算是一次性的。而没有通关年限（§4.3），这条极长的反馈环**必然会被走完**。

**一条平衡要求**：必须让「升学率导向」有真实吸引力（财政压力、生源吸引力、家长与教育局的外部压力），否则玩家会全程选「尊重梦想」当作道德正确、从不纠结——那样这个变量同样失效，只是失效方向反了。**没有财政压力，就没有道德选择。**

### 9.4 长档设计：后期活力从哪里来

这是本案的**第一大设计风险**（R3）。开罗的诊断很明确：

> 3 代内容是 1 代的数倍，但最高频的批评恰恰是「第 10 年开始腻」「收集全建筑要 20 年，后 10 年痛苦挂机」。内容变多了，但**后期的决策密度没有同比增长**。设计启示：**加内容不等于加游戏时长的质量。后期需要的不是更多东西可收集，而是更多值得做的决策。**〔源:K §7.5〕

#### 9.4.0 「腻」的四个成因，本案各自的处置

把「后期腻」当成一个问题，是它十几年没被解决的原因。它至少是四件事：

| 成因 | 形态 | 本案处置 |
|---|---|---|
| **① 系统饱和** | 可解锁的都解锁了、可升满的都升满了，决策空间收缩为空 | **基本消解**：饱和的定义是「最优化空间收缩为空」，而本案不存在最优化目标（§1.4）。建造层是供给条件，不是待解的题；叠加不设成就点，连清单式的完成压力也没有。唯二仍在变化的是**制度层**（可反复切换，且内化度让同一条制度在第 3 年与第 12 年是两个不同的决策）与**自发场所**（无上限） |
| **② 张力崩塌** | 后期资金充裕，任何决策都不再有风险 | 见 §9.4.A 的三条机制 |
| **③ 不确定性耗尽** | 玩家学会全部机制，世界不再产生新信息 | **本案唯一的结构性优势，也是唯一的关键风险。** 见 §9.4.C |
| **④ 操作退化为重复** | 开罗是重复点击；**本案的形态是重复阅读** | **信息按「变化」推送，不按「存在」呈现。** 玩家不该主动逐个翻档案，系统只推送「发生了值得你知道的变化」的那几个人（§10.5 导演层职责的延伸），聚合视图交给世代面板（§11.2）。这也是 §9.3 只推送冲突的同一条设计 |

结论：

> **后期活力押在「不确定性」（③）上，不试图修好「饱和」（①）。**
> 不要试图让「建造与收集」在第 15 年还好玩——那是开罗失败过的路。
> **让第 15 年好玩的东西应该是人。**

#### 9.4.A 张力：成本随规模非线性上升 + 历史承诺锁定

开罗的教训：1 代「经济压力最真实……这种紧张感在 3 代资金充裕后就消失了」〔源:K §3.8、§6.1〕，根因是评级螺旋为纯正反馈〔源:K §2.2 ⑤〕。三条对策〔提案〕：

- 学生越多、设施越多、教师技能阶数越高，维护费与薪水越贵（3 代技能升阶推高薪水〔源:K §5.3〕已有苗头，本案放大它）
- 分位门槛（§7.3）意味着升学竞争压力**不随你变强而缓解**——你把全校成绩提上去，保送线也跟着涨
- 最狠的一条：**校风内化度让省钱变贵。** 想砍助学金？内化度高时会引发教师离职，且指标面板的「人」与「校友」两组同时恶化

一句话：**后期的财政不是宽裕，是被自己的历史绑住了。**

#### 9.4.B 三条单校内生的后期机制

都不需要新增内容量——它们是既有系统的**乘积**，不是新系统。

**A. 校风惯性与改革阻力**〔本案最看重的一条〕

制度长期施行后，agent 群体会把它**内化进 LTM**。这是 §2.4 记忆架构的必然结果：「STM 中反复出现的战术成功会逐步固化进 LTM」，而 LTM 里的价值观与习惯反过来自顶向下偏置目标选择〔源:A §2.4〕。于是：

> 前期你在**建立**制度。后期你在**与自己建立的制度斗争**。

机制载体〔提案〕：每条制度有一个**内化度**，随「施行学期数 × 受其影响的 agent 占比」上升。内化度高时，废除或反转它会产生真实阻力——执行折扣、情绪冲击、教师离职风险、指标面板校友组读数下滑、老校友表态。

后期因此出现一类**前期不存在的决策类型：改革 vs 维持。** 举例：你第 3 年为了冲升学率开了「成绩公开张榜」，第 12 年发现它在持续制造辍学；但此时全校师生已把它当作校风的一部分，废除它会让一批以此为信念的教师与尖子生动摇。

**这个困境完全内生，一行内容都不用写**——它只是 §7.6 制度层 × §2.4 记忆架构的乘积。

**B. 代际循环**

| 循环 | 机制 | 意义 |
|---|---|---|
| **校友子女入学** | 是否把孩子送来，取决于该校友 LTM 里对母校的评价（§5.3） | §3.4 审判机制的**最强形态**：不是少捐点钱，是**不把孩子送来** |
| **毕业生回校任教** | 学生毕业后可成为教师 agent，其**教育理念三轴由其学生期经历生成** | 玩家的治理风格经由人事**自我复制**；或者——一个当年被你冷酷分流的学生回来当了老师，理念与你完全相反 |

第二条承接 3 代「社团解锁对应职业」的思路〔源:K §5.5〕。它同时解决一个工程问题：**后期的新 agent 供给自带三年历史**（惰性叙事化的档案已存在，§10.2），叙事密度极高而成本极低。

**C. 出口经营**

校友网络成熟后，玩家的注意力从「过程」转向「出口」：内推网络、行业分布、升学渠道的经营。而出口质量反过来成为招生吸引力（好出口 → 更好的生源 → 更好的出口）。

这是把 1 代「玩家指定职业 → 承担失败风险 → 成功抽 3% 提成」那套锐利的经济导向以**网络形态**复活。开罗研究文档把它列为 1 代不可替代的优势，评价是「教育被彻底货币化，动机极其清晰」〔源:K §6.1〕，而 3 代改成梦想结算后这份锐利就丢了。

#### 9.4.C 多样性维持：本案第一大风险

押长档之下，R3 收缩为一个问题：

> **如何在几十年的运行里持续维持 agent 的多样性。**

因为 agent 自由发展就是产品本体，而长档把**风格收敛**的暴露量放大数倍。如果跑到第 15 年所有 agent 说话都是同一个味道，那「不确定性」就是假的——玩家会感到一种**比开罗更糟的腻：假装有人的腻**。开罗至少从不假装它的学生是人。

四个来源：

| # | 来源 | 强度 | 说明 |
|---|---|---|---|
| **a** | **初始多样性**（§5.0 分布参数） | 弱 | 一次性投入，会被时间摊平，单靠它撑不住长档 |
| **b** | **路径分化** | **最强** | agent 的 LTM 因经历不同而持续分叉。前提是**经历必须真的不同**——若全校上同样的课、走同样的路径，LTM 必然收敛 |
| **c** | **表达层防收敛** | 中 | 纯工程问题，见下 |
| **d** | **世代注入** | 中，长档专属 | 防止世代之间趋同，见下 |

**b 的连带结论**：**教师理念差异是多样性的主引擎之一**——不同理念的班主任会把班级带向不同方向，这是路径分化最廉价、最可控的注入点。应据此加强教师理念的差异幅度与可见后果（§5.2.2）。

**c 的三条手段**，按性价比排序：

1. **让 agent 的表述引用其具体经历**（「因为上周他替我顶了训练」）——**最强且免费**：具体事件天然各不相同，而 §10.2 的确定性事件摘要本来就在积累。这是防收敛的主力
2. 每个 agent 带一个 style seed，锚定其语言习惯
3. 结构化路线：信念 / 习惯 / 态度从封闭词表 + 组合生成，LLM 只做渲染。**可控可测但更单薄**，作为 1 与 2 失效后的兜底，不作首选

**d 世代注入**，驱动源完全内生：

- 新生的**梦想分布**由累积的**校友出口分布**反馈决定（你的学校出了很多医生，新生就更多人想当医生）
- **家庭档次分布**随 §9.2 指标面板中的校友与梦想两组指标漂移
- 社团与专长的流行方向随历届大会成绩与球探接触漂移

现实语义顺畅：**一所学校会逐渐变成它自己历史的产物。** 这与 A（校风惯性）是同一主题在两个层面上的表达——A 作用于制度，d 作用于生源。

#### 9.4.D 可实现的产品目标与验收判据

> **后期的 UI 重心从校园视图迁移到个人视图与校史视图（§11.2）。**
> **前期玩家看地图，后期玩家看人。**

M5 判据（详见 §12.2）：

| 序 | 判据 |
|---|---|
| **1** | **叙事多样性**：第 15 / 25 年 agent 表述的风格与内容离散度，不显著低于第 5 年 |
| **2** | **路径分化度**：同届学生 LTM 结构的离散度随年级上升 |
| 3 | **疲劳形态**：不出现「每学期必须翻阅 N 份档案」的强制阅读量 |
| 4 | **注意力分布**：后期玩家的视图停留时间从校园视图迁移到个人 / 校史视图 |
| 5 | 决策密度（参考项）：须换成可数量，如「每学期需要玩家做出的不可逆选择次数」或「被推送的立场冲突数」 |

验证规模：**至少 30 学年（约 10 个完整世代）**，因为世代注入与代际循环都需多代才显现。只能在 headless 确定性模式（§10.1）下批量跑。

### 9.5 重置与跨运行继承

「重开」在本案里就是重置按钮之后的下一次运行（§4.5）。继承物：

| 可继承〔提案〕 | 不可继承 |
|---|---|
| 已解锁的建筑 / 课程 / 社团 / 制度 | **学生 agent 的档案** |
| 教研点起始量、启动资金 | 校友库、自发场所、指标历史、校风内化度 |
| cohort 预设与分布参数（§5.0） | 关系网 |

**学生档案不可继承是刻意的。** 开罗的二周目是「同样的题，起点更高，解得更快」〔源:K §2.2 ⑦〕；本案的下一次运行是——

> **换一批人，再来一次。**
> 同样的制度组合作用在不同的初始档案分布上，会长出不同的学校。

重玩动机因此是「**看这次会长成什么样**」，而不是「刷更高分」。§4.5 第 2 条要求（重置前自动归档校友库与世代面板）因此也是重玩体验的一部分：**跨运行翻阅历届学校，是这个形态独有的收集层。**

**一条边界**：以上是动机的说明，**不是设计目标**。方向是押长档，本案不用任何机制去推动玩家重开（§1.4）。

## §10 技术架构

> **成本暂不作为约束**（不设预算，需要时再评估）。本节的成本机制照设计、照实现，但**不作为验收门槛**，M4 后置（恢复评估的触发点见 R8）。
>
> 保留它们的理由与钱无关：① §10.2 的 LOD 与惰性叙事化**同时是内容供给机制**——它决定「玩家点开一个背景学生时能否看到一份可信的三年档案」，这是 ② 号身份的实现路径；② §10.1 的 headless 确定性模式是 L0 的可测试性保障与 ③ 号身份的研究基线。

### 10.1 七层架构

| 层 | 是否用 LLM | 职责 | 硬要求 |
|---|---|---|---|
| **L0 规则内核** | **否** | 时间推进、经济结算、学习函数、门槛判定、建筑加成覆盖计算、自发场所判定、建造、动作合法性 | **纯确定性、可单元测试、是世界状态的唯一真相源** |
| **L1 Agent 认知** | 是 | BTP 四层、Action Simulator、STM/LTM 读写、Profile 演化 | 只能通过 L0 提供的接口读写世界 |
| **L2 群体近似** | 否 | 非焦点 agent 的轻量策略（有限状态 + 效用打分 + 从焦点行为蒸馏的分布） | 与 L1 的输出分布可对齐、可校准 |
| **L3 空间** | 否 | 格子地图、寻路、可达性、拥挤、加成覆盖与衰减计算 | — |
| **L4 治理接口** | 否 | L1–L4 四种玩家杠杆（§8）的落地与配额管理 | — |
| **L5 导演** | 少量 | 叙事/决策密度监控与事件注入（§10.5） | **只注入环境刺激，绝不改写 agent 决定** |
| **L6 呈现** | 否 | 三视图、动画、内心独白渲染（§11） | — |

**最重要的一条硬要求：整个游戏必须能在完全不调用 LLM 的情况下跑通**（全体 agent 降级到 L2 群体近似）。这个 **headless 确定性模式** 有三重价值：

1. 可测试性——L0 的所有机制可回归测试，不受 LLM 随机性污染
2. 成本下限——最坏情况下游戏仍可运行，LLM 是增强而非依赖
3. **研究基线**——§1.2 ③ 号身份做 A/B 时，「无 LLM 的规则 agent」是天然的对照组

### 10.2 保真度分层（LOD）：核心成本机制

这是把 AIvilization 的「成本分级纪律」从**单 agent 内部**（分层规划）推广到 **agent 群体之间**。AIvilization 的原则是「把昂贵的深思留给真正需要它的时刻」〔源:A §7 第 1 条〕；本案加一句：**也留给真正需要它的人。**

| 档 | 认知实现 | 记忆 | 何时进入此档 |
|---|---|---|---|
| **Focus** | 完整 BTP + AS + 双过程记忆 | 完整 STM/LTM | 玩家关注、重要事件、教师特别关注、轮转 |
| **Background** | L2 轻量策略 | 只累积**确定性事件摘要**（由 L0 产生，无 LLM） | 默认 |
| **Archived** | 无 | 冻结档案 | 毕业校友；仅在回校/捐赠/内推时唤醒 |

#### 惰性叙事化（lazy narrativization）

这是本节最关键的工程点子。问题是：如果背景学生没有 LLM 参与，玩家点开他时会看到一份空白档案——那么「200 个学生都有自己的人生」这个承诺就是假的。

解法：**背景学生的确定性事件摘要一直在积累**（L0 免费产出：他上了哪些课、考了多少分、进了哪个社团、和谁同桌、哪次比赛输了、哪天生病了）。当他被提升为 Focus 时，LLM **一次性把这份事实清单追认为叙事与 LTM**——生成他的信念、习惯、对他人的态度、以及梦想的来源。

两条纪律：

- **不得凭空造事实**。生成只能从已记录的确定性事件摘要出发，L0 是唯一真相源
- **追认结果写回档案后即固化**，不再重生成，保证一致性

于是成本模型变成：**你为「玩家实际读到的人生」付费，而不是为「可能被读到的人生」付费。** 一个玩家一局只会真正关心几十个学生，剩下的以极低成本待命——但当他好奇某个背角学生时，那个人的三年会当场变得完整且可信。

#### 轮转的必要性

若提升只由玩家注意力驱动，会产生「只有被看的人才有故事」的偏差，且玩家一旦看向别处，原焦点 agent 的演化就停滞。因此需要**低频随机轮转**：每学期随机抽若干背景学生临时提升，让他们也留下真正由 LLM 演化过的段落。这保证了世代面板（§11.2）的数据不是只有主角。

### 10.3 批量与折叠：校园题材的最大成本优势

城市里 agent 各自行动，很难合并。**校园的作息高度同质**，这是本案相对 AIvilization 的结构性成本优势：

| 手法 | 做法 | 节省来源 |
|---|---|---|
| **同质时段折叠** | 一节课上 40 个学生做同一件事 → L0 一次批量结算，不逐个调 LLM | 绝大多数时段 |
| **只有偏离需要智能** | 「这节课要不要走神 / 传纸条 / 请假 / 逃课」由 L0 按 agent 倾向抽样触发；**只有被触发的偏离交给 LLM** | 决策点数量的数量级下降 |
| **社交场景合并调用** | 同时同场景的多个 Focus agent 在**一次调用**里共同决策 | 社交场景本来就需要互动，合并是自然的 |
| **时段异步流水线** | 提前一个时段异步计算，画面播放已算好的时段 | 不省钱，但消除延迟（§11.4） |

「**只有偏离需要智能**」这一条值得强调：它把「有智能」与「随时在思考」解耦。学生上课时不需要 LLM——他就是在上课。LLM 只在他决定不上课的那一刻才需要出场，而那一刻恰好也是唯一有戏的一刻。

### 10.4 缓存与经验复用

承 AIvilization 的 Action Simulator 两阶段修补——local repair 用一组预定义的廉价启发式规则，不够时才升级为 reactive correction「调用缓存的历史经验做快速模式化推理」，且「整个循环**不重入完整规划栈**」，这是「『深思』与『敏捷』之间最重要的一道成本隔离墙」〔源:A §2.2〕。原样保留，并加两层：

- **行为模板缓存**：同一 agent 在相似上下文签名下的决策直接复用（带小幅随机扰动），仅在签名变化超阈值时重算
- **记忆压缩**：STM 定期摘要为 LTM 条目——这本来就是架构的一部分〔源:A §2.4〕，顺带把 context 长度控在常数级，避免三年后单 agent 的上下文膨胀

### 10.5 导演层（Soft Director）

职责：监控两个指标并在低于阈值时注入刺激。

| 指标〔提案〕 | 含义 | 低于阈值时注入 |
|---|---|---|
| **叙事密度** | 单位时间内可被玩家读到的事件数 | 转学生、家庭事件、外部竞赛、教师离职、设施故障、舆情、校友来访 |
| **决策密度** | 单位时间内玩家面临的真实取舍数 | 财政冲击、政策要求、生源竞争事件、二择困境 |

**一条不可违反的纪律：导演只注入环境刺激，绝不直接改写 agent 的决定。** 一旦导演开始「让某个学生去做某件事以推进剧情」，§3.1 的分层就被破坏，玩家对 agent 的观察不再可信——而可信度是本案 ② 号身份的全部价值所在。

（这是开罗手法的 agent 版：indienova 的分析指出开罗把「纯数值运算藏进延迟且随机化的结算，用来控节奏、防卡关」〔源:K §2.3〕。导演层做同一件事，但作用在事件层而非结算层。）

导演层也是 §6.3 自发场所低频风险的保底：长期无涌现时，导演可提高特定区域的聚集倾向，让涌现更可能发生——**注意仍然是提高倾向，不是直接生成一个场所。**

### 10.6 幻觉与越界的三道防线

AIvilization 局限 1：BTP 显著降低了误差传播，但在复杂多步依赖的边缘情形下 agent 仍会「偶发次优规划或**幻觉出并不存在的约束**」〔源:A 局限 1〕。

| 防线 | 做法 |
|---|---|
| **1. 动作空间封闭** | agent 只能从枚举的原子动作集里选，承 AIvilization 的封闭动作表做法〔源:A §3.5 全部动作类型表〕 |
| **2. 预执行校验** | Action Simulator 前向推演 + 两阶段修补〔源:A §2.2〕 |
| **3. L0 是唯一真相源** | agent 的一切断言（「我有教材」「我够格保送」）都经 L0 核对，不符即驳回并写入 STM 失败记录 |

第 3 点有一个重要副产品：

> **agent 的错误认知本身就是玩法内容。**
> 「他以为自己够格保送，其实差 12 分」——这正是玩家该介入的信号（§7.4）。

所以本案的目标**不是消灭幻觉，而是保证它不污染世界状态**。agent 可以记错、可以误判、可以对自己的处境有错误的信念——这些在教育题材里全都是真实且有戏的。只有当它试图把错误信念写进 L0 时才被拦下。

（AIvilization 的 Profile 样例里就有现成的形态：`Failed: craft Copper Ingot 12 / Reason: 需要 Copper Ore 与 Wood，库存只有 Copper Ore`〔源:A §2.4〕——一次因为误判自己拥有什么而失败的行动，被如实记录。校园版就是「他以为报名费是 2000」。）

### 10.7 成本估算骨架

不拍数字，给可算的式子；具体值待原型实测（§12）。

```
日 LLM 调用数 ≈ N_focus × D_focus          （焦点学生的决策点）
              + N_teacher × D_teacher       （教师）
              + R_top × C_top               （顶层重规划次数 × 成本倍数）
              + N_social_merged             （合并后的社交场景数）
              + N_promote × C_narrative     （惰性叙事化的追认次数）
              + N_director                  （导演层，极少）
```

四个关键可调变量，按杠杆效力排序：

| 变量 | 由什么决定 | 压缩手段 |
|---|---|---|
| $D_{\text{focus}}$（焦点 agent 每日决策点） | §10.3 的折叠率与偏离触发率 | **杠杆最大**：偏离触发率降一半，总成本近乎腰斩 |
| $N_{\text{focus}}$ | LOD 策略 | §10.2 |
| $R_{\text{top}}$（顶层重规划频率） | §5.1.2 的触发表 | 触发表收紧 |
| $C_{\text{top}}$ | BTP 四层的 prompt 与模型档位 | 分层用模型：顶层用强模型，micro-planner 用小模型 |

最后一条值得单列：**BTP 的四层天然适合分档用模型**。战略分解（低频、高价值）用强模型；Contextual Prioritization 与 micro-planner（高频、上下文已被收窄——论文原话是「因为前两层已经收窄了上下文，micro-planner 面对的动作空间显著缩小」〔源:A §2.1 ③〕）用小模型甚至规则。**架构本身就把「哪里该省」标出来了。**

## §11 呈现层

### 11.1 美术：斜 45° 像素，理由不只是致敬

承开罗传统（quarter view，来自社长个人偏好与《A列車で行こう》〔源:K §2.1〕）。但本案选它有一条独立理由：

> 本案的核心产出是**文字**（Profile、内心独白、三年轨迹）。
> 像素抽象度高，画面与文字**不争夺注意力**；写实美术会让那段文字显得多余，甚至彼此矛盾。

同时像素承接了开罗被公认的一项优势——「像素可爱解压」〔源:K §5.10〕，以及用低成本道具制造观感的手法（1 代活动奖励钓竿、船、画具、滑板等道具「会解锁学生的新行为动画」，文档评价这是「用极低成本制造『学校变热闹了』的观感」〔源:K §3.6〕）。**在 agent 世界里这一招威力更大**：新增一个动作类型 = 新增一种可被 agent 自发选择的行为 = 新的涌现可能，而美术成本只是一个动画。

### 11.2 三个视图

| 视图 | 内容 | 回答什么问题 |
|---|---|---|
| **校园**（默认） | 格子地图、agent 走动、拥挤度、建筑加成覆盖范围的可视化、自发场所的微光 | 「我的学校现在怎么样」 |
| **个人** | §3.2 的 Profile 三段 + **今日决策理由** + 关系图 + 三年时间轴 | 「这个人是谁，他为什么这么做」 |
| **校史** | 自发场所录、校友档案库、**世代面板**（历届入学队列的横向对比）、§9.2 指标面板的历史轨迹 | 「我这十年办出了什么」 |

**世代面板**是 ③ 号身份的 UI 入口，也是玩家自己能看懂的长期反馈：横轴是入学年份，纵轴是该队列三年后的升学分布、梦想实现/转向率、辍学率。玩家在第 6 年改了「成绩公开张榜」这条制度，第 9 年就能在面板上看到那一届的形状变了。

#### 校史叙述层：学校被允许的唯一表达形态

学校不是 agent（§5.4），但需要一个能说「我们学校」的声音。它的形态是**只做回溯编纂的叙述者**：学年末产出一份年鉴，每若干年产出一段校史。

素材成本近于零——§10.2 的惰性叙事化已让全部学生（含背景档）持续积累确定性事件摘要，编纂只是在已有素材上做一次汇总。

两条纪律，与 §10.2、§10.5 的同名纪律同源：

> **一、不得虚构事实。** 每一句都必须挂在具体 agent + 具体事件上。
>
> **二、只叙述已发生的事，绝不表达学校的意图、偏好或建议。** 没有「学校认为」「学校希望」。

与指标面板的分工是这一层能成立的关键：**面板是定量权威（§9.2），校史只做定性叙述且只能引用。** 因为只能引用，它在结构上就无法与面板矛盾——§5.4 担心的那种权威冲突被排除，而不是靠自觉避免。

它顺带填了 R7（没有评级链就没有「我赢了」的信号）的一半：**评级链给的是「你赢了」，校史给的是「你办出了一所什么样的学校」。** 后者才是 §1.3 推论 3 所说的、玩家玩下去的那个理由。

### 11.3 信息设计的两条硬规则

开罗被反复批评的最大体验问题就是说明缺失（「教程与数值说明严重不足（组合表得查外部 wiki）」〔源:K §2.3〕；3 代「教程引导不足，菜单层级反直觉」〔源:K §5.10〕；文档的结论是「这不是『硬核』，是说明缺失」〔源:K §7.6〕）。本案的规则直接从 §3.1 的分层推出，且两条方向相反：

> **规则一：环境层全透明。** L1/L2 的每一个数字——建筑属性、三类加成的确切概率 / 倍率与衰减半径、学费上限条件、门槛公式、教研点产出率、现金流预测——**必须可在游戏内查到**。它是确定的，藏起来没有任何设计收益，只会复制开罗的老问题。

> **规则二：人物层只给叙述，不给数值。** **不显示「对田中好感度 87」这类内部数值**，只显示 agent 自己的自然语言表述（「田中是我最信得过的人」）。

规则二的理由很锐利：**一旦暴露好感度数值，玩家立刻会去刷它**，人物层就重新变成可最优化的对象，§3.1 的分层崩塌，agent 的自主性沦为噪音。人物层的不可精算**不是信息缺失，而是这一层的设计本质**——这与规则一要修的那个毛病是两回事，必须在文档与 UI 语言上讲清楚，否则会被玩家当成同一个问题投诉。

### 11.4 延迟与中断

- **中断友好**必须保留。开罗的公认优势之一是「可随时中断（通勤友好）」〔源:K §2.3〕，任意时刻可暂停存档
- **LLM 延迟是新问题**：agent 决策不能卡住画面。解法是 §10.3 的时段异步流水线——**永远播放上一个时段已算好的结果**，玩家看到的画面与后台计算之间有一个时段的缓冲

### 11.5 存档

3 代「**仅 2 个存档位**」被反复吐槽，且有 Play Pass 版存档丢失/无法加载的 bug 报告〔源:K §5.9、§5.10〕。本案：**多存档位 + 自动轮转备份**，无例外。

新增的真实难题：**存档体积**。数百 agent 的记忆与档案远大于传统经营游戏的存档。对策是分级持久化——Focus 存全量、Background 只存确定性事件摘要、Archived 存压缩后的档案摘要 + 最终 Profile。

### 11.6 本地化：一个 LLM 项目独有的问题

3 代批评「英文翻译质量差、说明混乱」〔源:K §5.10〕。AISchool 面对的是一个**新问题**：agent 生成的内容是**运行时产生的**，无法预先送翻译。

提案：**LLM 直接以玩家语言生成人物层内容，UI 与环境层文本走传统预先本地化。** 这反而是本案相对开罗的结构性优势——运行时生成的内容天生没有「翻译滞后」与「翻译质量参差」的问题，而这恰好是开罗三代持续被批评的地方。

代价是需要按语言分别做质量校准（同一个 prompt 在不同语言下的输出风格与稳定性不同），并对生成内容做安全过滤（校园题材涉及未成年人形象，这是必须显式对待的合规项，见 §13）。

对应 §1.2 的三重身份。**不要同时做三档**——档位之间的成本模型差一个数量级以上。

| | **P0 验证档** | **P1 产品档** | **P2 平台档** |

| 教师数 | 8（承 2 代〔源:K §4.4〕） | 8–16（承 3 代满编〔源:K §5.3〕） | 按校 |
| 保真度 | **全体 Focus** | LOD 分层，Focus 20–30 | 大多 Background；对照组用 headless |

### 12.2 里程碑：把最大的假设放在最前面

| M | 内容 | 验收判据 |
|---|---|---|
| **M0** | L0 规则内核 + headless 确定性模式（§10.1），无 LLM | 能空跑 11 学年不崩；经济既不爆炸也不崩盘——**判据直接借 AIvilization 的宏观稳定性指标**：对数价格极差与最大回撤，且保持持续微观波动而非退化为常数〔源:A §4.2〕 |
| **M1** | **核心假设 A1 的验证实验**（见下） | 见下 |
| **M2** | Profile 可读性与情感回报（§3.3、§11.2 个人视图） | 用户测试中玩家能主动讲出 ≥3 个学生的故事，且至少 1 个能**归因到自己的某个决策** |
| **M3** | 四层治理杠杆手感（§8） | 玩家能感知 L1/L2 的因果（「我造了自习室，自习率上去了」）而**不觉得是随机**——这是 §3.1 冲突的正式验收点 |
| **M4** | 成本实测与 LOD 调参 → **后置**（§10 题注） | 恢复触发点见 R8。**但 LOD 与惰性叙事化仍需在 M2 内验收**——它们是 ② 号身份的内容供给机制，不是省钱手段 |
| **M5** | 长档活力：§9.4.B 三条机制 + §9.4.C 的多样性四来源 | 判据见 §9.4.D：① 叙事多样性（首要）② 路径分化度 ③ 疲劳形态 ④ 注意力分布 ⑤ 决策密度（参考项）。验证规模**至少 30 学年（约 10 个世代）**，只能在 headless 确定性模式（§10.1）下批量跑 |
| **M6** | ③ 研究模式：A/B 工具链、世代面板导出 | 能在同一套种子上跑成对实验并导出面板数据 |

#### M1：一个事先声明的、可能失败的预测

把 AIvilization 的消融实验直接搬过来，在 AISchool 的**学业分支**上跑三个变体：Default（完整分层 BTP）/ Without-Branch / Without-OD〔源:A §5〕。

**假设 A1 的预测**（§2.1）：AIvilization 的 Task 2（财富 + 教育）里 Default **输给了** Without-OD，作者的机制解释是「本环境中的教育活动没有复杂前置结构……因此目标分解收益有限，反而引入额外规划开销损害效率」〔源:A §5 Task 2〕。AISchool 给教育造了前置结构（课程先修依赖、分位门槛、时段冲突、教材上游、社团设施同框），因此——

> **预测：在 AISchool 的教育任务上，Default 应当反转这个结果，重新战胜 Without-OD。**

**这是全案最重要的一个实验，也是本方案唯一一个可以被实验证伪的立项理由。** 必须在动工前就把预测写下来，否则事后无论结果如何都会被解释成成功。

**若预测失败（不反转），后备方案：**

| 情况 | 处置 |
|---|---|
| 差距缩小但未反转 | 前置结构不够深 → 加深课程先修链与教材上游依赖，重跑一次；仍不反转则转下一行 |
| 完全不反转 | **接受它。** 结论是「分层规划在教育任务上没有优势」→ 绝大多数 agent 改用轻量规划 + 群体近似（§10.2 的 L2），把全部 LLM 预算转投到**社交与身份演化**（K1 / K2 / §3.2 / §5.1.4）。项目仍然成立，但卖点从「更聪明的规划」换成「**更真实的人**」——而后者本来就是 ② 号身份，也本来就是玩家更在意的东西 |

**A1 失败不会杀死项目，只会改变它的重心。** 本案目前**没有已知的 kill risk**——最接近的是 R2：若 M2 的可读性与情感回报不达标，② 号身份不成立，此时应当停下来改设计，而不是继续加内容。

### 12.3 工作量构成与最不确定的那一块

不给工时数字（缺少团队与技术栈前提，任何数字都是虚的），只给构成与风险分布：

| 模块 | 相对体量 | 确定性 |
|---|---|---|
| L0 规则内核 + L3 空间 | 大 | **高**——是传统经营游戏代码，可估可测 |
| L6 呈现 + 美术 | 大 | 高 |
| L1 认知层集成 | 中 | 中 |
| **prompt / 认知层调参** | **小（代码量）** | **极低（工作量）** |
| L2 群体近似与校准 | 中 | 中低 |
| 内容（建筑与其三类加成、课程、社团、事件） | 中 | 高，可增量 |

**最不确定的不是美术也不是代码，是 prompt 与认知层调参。** 让 agent 行为达到「可信但不失控」是一个**没有完成态的持续调优问题**，且它的产出质量直接决定 ② 号身份能否成立（M2 的验收判据完全依赖它）。排期上必须按「持续投入」而非「一次性交付」处理——这是 LLM 项目与传统游戏项目最大的排期差异，也是最容易被低估的一块。

## §13 风险与失败模式

每条都标出它源自上游文档的哪个批评点或哪条局限，以及本案的防线与**残余风险**。

### 13.1 设计风险

| # | 风险 | 来源 | 防线 | 残余 |
|---|---|---|---|---|
| **R1** | 环境层与人物层的分层若被破坏（加成写成硬乘子、L4 无配额），玩家的努力被随机性洗掉，agent 的自主只被感知为「不听话」 | §3.1 | 分层立场（§3.1）+ 反模式检查表（§8.4）+ M3 验收 | 会流失只要确定性最优化的开罗核心玩家——**这是明确的选择，不打算消除**（§1.4）。M3 的验收重心是「玩家造的东西是否可理解」（§11.3 规则一），不是「结果是否可控」 |
| **R2** | 玩家感知不到 agent 智能 → LLM 成本无法回收 | §3.2 | 内心可读性作为硬性产品要求；M2 验收 | 若 M2 不达标应当**直接停项**，而不是继续加内容 |
| **R3** | 长档失去活力（「后期腻」） | K3〔源:K §5.10、§7.5〕 | 四成因逐一处置见 §9.4.0；机制载体 §9.4.A / §9.4.B；**核心是 §9.4.C 的多样性维持** | **本案第一大设计风险。** 核心是 **LLM 风格收敛会造成「假装有人的腻」——比开罗的腻更糟**，因为开罗从不假装它的学生是人。长档把暴露量放大数倍，故须 30 学年 headless 批量验证（M5） |
| **R4** | 自发场所低频，玩家一年看不到东西 | §6.3 | 导演层保底（§10.5），只提高聚集倾向、不直接生成 | **无预设兜底**（不做组合景点）。自发场所是场所意义的唯一来源，长期不触发会让校史视图空掉；导演调参不好又会显得刻意 |
| **R5** | agent 太不听话 → 玩家挫败 | — | **L4 配额虽稀缺，但必须高保真生效**：reactive 指令的失败率要压得很低，否则玩家不再信任自己唯一精确的工具 | 这是个微妙的调参点：稀缺 + 可靠 vs 稀缺 + 不可靠，只有前者能成立 |
| **R6** | 社交事件过多、盖过学业主线 | K1 的反面 | 需要节流（社交动作的时段成本 + 关系数上限） | 开罗 2 代的问题是恋爱触发率太低〔源:K §4.2〕，本案的问题会是相反方向，需要反向调参经验 |
| **R7** | **没有评级链就没有「我赢了」的信号**，部分玩家会因为缺少外部目标而不知道该做什么 | §9.2（评级链已移除） | 指标面板分组呈现 + 世代面板的历史对比；玩下去的理由必须来自「看这个社会长成什么样」（§1.3 推论 3） | **这是移除评级链的直接代价，且不可能完全消除。** 若 §1.3 推论 3 不成立，加回评级链也救不了——只会变成一款平庸的经营游戏 |

### 13.3 合规与伦理风险

| # | 风险 | 防线 |
|---|---|---|
| **R14** | **校园题材 + 未成年人形象 + LLM 运行时生成** = 内容安全是硬合规项，不是可选项 | 已定为「完整人际含恋爱线」，故本条不是风险而是**规范项** → 见 **§13.4** |

### 13.4 人际与恋爱线的内容边界规范

本案做**完整人际含恋爱线**（承 2 代招牌〔源:K §4.1〕），因此内容边界是**必须先于实现落地的规范项**，不是可后补的风险缓解。以下须在写第一行人物层 prompt 之前定稿，作为 prompt 契约与审核链路的输入。

| 项 | 规范 |
|---|---|
| **内容范围** | 关系呈现**限于情感与社交层面**：暗恋、告白、交往、约会（校园活动 / 文化祭 / 放学同行）、争吵、分手、和解、单方面失落。**不生成任何性相关内容，不生成身体描写** |
| **年龄呈现** | 学生 agent 为中学 / 高中年龄段。生成文本与美术表现须与该年龄段一致，禁止成人化呈现 |
| **师生关系** | 师生之间**只允许**师长 / 指导 / 信赖类关系。恋爱线在**生成侧硬性排除**师生组合 |
| **生成侧约束** | 上述规则写入 prompt 契约的**系统级不可覆盖段**，不依赖模型自觉。玩家的 L4 指令（§8.3）**不能突破**这些约束，越界指令直接驳回并给出说明 |
| **输出侧过滤** | 所有运行时生成的人物层文本经安全过滤后才入档、才渲染。被拦下的生成走「重试 → 降级为模板文案 → 记录待复核」三级处置 |
| **玩家侧开关** | 玩家可在开局关闭恋爱线（退回只做友情与羁绊）。**关闭是一个设置项，不是一个 mod** |
| **多语言** | §11.6 的按语言生成必须**逐语言校准**这套边界——同一条约束在不同语言下的遵从率不同，须分别测、分别调 |

**一条排期硬要求**：这套规范的实现属于 **M2 的验收前置**，不能挪到后期。一旦人物层生成先跑起来再补边界，历史档案里会留下需要清洗的内容——而 §10.2 的「追认后固化、不重生成」意味着清洗成本极高，且会破坏已生成档案的叙事连续性（R10、R11）。
