# 复盘文档模板（Review Template）

生成复盘文档时严格套用本结构，逐节填写。缺输入的节**必须**写「因 `{项}` 未答/未载而降级」并说明影响，**严禁**留空或跳过。

计划值一律抄自报告与手册并注明来源位置；实际值一律标注「用户提供 + 时间」；结算字段缺失一律写 `null` 并标「不可核查」。

> **节号约定**：后续插入的节一律采用 `二之二`、`八之二` 这类「`X之二`」编号，`§一`–`§九` 的编号**一律不重编**。理由：[period-review.md](references/period-review.md) 的 `PA1` 读各份文档的 `§四`、`PA2` 读 `§五`、`PA5` 读 `§三`，重编号会同时打断周月聚合口径与已落盘历史文档的可读性。

```markdown
# {ETF名称}（{6位代码}）T+0 收盘复盘 · {date}

- **来源报告**：{reportPath}
- **来源手册**：{manualPath}（未提供时写「未提供，对照仅按报告委托单清单」）
- **计划态状态文件**：{statePath}（未提供时写「未提供」）
- **报告结论**：____（做 / 观望 / 停手 / 不适合做 T / 不适用本体系 / 当日不做 T）
- **复盘生成时刻**：____
- **已收盘判定**：____（守时判据第 ____ 行命中；依据 ____；追溯复盘时写出所取那一根日线的日期 ____）
- **未答项及其影响**：____（逐条写「未答项 → 降级的节」；无未答项写「无」）
- **数据完整度**：完整 / 部分缺失（缺失项：____）

> ⚠️ 本文档登记事实与差异，次日部分只出「观察项 + 阈值 + 情景 + 定性操作倾向」的**条件式前瞻**（§八之二），**不产出**次日的三态、`W`、`L`、买卖价位、委托单清单、轮次数字或金额。次日参数须由 `etf-t0-analysis` 重跑产出。
```
