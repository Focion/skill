# 周 / 月度周期复盘（Period Review）

本文件定义 `mode` 为 `week` 或 `month` 时的聚合流程：只读已落盘的单日复盘文档，把它们的差异归因、纪律核查与结算数据汇总成趋势视图。

**作用域上限（必须先读这一段）**：本文件**严禁**产出任何仓位、胜率或策略结论。周月样本量只有 15–25 轮，其胜率的标准误足以让排序完全反转，故周月指标一律只作**执行质量观察值**；仓位与停做判定一律以报告所载滚动窗口口径为准。本文件也**严禁**重新问询单日数据或重跑单日结算——单日事实以已落盘的复盘文档为唯一来源。

## 一、输入与窗口界定

| 项 | 口径 |
|---|---|
| 输入文件 | `{outputDir}` 内文件名**逐字匹配** `etf-t0-review-{symbol}-YYYY-MM-DD.md` 的全部单日复盘文档——日期段后**必须**紧跟 `.md`。**严禁**把 `-week.md` / `-month.md` / `.todo.md` 结尾的文件纳入：前两者是本流程自己的产物，读回来会把周月汇总当单日事实二次计入；后者只是待补清单 |
| `mode=week` 窗口 | 含 `date` 的那个自然周的全部交易日 |
| `mode=month` 窗口 | 含 `date` 的那个自然月的全部交易日 |
| 长期沉淀文件 | `{lessonsPath}`，只读不写——周月复盘**严禁**改动沉淀文件 |
| 产物文件名的日期段 | **必须**取窗口**起始交易日**，使同一窗口重跑覆盖同一文件，**严禁**用入参 `date` 原值（否则窗口内每跑一次就多一份） |

- `{symbol}` **必须**由入参直接给出：本流程不读分析报告，没有可继承 `symbol` 的来源，缺失时**严禁**用目录内任一文件名反推
- 窗口内**每一个**已落盘复盘文档都**必须**读入，**严禁**抽样或只取最近几份
- 窗口内**不晚于 `date`** 的交易日中没有对应复盘文档的，**必须**在首部逐日列出为缺口日，**严禁**把缺口日当作「未操作日」并入统计
- 窗口内**晚于 `date`** 的交易日（周中或月中跑时尚未到来的那几天）**必须**单独标为「窗口未走完」，**严禁**计入缺口日或分母——把还没发生的日子算成缺口会凭空压低覆盖度
- 窗口内一份复盘文档都读不到 → **必须**停止生成并按 SKILL 退出码表走「需人工决策」

## 二、聚合项（逐项汇总，每项写出分母）

每一项**必须**一并写出「计数」与「分母」，**严禁**只给比例。分母一律为窗口内**已有复盘文档的交易日数**，不含缺口日（`PA3` 与 `PA9` 例外，其分母见各自行内口径）。

| # | 聚合项 | 汇总口径 |
|---|---|---|
| PA1 | 差异类别分布 | 各份文档 §四 的 `DV1`–`DV7` 条目数逐类相加 |
| PA2 | 纪律违反分布 | 各份文档 §五 判为「否」的 `DA` 编号逐个计数，按次数降序排列 |
| PA3 | 纪律核查覆盖度 | 各份文档「适用项 M」之和 ÷ 各份**该文档自己所载总项数**之和——分母**必须**逐份读该文档写出的项数，**严禁**统一按当前版本的项数折算（旧文档的项数可能不同，统一折算会算出失真的覆盖度）。覆盖度低说明手册或结算字段长期缺载 |
| PA4 | 轮次使用 | 各日「实际已开轮次 / 本日可用轮次」逐日列出，并给窗口内已用轮次合计 |
| PA5 | 已实现盈亏 | 各日已实现盈亏的**元数**逐日列出并求和（取各份文档 §三 的逐轮净额合计）；任一日为 `null` 时合计**必须**标「不完整（缺 ____ 日）」。占总资金的**比例值严禁跨日相加**——各日分母是各日总资金，相加得出的数没有意义 |
| PA6 | 权益轨迹 | 各日 `account_equity` 逐日列出；`null` 的日子留空并标出，**严禁**插值 |
| PA7 | 风控可核查率 | 四档（口径 A 单日/单周、口径 B 单日/单周）各自「可核查」的天数 ÷ 分母 |
| PA8 | 样本增量 | 窗口内新增轮数，及窗口末日 `rounds_ledger` 长度与 `sample_n` |
| PA9 | 信号验证率 | 各份文档 `§二之二` 的信号计数行逐类相加（验证 / 失效 / 不可判 / 不适用），分母**必须**逐份读该文档自己所载的分母之和——**严禁**统一按当前版本的信号条数折算；并按 `SG` 编号列出判「失效」次数最多的那一条。**未含 `§二之二` 的旧文档必须标「该节缺载」并不并入 `PA9` 的分母**（与 `PA3` 同一原则），窗口内一份都不含该节时 `PA9` 整项标「不适用（窗口内无含该节的文档）」 |

- `PA5` 与 `PA6` 只做**登记与求和**，**严禁**据其算胜率、盈亏比或期望
- `PA2` 排在首位输出：本文件的用途是找出反复违反的那一条，**严禁**把盈亏排在纪律之前呈现

## 三、趋势判定（只判可机械判定的三条）

| # | 判据 | 结论 |
|---|---|---|
| PT1 | 某个 `DA` 编号在窗口内判为「否」的天数 ≥ 分母的一半 | 该项为**系统性违反**，**必须**在首部单独点名 |
| PT2 | `PA3` 覆盖度 < 50% | 判**核查长期空转**，**必须**写出缺载的是手册还是结算字段 |
| PT3 | `PA7` 中任一档可核查率 < 50% | 判该档**长期不可核查**，**必须**写出缺的是历史结算 state 还是用户答复项 |

- 三条之外**严禁**新增趋势判定：其余观察量（盈亏、轮次、权益）在周月尺度上都不足以支撑判定，只登记不判定
- `PT1`–`PT3` 判为成立时**严禁**给出参数调整方案——修法属于分析环节，本文件只指出事实

## 五、常见填写错误

```markdown
<!-- ✅ 正确：计数与分母同列，缺口日单独列出不并入分母 -->
- 窗口内交易日：5 日｜已有复盘文档：4 日｜缺口日：2026-08-06｜分母：4 日
| DA2 | 已开轮次未超本日可用轮次 | 3 / 4 | 08-03、08-04、08-07 |

<!-- ❌ 错误：只给比例，看不出分母，且把缺口日当作未操作日并入 -->
| DA2 | 已开轮次未超本日可用轮次 | 60% | — |

<!-- ❌ 错误：由周样本推出胜率并给仓位结论，越出本文件作用域 -->
本周 9 轮 6 胜，胜率 67%，下周可把 T 仓上限提回 15%
```
