# 盘后盘面核对（Market Recheck）

本文件定义收盘后取哪些行情事实、怎么取、取不到怎么标，以及用这些事实核对报告计划的哪几项。

**作用域上限（必须先读这一段）**：本文件只覆盖「取当日已收盘的一根行情记录」这一件事，只取 `开 / 高 / 低 / 收 / 量 / 额` 六个原值。ATR、放量阈值、振幅门槛、三态斜率、tick、申报单位、集合竞价时点等**一切口径与阈值一律取报告所载值**，本 skill **严禁**重算其中任何一项——重算等于在复盘环节悄悄换掉被复盘的标准。**对标基准（跟踪指数、宽基）与外盘读数不在本文件作用域**，取数与登记见 [board-signal-review.md](references/board-signal-review.md) §二；次日的观察项与取数见 [next-day-outlook.md](references/next-day-outlook.md) §四。

## 一、复盘时机守卫（先判复盘日已收盘，再取数）

复盘日可以是当前交易日，也可以是更早的交易日（补做前几日的复盘）。按下表逐级判定，**命中即定**：

| # | 判据 | 结论 |
|---|---|---|
| 0 | 复盘日早于当前交易日（追溯复盘） | 该日已收盘 → 进入 §二。第 ① 级（用户提供）**照常可用**（用户给的是该日读数）；落到第 ② 级时**必须**只走日线路径并取**日期 == 复盘日**的那一根，**严禁**用快照路径（快照永远返回最新交易日，不是复盘日） |
| 1 | 行情记录日期 == 复盘日 == 当前交易日，且报告载有收盘集合竞价结束时点、当前时刻晚于该时点 | 已收盘，进入 §二 取数 |
| 2 | 行情记录日期 == 复盘日 == 当前交易日，报告未载收盘时点 | **必须**向用户逐字确认「**今天是否已经收盘？**」；答"是"→ 已收盘并标「依据用户口述」；答"否"或不答 → 按第 4 行处置 |
| 3 | 复盘日 == 当前交易日，但取到的行情记录日期 < 复盘日 | 该日行情记录尚未生成 → 按第 4 行处置 |
| 4 | 复盘日未收盘 | **必须**停止结算数据产出并提示收盘后重跑，按 SKILL 退出码表走「需人工决策」 |
| 5 | 复盘日早于当前交易日，第 ① 级未提供，且日线中取不到日期 == 复盘日 的那一根 | **必须**停止结算数据产出并提示「该日无行情记录（休市或标的停牌），须改传交易日」，按 SKILL 退出码表走「需人工决策」 |

> 复盘日未收盘时**严禁**用盘中快照结算：盘中价不是收盘价，据其算出的 `account_equity` 会成为次日回撤口径 A 的错误基准，且该错误会沿每日续算一路传下去。
> 第 0 行与第 5 行分开的理由：追溯复盘失败有两种原因——**没收盘**与**那天没有行情**，前者的修法是等收盘、后者的修法是换日期，合并成一条会给出错误的修复提示。

## 二、两级取数降级链（逐级尝试，取到即止）

| 级 | 前提 | 做法 | 来源标注 |
|---|---|---|---|
| ① | 用户已答 `RV8` 或传入 `closeQuote` | **必须**直接采用用户所给六个原值 | 「用户提供 + 提供时间」 |
| ② | ① 未提供 | 经 `Bash` 用公开接口取**复盘日**已收盘记录（见 §2.1）；追溯复盘时**必须**只用日线路径 | 「接口名 + 取数时间戳 + 所取那一根的日期」 |
| ③ | 两级皆不可得 | **必须**把 §三 全部核对项标「不可判」，并按 SKILL 退出码表走「需人工决策」 | 标「数据缺失」 |

- 用户所给值与接口取到的值不一致时**必须**以用户所给值为准，并在文档的数据来源节写出两者差异值，**严禁**取平均或静默采信其一
- ② 级失败一次**必须**重试一次；重试仍失败按可重试故障处置，重试成功后照常进入 §三

### 2.1 接口（返回字段顺序以实际返回核对，严禁硬套下标）

```bash
# 盘后快照：返回值即最新交易日收盘值。{前缀} 取 sh 或 sz，按报告所载市场归属填
# 仅在「复盘日 == 当前交易日」时可用（§一 第 1、2 行）
curl -s --max-time 8 -H 'Referer: https://finance.sina.com.cn/' \
  'https://hq.sinajs.cn/list={前缀}{6位代码}' | iconv -f GBK -t UTF-8

# 日线：追溯复盘（§一 第 0 行）时的唯一路径。{secid前缀} 取 1. 或 0.，与上行市场归属一致
# {lmt} 取「当前交易日与复盘日相距的自然日数 + 5」并向上取整，取回后按日期字段挑出 == 复盘日 的那一根
curl -s --max-time 10 \
  'https://push2his.eastmoney.com/api/qt/stock/kline/get?secid={secid前缀}{6位代码}&klt=101&fqt=1&fields1=f1,f2&fields2=f51,f52,f53,f54,f55,f56,f57&end=20500101&lmt={lmt}'
```

- 解析前**必须**先打印一次原始返回并逐字段核对到 `开 / 高 / 低 / 收 / 量 / 额` 六项，**严禁**按记忆中的下标直接切分
- 两个接口的成交量单位不同（一为股、一为手），写入文档前**必须**统一到「股」并注明换算，**严禁**混用单位比对
- 成交额一律统一到「元」；报告所载日均成交额若以「亿」为单位，比对前**必须**写出换算过程，**严禁**跨单位直接相除

## 三、核对项（逐项写出实际值与判定，不得只打勾）

计划值一律抄自报告，实际值一律取 §二 所得，**严禁**在本节出现任何第三方来源的数值。

| # | 核对项 | 判据 | 用于 |
|---|---|---|---|
| M1 | 区间上沿是否被穿透 | 当日最高 > 报告所载区间上沿 → 穿透 | 判定报告区间当日是否仍成立 |
| M2 | 区间下沿是否被穿透 | 当日最低 < 报告所载区间下沿 → 穿透 | 同上 |
| M3 | 各委托单行触发价是否被触及 | 买向行：当日最低 ≤ 该行触发价 → 触及；卖向行：当日最高 ≥ 该行触发价 → 触及 | `DV1` 与 `DV2` 的客观判据（见 [reconcile.md](references/reconcile.md)） |
| M4 | 当日高低差容不容得下一轮 T | 当日最高 − 当日最低 ≥ 报告所载 `2W` → 容得下 | 判定「无信号」是价格没动还是计划差价过大 |
| M5 | 收盘价相对区间的位置 | 收盘价与报告所载上沿、下沿逐一比较，写出「上沿之上 / 区间内 / 下沿之下」 | 次日分析入参回执的事实项 |
| M6 | 当日成交额与近 20 日日均成交额之比 | 当日成交额 ÷ 报告所载**近 20 日日均成交额**（两者均统一到「元」后相除）；报告未载该值 → 本项标「不可判」 | 量能事实登记 |

> M3 的「触及」只判定**价格到过该点位**，**严禁**据其推出「该单本应成交」——限价单能否成交还取决于排队与挂单量。故 `DV2` 的证据除 M3 之外**必须**一并登记用户对未成交原因的说明。

> 本表的**判定结果**由 [board-signal-review.md](references/board-signal-review.md) §四 取用为 `SG1`–`SG6` 的信号有效性判据。该文件只引用本表的结论，**不**重新推导本表判据；本表的读数与判定一经写出**严禁**在别处改写。

## 四、缺失与失真的标注

| 情形 | 处置 |
|---|---|
| 六个原值中任一项缺失 | **必须**只标该项「数据缺失」，依赖该项的核对项标「不可判」，其余核对项照常判定，**严禁**因一项缺失整节跳过 |
| 报告未载区间上沿或下沿 | M1、M2、M4、M5 中依赖该值的项标「不可判」并写出缺的是报告哪一项，**严禁**由本 skill 外推区间 |
| 当日停牌 / 涨跌停封死 / 复牌首日 | **必须**照常登记取到的原值，并在本节标出该状态，**严禁**据失真读数判定 M3 的触及与否 |
