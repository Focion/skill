# 盘面与信号复盘（Board & Signal Review）

本文件定义当日盘面总结的两件事：**登记**标的相对对标基准的强弱与量能，**判定**报告所载信号在当日是否被验证。

**作用域上限（必须先读这一段）**：本文件只做「登记」与「判定」。三态判据、区间上下沿、目标差价 `W`、`2W`、放量倍数阈值、连亏停手线、ATR 等**一切口径与阈值一律取报告所载值**，本文件**严禁**重算或改写其中任何一项——在复盘环节重算等于悄悄换掉被复盘的标准。对标读数只用于**解释当日**，**严禁**据其推断次日；次日一律走 [next-day-outlook.md](references/next-day-outlook.md)。判为「失效」的信号**严禁**在本文件给出修正参数——修法属分析环节。

## 一、对标基准的确定（三层，逐层填满）

| 层 | 基准 | 取值来源 | 取不到时 |
|---|---|---|---|
| 跟踪指数 | 标的所跟踪的指数名称与代码 | 报告首部或标的基础信息节所载 | **必须**逐字问用户「**这只 ETF 跟踪的是哪个指数？给我指数名称和代码。**」；**严禁**由 6 位代码或 ETF 名称猜测跟踪指数 |
| 所属宽基 | 上证综指 `sh000001` / 深证成指 `sz399001` / 创业板指 `sz399006` / 科创50 `sh000688` 之一 | 按报告所载市场归属与上市板块判定 | **必须**回落为「上证综指 + 深证成指」双基准并标「宽基归属报告未载，取双基准」，**严禁**只取其一 |
| 板块归属 | 供次日前瞻路由用的板块名 | 拿上面已定的**跟踪指数名称**逐行比对 [next-day-outlook.md](references/next-day-outlook.md) §三 路由表的板块列，命中即定 | 标「板块未定」，路由按该表的未命中行处置 |

- 板块归属的判定表在 `next-day-outlook.md` §三，本文件**只引用不复写**
- 判定出的板块归属**必须**写入本节与次日前瞻节两处
- 两处所写的板块归属**必须**为同一个字面串
- 跟踪指数取不到时 `BM1` 标「不可判」，`BM2`（宽基）照常判定，**严禁**用宽基读数充当跟踪指数读数

## 二、三级取数降级链（逐级尝试，取到即止）

| 级 | 前提 | 做法 | 来源标注 |
|---|---|---|---|
| ① | 用户已答 `RV10` | **必须**直接采用用户所给读数 | 「用户提供 + 提供时间」 |
| ② | ① 未提供 | 经 `Bash` 按 §2.1 取数 | 「接口 key + 取数时间戳 + 所取那一根对应的交易日」 |
| ③ | 两级皆不可得 | **必须**只把该项标「不可读」，依赖它的登记项标「不可判」 | 标「数据缺失」 |

- 单项取不到**必须**只标该项，其余项照常判定，**严禁**因一项缺失整节跳过
- 用户所给值与接口值不一致时**必须**以用户所给值为准并写出两者差异，**严禁**取平均或静默采信其一
- ② 级失败一次**必须**重试一次；重试仍失败按 ③ 级处置，**严禁**为此中止整份复盘——盘面登记不可得不影响台账、差异归因与结算

### 2.1 A 股基准取数（外盘 key 表在 next-day-outlook.md §四，本节不复写）

```bash
# 大盘与跟踪指数：{key} 逐个填 sh000001 / sz399001 / sz399006 / sh000688 / 跟踪指数代码
curl -s --max-time 8 -H 'Referer: https://finance.sina.com.cn/' \
  'https://hq.sinajs.cn/list={key1},{key2}' | iconv -f GBK -t UTF-8
```

- 解析前**必须**先打印一次原始返回并逐字段核对到「昨收」与「收盘」两项，**严禁**按记忆中的下标直接切分
- **A 股指数的返回不含涨跌幅字段**，涨跌幅**必须**由 `(收盘 − 昨收) ÷ 昨收` 现场算出
- 昨收与收盘两个原值**必须**一并写入文档，**严禁**只写算出的百分比
- 跟踪指数代码由 §一 所定，**严禁**用 ETF 自身代码充当跟踪指数代码
- 涨跌幅一律写到小数点后两位；两个涨跌幅相减得到的差值单位写作 `pct`，**严禁**与百分比混写

## 三、相对强弱与量能登记（BM1–BM4，只登记不判优劣）

| # | 登记项 | 口径 | 必须写出 |
|---|---|---|---|
| BM1 | 标的 vs 跟踪指数 | 标的当日涨跌幅 − 跟踪指数当日涨跌幅 | 标的 `___%`（昨收 `___` / 收盘 `___`）、指数 `___%`（昨收 `___` / 收盘 `___`）、差 `___pct` → 强于 / 弱于 / 基本同步 |
| BM2 | 标的 vs 所属宽基 | 同上，宽基取 §一 所定；双基准时**必须**两行分列 | 同上 |
| BM3 | 量能分布 | **直接引用** [market-recheck.md](references/market-recheck.md#三核对项) `M6` 的倍数读数 | 「引用 `M6` = `___` 倍」；`M6` 标「不可判」时本项一并标「不可判」 |
| BM4 | 昨夜对标外盘背景 | 按 §一 所定板块，取 `next-day-outlook.md` §三 该板块领先指标的**最近一根已收**读数（即已经作用在当日盘面上的那一根） | 逐项：名称 / 收盘 / 涨跌幅 / **该读数对应的交易日** / 来源 |

- 「基本同步」的判据为 `|差| ≤ 0.10pct`（本文件为该判据的唯一出处）；差值为正判「强于」，为负判「弱于」
- `BM3` **严禁**重算成交额比值——`M6` 已算出，重算会得到与核对节不一致的两个数
- 本节**严禁**出现「强于大盘故次日可加轮次」这类推论：相对强弱只是当日事实登记，`BM1`–`BM4` 一律不得产出操作结论

> ⚠️ `BM4` 的用途是**解释当日**：它是已经作用在今日盘面上的那一根。**严禁**把 `BM4` 的读数搬进次日前瞻节当作「今夜」读数——那是把已生效的旧信息当成未来信息（`ETS14`）。两节的同名指标**必须**各自写出「对应交易日」，据此可一眼看出不是同一根。

## 四、信号有效性判定（SG1–SG6，逐项判「验证 / 失效 / 不可判 / 不适用」）

判据来源一律**引用** [market-recheck.md](references/market-recheck.md#三核对项) 的 `M` 编号**判定结果**，本节**严禁**重新推导 `M` 的判据、**严禁**改写 `M` 的读数。

| # | 被检信号 | 判据来源 | 判「验证」 | 判「失效」 |
|---|---|---|---|---|
| SG1 | 报告的三态与区间判断 | `M1`、`M2`、`M5` | 三态为震荡类且 `M1`、`M2` 均「未穿透」；或三态为趋势类且 `M1`/`M2` 有一侧「穿透」且 `M5` 落在同一侧之外 | 上述条件不成立（含震荡态被双向穿透、趋势态方向相反） |
| SG2 | 目标差价 `W` 与当日波幅是否匹配 | `M4` | `M4` 判「容得下」 | `M4` 判「容不下」 |
| SG3 | 委托单各行触发价是否落在当日价格路径上 | `M3`（**逐行**） | 该行 `M3` 判「已触及」 | 该行 `M3` 判「未触及」 |
| SG4 | 报告的量能预期 | `M6` 倍数 + 报告所载放量倍数阈值 | 倍数 ≥ 报告所载阈值 → 判「触发」记为验证 | 倍数 < 阈值 → 判「未触发」记为失效 |
| SG5 | 报告结论与当日实际是否自洽 | 报告结论 + `M4` + `M1`/`M2` | 结论为做 T 类且 `M4`「容得下」；或结论为不做 T / 停手类且 `M4`「容不下」 | 结论为做 T 类而 `M4`「容不下」；或结论为不做 T 类而 `M4`「容得下」且区间未被双向穿透 |
| SG6 | 区间宽度与当日实际高低的贴合度 | `M` 的六个原值 + 报告所载上沿 / 下沿 / `W` | 两个差值的绝对值均 ≤ `W` → 判「贴合」 | 任一差值 > `W` → 判「过宽」；当日最高 > 上沿或最低 < 下沿 → 判「过窄」 |

**`SG6` 的两个差值**：`上沿 − 当日最高`、`当日最低 − 下沿`。两者**必须**各自写出算式与结果，**严禁**只给「过宽 / 贴合」结论。

- 判据来源中任一 `M` 标「不可判」→ 对应 `SG` **必须**一律标「不可判」，**严禁**据其余项外推
- 报告未载被检信号本身（未载放量阈值、未载区间上下沿、未载 `W`）→ 该 `SG` 标「**不适用（报告未载 `___`）**」，**严禁**代入通用阈值或行业常见值补齐
- `SG3` **必须**逐行判并逐行写出行号，**严禁**汇总成一个「部分触及」——哪几行的价位选错，是次日调价位的唯一线索
- 计数行**必须**写出「验证 `___` / 失效 `___` / 不可判 `___` / 不适用 `___`，分母 `___`」，分母为**逐项展开后的信号条数**（`SG3` 按委托单清单行数展开，其余各计 1 条）
- 判为「失效」的每一条**必须**写出判据读数，并按 [lessons.md](references/lessons.md) §二 转入沉淀候选；**严禁**在本节写出修正后的三态、区间、`W` 或阈值（`ETS5`）

## 五、缺失与失真的标注

| 情形 | 处置 |
|---|---|
| 跟踪指数取不到 | `BM1` 标「不可判」并写出缺的是报告哪一项；`BM2`–`BM4` 与全部 `SG` 照常 |
| 宽基读数取不到 | `BM2` 标「不可判」，**严禁**用跟踪指数读数代填 |
| 外盘任一指标取不到 | `BM4` 只标该项「不可读」，同板块其余指标照常登记 |
| 当日停牌 / 涨跌停封死 / 复牌首日 | `BM1`–`BM3` **必须**照常登记读数并加标该状态；`SG1`–`SG6` 一律标「**不可判（读数失真）**」，**严禁**据失真读数判信号有效性 |
| 报告未载区间上沿或下沿 | `SG1`、`SG6` 标「不适用（报告未载 `___`）」，`SG2`–`SG5` 按各自判据来源照常 |
