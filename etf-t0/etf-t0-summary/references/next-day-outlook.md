# 次日前瞻（Next-Day Outlook）

本文件定义复盘文档最后一节的产出：次日**看什么**（观察项与阈值）、**分几种情形**（三情景）、**当前落在哪一档**（落点）。

**作用域上限（必须先读这一段）**：本节产出是**条件式观察**，不是计划。**严禁**给出次日的三态、目标差价 `W`、止损差价 `L`、买卖价位、委托单清单、轮次数字或金额——这些一律由 `etf-t0-analysis` 用次日数据重算，今天写下的任何具体数值到次日只是一组过期数字，而它会被当成计划照做。本节内容**严禁**写入 `.state.json`：state 是给分析环节读的**已结算事实**，混入情景推断会让分析环节把自己昨天的猜测当作输入数据。本节的阈值（§三）只用于把外盘读数映射到情景，**严禁**当作交易参数，**严禁**与报告所载的放量阈值、`W`、`L` 混用。

## 一、三类 key 的语义差异（判档与选指标的前提）

外盘 key 的更新时机不同，同一个时间戳在三类之间含义完全不同：

| 类 | key 形态 | 更新时机 | 该读数对应的交易日 | 前瞻可用性 |
|---|---|---|---|---|
| **美股隔夜型** | `gb_*`、`int_dji` / `int_nasdaq` / `int_sp500` | 只在美股收盘后更新（北京时间次日凌晨） | **时间戳的北京日期 − 1 自然日** | 判档的唯一依据；对应交易日 ≥ 复盘日时才含隔夜信息 |
| **连续盘型** | `hf_*`、`fx_*`、`DINIW` | 24 小时连续（含美股时段与夜盘） | 时间戳即取数时刻，无「对应交易日」概念 | 可读，但**必须**写出取数时刻；取数时刻早于复盘日 A 股收盘时**必须**加标「不含隔夜信息」 |
| **港股现货型** | `rt_hk*`、`int_hangseng` | 与 A 股同时段收盘 | 时间戳的北京日期（**不减 1**） | 本节**严禁**采用——它与 A 股同步收盘，不含隔夜信息；只可用于 [board-signal-review.md](references/board-signal-review.md) 的 `BM4` 当日背景。港股方向的隔夜信息一律取恒指夜期 `hf_HSI`（连续盘型） |

> 「时间戳 − 1」这条只对美股隔夜型成立：美股收盘落在北京时间次日凌晨 04:00–05:00（夏令时 / 冬令时不同），故实测 `gb_$sox` 返回 `2026-08-08 05:16:26` 对应的是 **8/7** 美股交易日。用这条机械规则**替代**硬编码收盘时点，可自动吃掉夏令时切换与美股假日，**严禁**改为按固定钟点判断。

## 二、双档判定（机械判据，命中即定）

档位一律按**主指标**（§三 该板块第一优先级那个指标）判定。**第 0 行先判，命中即止**：

| # | 判据 | 档位 | 本节写法 |
|---|---|---|---|
| 0 | **追溯复盘**：按 [market-recheck.md](references/market-recheck.md#21-接口返回字段顺序以实际返回核对严禁硬套下标) §2.1 日线路径取标的**最近一根已收日线**，其日期 **> 复盘日** | **不适用** | 本节整节标「**不适用（追溯复盘，次日已走完）**」，只填板块、主指标与阈值三项，**严禁**填任何读数、**严禁**判落点——所谓「次日」已经是过去，拿一根更晚的外盘读数去推它是倒因为果 |
| 1 | 主指标为美股隔夜型，且其对应交易日 **≥ 复盘日** | **盘前档** | 填入实际读数，按 §六 判出落点 |
| 2 | 主指标为美股隔夜型，且其对应交易日 **< 复盘日** | **收盘档** | 美股隔夜型各项一律标「**未开盘·不可读**」；连续盘型项可填读数但**必须**加标「不含隔夜信息」；落点写「**未落点·待盘前补跑**」 |
| 3 | 主指标为连续盘型（黄金 / 原油板块），取数时刻**晚于**复盘日 A 股收盘 | **盘前档** | 同第 1 行；**必须**写出取数时刻 |
| 4 | 主指标为连续盘型，取数时刻**不晚于**复盘日 A 股收盘 | **收盘档** | 同第 2 行 |
| 5 | 主指标两级取数皆不可得 | 按第 1–4 行已判出的档位保留 | 落点按 §六 第 3 行写「未落点（主指标不可读）」 |

- 入参 `outlookStage` 为 `close` / `preopen` 时**必须**以入参为准并标「**用户指定档位**」，但**严禁**因此凭空填读数：指定 `preopen` 而主指标对应交易日仍 < 复盘日时，该项**必须**照常标「未开盘·不可读」、落点照常标「未落点」（`ETS14`）
- 第 0 行**优先于** `outlookStage`：追溯复盘时即使显式传 `preopen` 也**必须**判「不适用」，**严禁**由入参把已走完的交易日重新当作「次日」
- `outlookStage` 为 `auto`（缺省）时按上表判定，并**必须**写出命中的是第几行
- 同一份复盘文档**必须**就地更新：盘前档补跑时改写本节的读数、档位标注与落点行，**严禁**另建第二份复盘文档，也**严禁**删除收盘档已写下的阈值与三情景

## 三、板块路由表（封闭清单，自上而下第一个命中行即定）

用 [board-signal-review.md](references/board-signal-review.md#一对标基准的确定三层逐层填满) §一 所定的**跟踪指数名称**逐行比对关键词：

| 板块 | 跟踪指数名称命中关键词 | 领先指标（① 为主指标） | 阈值口径 |
|---|---|---|---|
| 半导体 / 芯片 | 半导体、芯片、集成电路 | ① SOX 费半 `gb_$sox` ② 台积电 ADR `gb_tsm` ③ 纳指100 `gb_$ndx` | 主 ±2.0%；次 ±1.0% |
| 港股科技 / 中概 | 恒生科技、中概、互联网 | ① 中概金龙 `gb_$hxc` ② 纳指100 `gb_$ndx` ③ 恒指夜期 `hf_HSI` | 主 ±1.5%；次 ±1.0% |
| 黄金 / 有色 | 黄金、有色、贵金属、铜 | ① COMEX 金 `hf_GC` ② 美元指数 `DINIW` ③ 10Y TIPS 实际利率（**无免费接口**，一律走 §四 第 ③ 级） | 主 ±1.0%；次 ±0.5% |
| 原油 / 能源 | 原油、能源、油气、石油 | ① WTI `hf_CL` ② 布伦特 `hf_OIL` | 主 ±2.0%；次 ±2.0% |
| 医药 / 生物 | 医药、生物、创新药、医疗 | ① XBI `gb_xbi` ② NBI `gb_$nbi` | 主 ±2.0%；次 ±2.0% |
| **宽基 / 未命中** | 上述均未命中（含沪深300、中证500、科创50、创业板等宽基，以及板块未定） | ① 标普500 `int_sp500` ② 纳指100 `gb_$ndx` ③ 美元指数 `DINIW` ④ 离岸人民币 `fx_susdcnh` | 主 ±1.0%；次 ±0.5% |

- 命中多行时**必须**取自上而下第一个命中行，**严禁**合并两行的指标清单
- 本表是**阈值口径的唯一出处**；阈值只用于 §五 的情景映射，**严禁**据其调整报告所载任何参数
- 主指标决定档位与落点，次指标**只做同向 / 背离登记**，**严禁**用次指标顶替主指标判落点
- 加新板块**必须**同时补齐「关键词 + 主指标 key + 阈值」三项，只加关键词即使该行不可用

## 四、取数（三级降级链 + 已实测 key）

| 级 | 前提 | 做法 | 来源标注 |
|---|---|---|---|
| ① | 用户已答 `RV10` 并给出该指标读数 | **必须**直接采用 | 「用户提供 + 提供时间」 |
| ② | ① 未提供 | 经 `Bash` 按下方命令取数 | 「接口 key + 取数时间戳 + 该读数对应的交易日（美股隔夜型）或取数时刻（连续盘型）」 |
| ③ | 两级皆不可得（含无免费接口的指标） | **必须**只把该项标「**不可读**」 | 标「数据缺失」 |

```bash
# {key} 逐个填 §三 所列 key，多个用逗号分隔
curl -s --max-time 8 -H 'Referer: https://finance.sina.com.cn/' \
  'https://hq.sinajs.cn/list={key1},{key2}' | iconv -f GBK -t UTF-8
```

- 上表 key 于 **2026-08-10 实测全部可用**；距该日 **> 180 天** 时**必须**在本节加标「**key 快照可能过期，须复核**」（同 `ETS11` 的处置）
- 返回为空串（形如 `var hq_str_xxx=""`）**必须**按第 ③ 级处置，**严禁**据空串推出「持平」或「无变化」
- 解析前**必须**先打印一次原始返回并逐字段核对，**严禁**按记忆中的下标直接切分；两类取值规则不同：
  - **美股隔夜型**：**必须**取返回自带的「涨跌幅」字段，写出「现价 + 涨跌幅」两项，并用「现价 − 涨跌额 = 昨收」交叉校验一次
  - **连续盘型**：返回**不保证**含涨跌幅字段，**必须**取现价与昨收两个原值后现场计算涨跌幅，并把两个原值一并写入文档
- ② 级失败一次**必须**重试一次；重试仍失败按第 ③ 级处置，**严禁**为此中止整份复盘

## 五、情景构造（固定三情景，全部写出）

三情景的触发条件按主指标涨跌幅与 §三 阈值比较，**互斥且完备**：

| 情景 | 主指标触发条件 | 操作倾向可取值 |
|---|---|---|
| **A 偏多** | 涨幅 **≥ +主阈值** | `正常做` |
| **B 震荡** | 涨跌幅落在 **±主阈值之内** | `正常做` / `降轮次` |
| **C 偏空** | 跌幅 **≤ −主阈值** | `降轮次` / `只做单向` / `观望` / `停手` |

每个情景**必须**写出三格，缺一即不合格：

| 格 | 必备内容 |
|---|---|
| 触发条件 | 主指标名 + 比较式（引用 §三 阈值原值），如「SOX ≤ −2.0%」 |
| 盘面推断 | **必须**由两部分构成：① 主指标读数与阈值的比较结果；② 当日 `SG1` / `SG6` 的判定结果（区间是否被验证、宽窄贴合度）。**严禁**写不含这两项的泛化描述 |
| 操作倾向 | **必须**取上表该行的封闭词表之一，并写出所依据的条数 |

- 操作倾向词表封闭为五个字面串：`正常做` / `降轮次` / `只做单向` / `观望` / `停手`，**严禁**自造第六个
- 操作倾向**严禁**附带具体轮次数、金额、价位或 `W`/`L`；须原样附一句「**具体数值由 `etf-t0-analysis` 次日重算**」
- 三情景**必须**全部写出（含未命中的）——未命中情景的触发条件是次日盘中的现场判据；**严禁**只写命中的那一个
- 情景数**固定为三**，**严禁**新增第四情景

## 六、落点判定

| # | 情形 | 落点写法 |
|---|---|---|
| 1 | 盘前档且主指标有读数 | 判出**唯一**落点（A / B / C），并写出主指标读数、所用阈值、比较式三项 |
| 2 | 收盘档 | 一律「**未落点·待盘前补跑**」；**严禁**用连续盘型读数或 `BM4` 的昨夜读数判落点 |
| 3 | 主指标标「不可读」 | 一律「**未落点（主指标不可读）**」；**严禁**改用次指标顶替主指标判落点 |
| 4 | 次指标与主指标反向 | 落点仍按主指标判定，但**必须**加写一行「次指标背离：`___`（读数 `___`）」 |

- 三情景的触发条件互斥，**不可能**同时命中两个；若出现两个同时成立，说明阈值或读数抄错 → **必须**回退重取，**严禁**自行选一个写下
- 落点判出后**必须**紧接一行指回：次日的三态、`W`、`L`、价位与委托单清单**须由 `etf-t0-analysis` 重跑产出**，本节不构成操作指引

## 七、严禁项清单与正误示例

| # | 严禁 | 原因 |
|---|---|---|
| 1 | 写出次日的三态、`W`、`L`、买卖价位、委托单清单、轮次数字、金额 | 越界为计划，且次日必被重算（`ETS5`） |
| 2 | 把 `BM4` 的昨夜读数搬来当「今夜」读数 | 那是已经作用在今日盘面上的旧信息（`ETS14`） |
| 3 | 主指标不可读时仍判落点，或取不到时按「持平 / 平盘」代入 | 无读数的落点是凭空判定（`ETS14`） |
| 4 | 用次指标顶替主指标判档或判落点 | 档位与落点口径不唯一，两次补跑会得出不同结论 |
| 5 | 采用港股现货型读数做前瞻 | 与 A 股同步收盘，不含隔夜信息 |
| 6 | 把本节任何内容写入 `.state.json` | 分析环节会把昨天的猜测当作输入数据 |
| 7 | 因外盘取不到而中止整份复盘 | 台账、差异归因、纪律核查、结算均不依赖外盘 |
