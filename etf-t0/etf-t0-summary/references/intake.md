# 复盘前信息问询清单（Intake）

本文件定义生成复盘文档**之前**必须向用户问到的实际操作数据、逐字问法、答复校验与未答处置。

实际成交与账户数据**只能由用户提供**：成交明细与账户权益无任何公开接口可查，凭手册的计划值回填会使全部差异归因与结算数据失真，且违反「每条信息必须标注来源」的总纲。

计划值来自报告与手册、**实际值来自用户**，两者必须分开采集——用计划值充当实际值等于让复盘自证正确。

## 一、问询规则

- 用户已粘贴手册第七节「轮次记账卡」或「收盘后回填清单」时，**必须**先逐项解析该文本，只对解析不出的项发问
- 待问项**必须**一次性全部列出再等用户答复，**严禁**逐条往返追问
- 用户未答或答"不记得"的项**必须**记为 `未答`，**严禁**填入手册计划值、估算值或上一日旧值
- 每一项答复**必须**逐条过 [§五 答复校验](references/intake.md#五答复校验)，未过校验的项按 `未答` 处置
- 命中 [§四 口径歧义](references/intake.md#四口径歧义的二次确认) 的项**必须**二次确认后再采用
- 阻塞必答三项全部通过校验才进入复盘生成；存在 `未答` 项时按 [§六](references/intake.md#六未答项的处置) 处置

## 二、阻塞必答项（三项，任一未答即停止生成）

| # | 项 | 逐字问法 | 校验 | 未答处置 |
|---|---|---|---|---|
| RV1 | 实际成交台账 | 「把今天在这只标的上的**每一笔成交**报给我，每笔给六项：**时刻 / 方向（买或卖）/ 成交价 / 委托股数 / 实际成交股数 / 对应委托单清单第几行**（清单外的写"清单外"；全部成交时两个股数填同一个数）。今天一笔没做就答"今日未操作"。」 | 答"今日未操作"即通过；有成交时每笔六项齐全，成交价为正数、两个股数均为正整数且成交股数 ≤ 委托股数 | 记 `未答` → 转 §六 |
| RV2 | 收盘未平 T 仓 | 「**收盘时还有没有没平掉的 T 仓**？有的话给：方向、股数、成交价，以及**是否已按报告的收盘清零升级链处置过**。」 | 答「无」即通过；答「有」须四项齐全 | 记 `未答` → 转 §六 |
| RV5 | 清单外与违纪动作 | 「今天有没有做过**手册清单上没有的动作**？逐条报给我：清单外价位下单、改单、撤单、移动止损、加仓摊平、超出轮次上限。一条都没有就答"无"。」 | 答「无」即通过；答「有」须逐条给出时刻与动作内容 | 记 `未答` → 转 §六 |

> `RV1` 的「对应委托单清单第几行」是差异归因的输入，行号基准为手册第四节（手册未提供时为报告委托单清单），缺这一项时**必须**回读确认，**严禁**由本 skill 按价格接近程度自行匹配行号——价格接近不等于同一笔意图。

## 四、口径歧义的二次确认

以下三项的答复存在两种常见口径，**必须**在采用前确认到具体一种，**严禁**按其中一种默认解读：

| 歧义项 | 两种口径 | 确认话术 |
|---|---|---|
| RV3 账户总资产 | 账户总资产（含持仓市值）/ 可用资金 | 「`{值}` 元是「账户总资产」还是「可用资金」？口径 A 只能用账户总资产。」 |
| RV4 已实现盈亏 | 已扣佣金的净额 / 未扣费用的价差毛额 | 「`{值}` 元扣过佣金了吗？」 |
| RV7 持仓成本价 | 摊薄成本 / 买入均价 | 「你给的 `{值}` 是摊薄成本还是买入均价？」 |

> 两种口径差值可达单轮金额量级：把「可用资金」当「账户总资产」会算出虚假的账户回撤幅度，把毛额当净额会低估口径 B 的当日已实现亏损、在该停手时放行。

## 五、答复校验

逐项按下表判定，**任一项不通过即记 `未答`**：

| 校验 | 判据 |
|---|---|
| 数值格式 | 去掉千分位逗号与单位字后**必须**能解析为数字；解析失败即不通过 |
| 单位 | 价格类**必须**为元/股，金额类**必须**为元，股数类**必须**为股；用户答「2 千」「1 万 8」时**必须**换算后回读确认 |
| 时刻格式 | `RV1`、`RV5` 的时刻**必须**能归一化为 `HH:MM`；只答「上午」「快收盘」时**必须**回读确认到具体分钟 |
| 台账自洽 | `RV1` 每一轮买腿与卖腿的**实际成交股数必须**相等；不相等时**必须**回读确认是残股还是未平部分 |
| 与 `RV2` 一致 | `RV1` 中买卖股数不轧平的部分**必须**与 `RV2` 所报未平仓一致；不一致即回读确认 |
| 口径已定 | 命中 §四 的项**必须**已完成二次确认 |

```markdown
<!-- ✅ 正确：六项齐备 + 行号 + 来源标注；委托 600 只成交 400，卖腿按实际 400 挂 -->
RV1 第 1 轮｜10:12 买 4.615 委托 600 成交 400 股（委托单第 1 行）｜10:48 卖 4.660 委托 400 成交 400 股（第 1 行止盈价）｜用户 2026-08-05 提供

<!-- ❌ 错误：缺时刻与行号，无法判定是清单内执行还是清单外动作 -->
RV1 买了 400 股，后来卖了

<!-- ❌ 错误：用户未答成交价，却取了手册的计划委托价回填 -->
RV1 第 1 轮买入价 = 4.615（取手册第 1 行最终委托价）
```

## 六、未答项的处置

- `RV1`、`RV2`、`RV5` 任一为 `未答` → **必须**停止复盘文档生成，改出**待补信息清单**（逐条列出未答项与其逐字问法），并按 SKILL 的退出码表走「需人工决策」
- `RV3`、`RV4` 为 `未答` → **必须**按 §三「未答处置」列降级出复盘文档，且在首部逐条写出「因 `{项}` 未答而降级的节」
- 选答项（[§七](references/intake.md#七选答项缺省口径已定不阻塞生成)）为 `未提供` → **必须**按其缺省口径处置，并在首部登记该项为 `未提供`
- 全部答复**必须**原样写入复盘文档的输入快照节，含每项的**来源标注「用户提供」与提供时间**

```markdown
未答项：RV3（收盘账户总资产）→ 结算节回撤口径 A 全部标「不可核查」，次日口径 A 单日档须由用户在 position 中补填

```
