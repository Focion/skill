# 纪律执行核查（Discipline Audit）

本文件定义收盘后逐项核查纪律执行的 14 个检查项与其判据。每项只输出「是 / 否 / 不适用」加证据，**严禁**折算成分数——分数会把性质不同的违规压成一个数，既不可判定，也会让「今天还不错」取代逐条修正。

判定标准一律取报告与手册所载值（轮次上限、止损价、连亏停手线、口径 B 当日档绝对额、时段可盯盘标注），本文件**严禁**给出任何自有阈值。

## 一、四条通则

- 判定**必须**只看动作本身是否合规，**严禁**把该轮盈亏结果纳入判据——赚钱的违规仍是违规，这正是需要被记下来的那一类
- 判定所需的报告或手册值缺载、或所需台账项未答时**必须**标「不适用」并写出缺的是哪一项，**严禁**用「否」代替「不适用」
- `DA14` **必须**在结算完成后才判定（它依赖结算出的 `prev_close_equity`），**严禁**在结算前以「该值为 `null`」为由把它标成「不适用」
- 每项**必须**写出证据中的具体数值与时刻，**严禁**写成「基本照做了」这类无读数表述

## 二、14 个检查项

| # | 检查项 | 判为「是」的判据 | 证据来源 |
|---|---|---|---|
| DA1 | T 仓当日清零、无过夜 | `RV2` 答「无」 | `RV2` |
| DA2 | 已开轮次未超本日可用轮次 | `RV1` 台账轮数 ≤ 手册第三节所载本日可用轮次；手册未提供时**必须**回退取报告所载每日轮次上限，**严禁**直接标「不适用」 | `RV1` + 手册第三节 / 报告 |
| DA3 | 连亏达停手线后未再开新轮 | 台账中连续亏损轮数首次达到报告所载连亏停手线的时刻之后，无新的开仓时刻 | `RV1` + 报告铁律节 |
| DA4 | 亏损轮均按该行止损价了结 | 每个亏损轮的平仓价与该轮对应行止损价的差额 ≤ 报告所载 `tick` | `RV1` + 手册第四节 |
| DA5 | 未移动过止损价 | `RV5` 未报出「移动止损」「下移止损」形态的动作 | `RV5` |
| DA6 | 无清单外价位下单 | 对照表中无 `DV4` 条目 | [reconcile.md](references/reconcile.md) 归类结果 |
| DA7 | 未因浮亏加仓摊平 | `RV5` 未报出「加仓」「补仓」「摊平」形态的动作，或台账中不存在两笔同向开仓之间无平仓的情形 | `RV5` + `RV1` |
| DA8 | 部分成交按实际成交股数挂止盈止损 | 台账中「成交股数 < 委托股数」的轮，其平仓股数等于该轮开仓的**实际成交股数**；无此类轮时标「不适用」 | `RV1` |
| DA9 | 停牌 / 涨跌停封死 / 复牌首日未开仓 | 盘后核对节标出该状态时台账无开仓时刻；未标出该状态时标「不适用」 | [market-recheck.md](references/market-recheck.md) §四 + `RV1` |
| DA10 | 纠错成交已计入轮次 | `RV6` 报出的纠正类预案，其纠正成交在 `RV1` 台账中各占一轮；`RV6` 未报出纠正类预案时标「不适用」 | `RV6` + `RV1` |
| DA11 | 口径 B 当日档触及后停止当日开仓 | 台账累计已实现亏损首次达到手册第三节所载口径 B 当日档绝对额的时刻之后，无新的开仓时刻；手册未提供时**必须**回退取报告所载该档百分比并按 `RV3` 换算为绝对额，**严禁**直接标「不适用」；全日未达该额时标「不适用」 | `RV1` + 手册第三节 / 报告 + `RV3` |
| DA12 | 不可盯盘段无需人工确认的动作 | 手册第五节标「不可盯盘」的时段内，台账无成交时刻落入该段；手册未标不可盯盘段时标「不适用」 | `RV1` + 手册第五节 |
| DA13 | 预案触发已当场记录 | `RV6` 报出的每个预案编号，在 `RV1` 台账的对应轮均有记录；`RV6` 答「无」时标「不适用」 | `RV6` + `RV1` |
| DA14 | 口径 A 单日档命中后未继续按原打法开仓 | 由 `RV3` 与**结算后的** `prev_close_equity` 算出收盘单日跌幅、写出命中档位：命中 1%–2% 档时台账收盘前**最后一笔**开仓为反向 T 或全日无开仓；命中 > 2% 档时台账无开仓。结算后 `prev_close_equity` 仍为 `null`、或收盘跌幅未命中任何档时标「不适用」 | `RV3` + [settlement.md](references/settlement.md) §三 结算后的 `prev_close_equity` + `RV1` |

> DA14 只看**收盘档位与最后一笔开仓**，理由是穿档时刻客观不可得：口径 A 的跌幅要用盘中权益序列才能定位穿档时点，而散户拿不到 tick 级权益记录。判为「否」时**必须**在证据列写明「据收盘档位与最后一笔开仓推定，穿档时刻不可核实」，**严禁**表述为「当时已知触及该档仍开仓」。

> DA4 与 DA5 分开的理由：按止损价了结与没动过止损价是两件事——把止损从 `4.593` 下移到 `4.560` 后照 `4.560` 卖出，DA4 会通过而 DA5 不通过，合成一条就查不出这种形态。

## 三、计数行（必须写在核查表末尾）

```markdown
本日纪律核查：适用项 M = ____ 项（14 项中标「不适用」____ 项）｜判为「否」N = ____ 项｜违反项编号：____
```

- `M` **必须**为 14 减去标「不适用」的项数，**严禁**把「不适用」项计入 `M`
- `N` 为判为「否」的项数，违反项编号**必须**逐个列出，**严禁**只给数量
- 计数**严禁**加权，**严禁**换算为百分比或分数

## 四、核查结果的下游用途

- 判为「否」的每一项**必须**在沉淀节按 [lessons.md](references/lessons.md) 提炼为条目，**严禁**只在核查表打「否」而不进沉淀
- 判为「否」的项**严禁**改写报告或手册的任何数值——纪律没照做是执行侧的事实，不构成调整策略参数的依据

```markdown
<!-- ✅ 正确：是/否 + 具体读数 + 时刻 -->
| DA2 | 已开轮次未超本日可用轮次 | 否 | 台账 4 轮（10:12 / 11:05 / 13:34 / 14:22）vs 手册本日可用轮次 3 轮 |
| DA9 | 停牌 / 涨跌停封死 / 复牌首日未开仓 | 不适用 | 盘后核对节未标出该状态 |

<!-- ❌ 错误：无读数、无时刻，且把盈亏结果当成判据 -->
| DA2 | 已开轮次未超本日可用轮次 | 是 | 多做了一轮但是赚的，不算违规

<!-- ❌ 错误：判据缺载却写「否」，掩盖了缺的是手册未载可用轮次 -->
| DA11 | 口径 B 当日档触及后停止当日开仓 | 否 | 不清楚停手线是多少
```
