# 多面分析维度清单（利空利多 + 盘面 + 当日）

> 本文件定义"深度多面"分析必须覆盖的维度。每个维度均要求：**结论 + 依据（来源/时间戳）+ 利多/利空/中性定性 + 强度（强/中/弱）**。
> 无法获取数据的维度必须标注 `数据缺失`，严禁用过时或臆测数据冒充。
> 📌 维度字母 **A–G（基本面）/ H–K（盘面）保持不变**（与 report-template 七维表一一对应）；本次新增的可转债专项为 `F.1` **条件维度**（仅可转债标的适用），未新增维度字母。
> 📌 **交易所规则数值（涨跌幅、临停阈值、最小变动价位、申报单位、集合竞价时段、税费）一律引用主文档【附录 D 外部规则快照表】**，本清单只引用、不复写数值；引用时必须写出附录 D 该行的**快照日期**，快照为空或距分析日 **> 180 天** → 标注「规则快照可能过期，须复核」（约束 **ETA11**）。附录 D 中标 **待核实** 的行严禁填入猜测值（ETA1）。

## 一、基本面信息（利空利多收集，A–G 七维）

### A. 宏观与政策
- 货币政策（利率、准备金、公开市场操作、流动性松紧）
- 财政与产业政策（补贴、监管、行业专项政策）
- 汇率与外围（人民币汇率、美股/相关海外市场、大宗商品）
- 关键宏观数据（PMI、CPI、社融、进出口）临近发布或刚公布

### B. 行业与主题（ETF 跟踪指数所属赛道）
- 行业景气度（订单、价格、产能、库存周期位置）
- 行业政策催化或压制（准入、限价、环保、出口管制等）
- 产业链上下游动态（上游成本、下游需求、技术拐点）
- 同赛道其他 ETF / 龙头个股走势的领先或背离

### C. 成分股与指数
- 前十大权重股近期动态（业绩预告、重大合同、减持、突发）
- 指数成分调整 / 编制规则变更预告
- 龙头股财报窗口期（业绩雷或超预期）

### D. 资金面
- ETF 份额变化（申购/赎回，反映资金进出）
- 近 5 日成交额趋势（放量/缩量）
- 北向资金、主力资金流向（若可得）
- 融资融券余额变化（若为可两融标的）

### E. 折溢价与套利

- **第一步先分类，两类品种用两套口径，严禁混用**：

| 品种 | 折溢价判定口径 |
|---|---|
| **境内股票型 ETF**（无额度限制） | 沿用 **绝对阈值表**（\|率\| ≤ 0.3% 正常 / 0.3%–0.5% 关注 / > 0.5% 警惕，口径见 calc-methods §三）；需当日 IOPV，取不到 → 标 `数据缺失` |
| **跨境 / QDII / 商品 ETF**（有额度或申赎限制） | **绝对阈值表不适用**（常态溢价可达 5%+，用绝对阈值会系统性误报利空）→ 一律走下方 E3 的**三级降级口径** |

　　分类不明时按"常态溢价品种"从严处理（走三级降级）。
- 折溢价是否提供套利驱动、是否影响做 T 进出场价
- **跨境 / QDII ETF 三项专查（对接 framework §8、取数与字段见 data-sources §五 / §5.2）**：

| # | 检查项 | 判定与处置 |
|---|---|---|
| E1 | 标的市场当日是否休市 / 未开盘 | 是 → **IOPV 不更新或失真，折溢价率不可信** → 该维度标 `IOPV 失真（标的市场休市）`，**不据此判多空、不据此校正进出场价** |
| E2 | 是否属额度限制导致的**常态高溢价** | 是 → **不可简单当利空**，且绝对阈值表不适用；溢价收窄本身是真实风险（可在标的市场平盘时单独造成 3%+ 跌幅，与 W/L 完全无关） |
| E3 | **高溢价判定：三级降级（依次尝试、命中即定）** | ① 有近 1 年 IOPV 历史 → 溢价率 > **80% 分位** → **停做正向 T**；② 无 IOPV 历史但有二级价日线 → `当日收盘 / 近 20 日均价 − 1 > +3%`（且标的市场同期无对应涨幅）→ 视同高溢价、**停做正向 T**，**必须标注「代理指标，非真实折溢价分位」**；③ 二者皆无 → 标「溢价分位不可得」并**一律保守停做正向 T** |

- 盘中公告停止/限制申购 → 当日不做 T（`framework §8`）。

### F. 公告与事件
- 分红除权、暂停申赎、基金合并/清盘风险
- 管理人变更、费率调整
- 停牌/复牌安排（判定口径见 data-sources §九）→ 命中即触发 **framework §5.1 铁律 5：涨跌停日、停牌日、复牌首日不做 T**（复牌首日量能失真、放量判定失效）

#### F.1 可转债专项（**条件维度：仅当标的为可转债时必填**，对接 framework §8）

> 📌 本项是 F 的条件性扩展，**不新增维度字母**（避免与 §二 H–K 冲突）；标的非可转债时整块写"不适用"。

| # | 检查项 | 判定与处置 |
|---|---|---|
| F1 | **强制赎回公告 / 已进入强赎条款计数期** | **一票否决**：命中即立即停做 T 并重估底仓（强赎后价格向"面值 + 当期利息"回归，高转股溢价率的转债可单日暴跌） |
| F2 | **转股溢价率** | > 30% → **排除，不适合本体系**（波动极大、易被资金操纵，W/L 结构失效） |
| F3 | **临停机制** | 阈值数值**以主文档附录 D「可转债临停阈值」行为唯一出处**（本清单不复写数值），引用时必须写出该行的**快照日期** → **临停期间无法平仓，直接破坏"收盘清零"** → 盘中波动接近**临停阈值的 3/4** 时**主动清仓离场，不等信号**（不写死百分比：阈值一变，写死的数字立刻失效）。附录 D 该行快照日期为空、或距分析日 **> 180 天** → 标「规则快照可能过期，须复核」，不得当已核实事实使用（**ETA11**） |
| F4 | 信用与条款风险 | 正股退市风险、回售/到期条款 → 纳入基本面闸门 |
| F5 | 费用结构 | 无印花税（优势），但佣金结构与股票不同、部分券商有最低收费 → 仍须过「无最低佣金」硬门槛（见 §二 K） |

- 突发新闻、传闻、监管问询、黑天鹅
- 市场情绪（恐慌/亢奋）与一致预期是否过度

## 二、盘面技术分析（H–K 四维）

### H. 趋势与三态（对接 strategy-framework §2）

- 20 日 / 60 日均线结构与斜率，收盘价位置（日线不足 60 根时按 data-sources §4.2 降级并标注）
- **三态判定必须按 calc-methods §六 的量化口径，不得凭形态感觉给**：

```
20 日线斜率 = (20MA(t) − 20MA(t−10)) / 20MA(t−10)

|斜率| < 0.5%  → 走平 → 震荡
斜率 ≥ +0.5%   → 上涨
斜率 ≤ −0.5%   → 下跌
```
　　阈值为示例起点、须回测校准；高波动标的（ATR/P > 3%）可放宽到 1%，**放宽须在报告写明**。

- **冲突态 tie-break（framework §2.1）**：以「价格相对 20 日线位置」+「20 日线近 10 日斜率方向」为准，**均线排列（20/60 谁上谁下）仅作辅助**。价格在 20 日线下方且 20 日线向下 → 判**下跌**，不因 20 > 60 的滞后残留误判上涨。
- **regime 二次确认状态必须记录（framework §2.1）**，四项缺一不可：

| 记录项 | 内容 |
|---|---|
| 本日三态 | 震荡 / 下跌 / 上涨 + 斜率实际数值 |
| 前一日三态 | 同上（无历史 → 标 `数据缺失`） |
| 是否已连续 2 日一致 | 是 → 按新态执行；否 → **过渡日**，按新旧两态中**更保守者**执行（保守序：上涨 > 下跌 > 震荡，即取 T 仓上限更低者） |
| 本次是否为切换过渡日 | 是 / 否（是则打法为保守态，须在策略节写明"过渡日按 X 态执行"） |

> ⚠️ **MACD、KDJ、趋势强度等指标仅作辅助佐证，不参与三态判定**。与斜率口径结论冲突时**一律以斜率口径为准**，冲突事实并列记录（§五"矛盾信息并列呈现"），不得用 MACD 反推或推翻三态。

- 关键日线形态（突破、跌破、假突破迹象）—— 定性佐证，同样不参与三态判定。

### I. 量能
- 当日量 vs 近 20 日均量（放量定义见 framework §4.2）
- 量价配合（放量上涨/放量下跌/缩量反弹的含义）
- 关键价位处的量能确认

### J. 波动与关键价位

- 近 20 日平均振幅、当日振幅、ATR(14)（口径见 calc-methods §二、§四）
- **支撑位 / 阻力位 / 日内区间上下沿必须按 calc-methods §七 口径给出，并标注每个价位所用的候选来源**：

```
候选集 = { 近 20 日最高价, 近 20 日最低价, 前一交易日最高价, 前一交易日最低价,
           当日开盘价, 20 日均线, 最近整数关口 }

日内区间上沿 = 现价【上方】最近的阻力候选
日内区间下沿 = 现价【下方】最近的支撑候选
有效性校验：上沿 − 下沿 ≥ 2W  →  不满足则本轮不做
```
　　写法示例：`上沿 5.120（近 20 日最高价）/ 下沿 4.985（前一交易日最低价）`。**只给数字不给来源视为不合格**（对接 §五 可追溯要求与 ETA9）。

- **目标差价 W / 止损差价 L 的口径（framework §4.4）**：

| 口径 | 公式 | 适用 |
|---|---|---|
| **ATR 动态（默认）** | `W = k × ATR(14)`、`L = W/2`，**k ≤ 1/3 为硬上限，默认 k = 0.30** | 一律默认用此口径；`w = k × (ATR/P)` |
| 静态分级表（备用） | 按价格区间查表取 W、L | **仅**在 framework §4.4 允许的退回情形使用：① 取不到足够 K 线算 ATR(14)（data-sources §4.2）；② 纯手动心算无脚本环境且近 20 日均振幅 ≥ 4%。退回时**必须额外确认近 20 日均振幅 ≥ 该档「所需最低振幅」列**，否则不做 |

> ⚠️ 两套口径**必须固定其一或固定切换规则，严禁临场挑选对自己有利的那个**。用了哪套、为何退回，必须写进报告。
> 📌 所有价位（含 W/L 换算出的买点、卖点、止损价）必须落在**最小变动价位网格**上——该数值取自**主文档附录 D**「ETF 最小变动价位」行（取数与用法见 data-sources §八），引用时须带该行**快照日期**；快照为空或距分析日 > 180 天 → 标「规则快照可能过期，须复核」（**ETA11**）。取整后须复核 `上沿 − 下沿 ≥ 2W` 与 `W ≥ 4×2C` 仍成立。

### K. 盘口与流动性（含成本维度）

- **价差 / 深度 / 滑点三项按 [calc-methods.md](./calc-methods.md) §九（盘口价差、深度与滑点估算）口径算，取数字段见 [data-sources.md](./data-sources.md) §三**：

| # | 检查项 | 判定 |
|---|---|---|
| K-a | **一档价差** = 卖一价 − 买一价 | `一档价差 ≤ W / 5`，不满足 → 价差吃掉利润，本轮不做 |
| K-b | **盘口深度（按方向取同向可成交量）** | 买入看卖侧 `depth_buy` = 卖一~卖三挂单量之和；卖出看买侧 `depth_sell` = 买一~买三挂单量之和；门槛 `对应方向 depth ≥ 本轮计划股数 × 3`，不满足 → 放弃本轮 |
| K-c | **预估滑点** = `max(1 个最小变动价位, 一档价差 / 2)`（穿档时按穿过档位加权均价与买一/卖一之差计） | 校验 framework §1 边界条件 `滑点 < W/3` |

> ⚠️ **集合竞价（三段）与临停期间五档失真** → K-a/K-b/K-c **三项一律标注"不可用"**，不得用失真盘口下结论或宣称门槛通过。三段为 `09:15–09:25`（开盘集合竞价）、`09:25–09:30`（无撮合）、`14:57–15:00`（收盘集合竞价）——**漏掉任一段都会让该时段的失真盘口被当作有效盘口使用**；时段取值以**主文档附录 D**「集合竞价时段」行为准（引用须带**快照日期**，ETA11），判定口径见 data-sources §三 / calc-methods §9.4。

- 日均成交额是否 ≥ 5 亿 —— 必须用**日线近 20 根成交额算日均**（data-sources §四），严禁用盘中半日额对比全日门槛
- **振幅门槛双档（依所用 W/L 口径取对应档，不得混用）**：

| 所用差价口径 | 近 20 日平均振幅门槛 |
|---|---|
| ATR 动态（k ≤ 1/3，默认口径） | **≥ 1.5%** |
| 静态分级表（备用口径） | **≥ 4%**，且须另过该档「所需最低振幅」 |

- **真实往返成本 2C 与成本硬门槛（口径与算法见 calc-methods §八）**：

| # | 检查项 | 判定 |
|---|---|---|
| K1 | 真实往返成本 `2C`（元/股） | 按 calc-methods §八 由价格与账户费率算出，**不用名义费率蒙**；账户费率未提供 → 标 `待用户确认`（data-sources §十） |
| K2 | `W ≥ 4 × 2C` | 不满足 → 本轮不做 |
| K3 | **最低佣金咬合判定** | 通过条件：券商单笔最低佣金 `F = 0`，**或** 单轮金额 ≥ `F / 佣金率`。例：万0.5 费率 + F = 5 元 → 需**单笔 ≥ 10 万元**才不咬合 |
| K4 | **「无最低佣金」硬门槛是否通过** | 未通过（被咬合）→ 真实往返成本从万1 升至约**万5（5 倍）**，最低佣金会吃掉约 2/3 的策略收益 → 结论为**不适合按本体系做 T**，须换零最低佣金账户或提高单笔金额；**这是硬门槛，不是建议项**，不得以"先小仓试试"绕过 |
| K5 | 单笔金额下限 | 同时满足 framework §1 / calc-methods §八 的三条：成本约束（F > 0 时 `≥ 8FP/W`）、性价比下限（`≥ 40/w`）、整手约束（`≥ 申报单位 × P`）。**申报单位按品种取，见主文档附录 D**：ETF = **100 份**、可转债 = **10 张**（每张面值 100 元）。⚠️ 两者差 10 倍，把 ETF 的 `100 × P` 套到可转债会把整手门槛**高估 10 倍**（1,200 元算成 1.2 万元），进而错判"资金不够做不了" |

## 三、当日情况（按分析时段取对应视角）

| 时段 | 视角 | 重点 |
|---|---|---|
| **盘前（09:15 前）** | 预期 | 隔夜消息、集合竞价、外围、今日预案与关键价位；**先按 data-sources §九 确认当日是交易日**（周末/节假日/停牌分别处置） |
| **盘中（09:30-15:00）** | 实况 | 实时三态是否成立、信号是否触发、是否触发熔断、**是否触发 framework §5.2 两套回撤口径的触发线** |
| **收盘后（15:00 后）** | 复盘 | 当日走势归因、操作复盘、**次日 regime 二次确认状态**、次日三态与打法预判 |

**盘中必查：framework §5.2 两套回撤触发线（两套并行，各管一件事，须分别报当前值与所处档位）**

| 口径 | 计量对象 | 必须报出的内容 |
|---|---|---|
| **口径 A** | 账户总资产跌幅（含底仓浮动盈亏）—— 管**打法收缩** | 当日跌幅落在 `<1%` / `1%–2%`（停正向 T，仅许减损型反向 T，T 仓上限降一档）/ `>2%`（当日停做 T）哪一档；单周是否 > 3% |
| **口径 B** | T 交易**已实现**盈亏（占总资金）—— 管**停手** | 落在 `<0.2%` / `0.2%–0.4%`（T 仓上限减半）/ `>0.4%`（当日停止 T）哪一档；单周是否 > 0.8% / > 1.2% |

> 📌 **口径 A 的取数前提**：`prev_close_equity`（昨收账户总资产，**市值口径**）与 `account_equity_week_high` 无法从行情接口取得，取数链见 **data-sources §10.1**（历史 state → 用户 `position` 入参 → 皆无）。皆无 → 单日档标「不可核查」并按**冷启动档**执行（framework §5.2）；单周档缺失 → 只标注 + 人工确认，**不自动触发、不额外降档**。**不得用成本口径的 `total_capital` 代替**，也不得把 `null` 当 0 宣称"未触发"。
> 📌 口径 B 的单日档位大多先被铁律 4「连亏 3 轮停手」截断（单日 3 轮全亏仅约 0.25% 总资金），其实际约束力主要体现在**单周/单月累计**层面——这是纪律冗余，不是缺陷。
> ⚠️ 两个口径不可互相替代：账户下跌（口径 A）**只禁正向 T、保留减损型反向 T**；停手判定只看口径 B。

**收盘必产出：次日 regime 二次确认状态**——本日三态、与前一日是否一致、是否已连续 2 日一致、次日按新态还是按更保守者执行（口径见 §二 H / framework §2.1）。

## 四、多日视角（horizon=multiday 时补充）

- 未来 3-5 交易日的关键事件日历（财报、数据、政策窗口、除权）
- **A 股休市日**：所列区间内的非交易日须先剔除（口径见 data-sources §九），不得把休市日排进分日路径
- **跨境 / QDII ETF 必列：标的市场（美股/港股等）在该区间的休市日历** —— 标的市场休市日 IOPV 不更新，**折溢价维度当日不可信**（§一 E1、framework §8）；取不到该市场日历 → 标 `数据缺失`，并把该日的折溢价结论整块标为不可用
- 多日区间预判（震荡区间上下沿 / 趋势延续或反转的观察点，价位口径同 §二 J）
- 分日打法路径：每日三态假设 → 对应 T 仓上限与轮次 → 触发条件；**三态发生切换的日子须按 regime 二次确认标为过渡日并取更保守者**（§二 H）
- 底仓层面的中期判断（是否需调整底仓、是否触发基本面闸门）

## 五、信息质量自检

- 每条信息必须有**来源**（媒体/公告/行情接口）与**时间戳**。
- 区分**事实**（已发生、可核实）与**观点/预期**（推测）。
- 相互矛盾的信息需并列呈现，不擅自取舍。
- 无法联网或无行情工具时，整体标注"数据缺失"，并说明策略建议因此为"框架性、需用户补数据后校准"。
- **所有价位类输出必须可追溯到计算口径，不得凭经验给数**（对接 SKILL 约束 ETA9）：支撑/阻力/区间上下沿须写出所用候选（calc-methods §七），W/L 须写出所用口径与参数（ATR 动态的 `k` 与 `ATR(14)` 实际值，或静态表档位；framework §4.4），三态须写出斜率数值（calc-methods §六），成本须写出 `2C` 与最低佣金咬合结论（calc-methods §八）。**给不出计算依据的价位一律删除并标 `数据缺失`，不得用"大致在 X 附近"替代。**
