> 本文件给出盘面分析核心指标的**精确计算口径**，供 STEP 4 直接套用。
> 原则：口径先说清、再取数、再判定；任一输入缺失则该指标标注"数据缺失"，不得用估算值冒充。
> 本文件与 [strategy-framework.md](./strategy-framework.md)（v2.5）同步；两者不一致时以 framework 为准，framework 再以主文档 `T0日内回转交易体系.md` 为准。

**口径符号（全文统一，引用比例数字时必须标明用哪个）**：

```
W、L    绝对差价，单位 元/股
w = W/P、l = L/P    占买入价比例（≡ 占本轮 T 仓市值比例）
θ       T 仓占总资金比例（震荡 20% / 下跌 10-15% / 上涨 ≤10%）
l_A = l × θ         单轮止损占【总资金】比例
恒等关系：本体系盈亏比恒 2:1 ⟹ W = 2L ⟹ w = 2l
```

## 一、放量（量能放大）

### 1.1 定义与公式

判断"当前是否放量"，用**当根周期成交量**对比**同周期近期均量**：

```
放量倍数 R = 当根成交量 V_now / 近 N 根均量 MA_vol(N)

MA_vol(N) = (V_{-1} + V_{-2} + ... + V_{-N}) / N   （不含当根，取之前 N 根）

判定：R ≥ 阈值 → 放量；R ≤ 1/阈值 → 缩量；其间 → 平量
```

### 1.2 参数取值（对接 strategy-framework §4.2）

| 场景 | 周期 | N | 放量阈值 | 说明 |
|---|---|---|---|---|
| 日内信号（默认） | 5 分钟 | 20 | **× 1.5** | 覆盖近 100 分钟量能基准 |
| 尾盘时段（14:00 后） | 5 分钟 | 20 | **× 1.3** | 尾盘量能天然抬升，阈值放宽 |
| 日线级别放量 | 日 | 5 | × 1.5~2.0 | 判断日线突破/趋势时用 |

> 阈值均为**示例起点，须回测校准**。

### 1.3 计算要点与陷阱

- **均量不含当根**：MA_vol 取当根之前的 N 根，否则当根被自己稀释，放量被低估。
- **集合竞价与首根**：09:30 首根 5 分钟量常异常放大，判定开盘信号时可改用"首根 vs 近 5 日同一时段首根均量"，避免误判。
- **成交量口径统一**：全程用"股数"或全程用"成交额"，不可混用（价格波动会污染成交额口径）。
- **停牌复牌日**：复牌首日量能失真，当日放量判定失效，标注"数据缺失/失真"。

### 1.4 示例

近 20 根 5 分钟均量 = 80 万股，当根成交量 = 130 万股 → R = 130/80 ≈ 1.63 ≥ 1.5 → **放量成立**。

## 二、ATR（真实波动幅度，Average True Range）

### 2.1 TR（单周期真实波幅）

```
TR = max(
       High − Low,                 高低差
       |High − PrevClose|,         今高与昨收差
       |Low − PrevClose|           今低与昨收差
     )
```

> 取三者最大值，目的是把**跳空缺口**也计入波动（只用 High−Low 会漏掉跳空）。

### 2.2 ATR（TR 的移动平均）

两种主流平滑法，**回测与实盘必须用同一种**：

```
① Wilder 平滑（经典，推荐，反应更平稳）：
   ATR_today = (ATR_prev × (n−1) + TR_today) / n
   首个 ATR = 前 n 根 TR 的简单平均

② 简单移动平均 SMA（口径直观）：
   ATR(n) = (TR_{-1} + ... + TR_{-n}) / n
```

**默认周期 n = 14**；日内做 T 也可另算 5 分钟级 ATR 辅助判断日内波动。

### 2.3 与策略的挂钩：ATR 动态目标差价（**默认口径**，对接 strategy-framework §4.4）

```
W = k × ATR(14)
L = W / 2                 维持盈亏比 2:1
w = k × (ATR / P)         l = w / 2

k ≤ 1/3 是硬上限，默认 k = 0.30（示例起点，须回测校准）

硬约束校验（不满足则本轮不做）：
  W ≥ 往返成本 2C 的 4 倍        （2C 口径见 §八）
  当日预估振幅 ≥ 3W              （振幅口径见 §四）
  日内区间：上沿 − 下沿 ≥ 2W     （区间口径见 §七）
```

> 📌 **`k ≤ 1/3` 的推导（必须理解，不是拍的）**：边界条件① 要求 `日内振幅 ≥ 3W`；
> 而 `ATR(14) ≈ 平均日内高低差`，故 `3k × ATR ≤ ATR ⟺ k ≤ 1/3`。
> ⚠️ 旧版口径写的 `k = 0.3 ~ 0.5` 中，**k > 1/3 的部分在数学上必然违反边界条件①**，已废止：
> 用 k=0.4 时 `3W = 1.2 × ATR`，要求的振幅比标的的平均振幅还大，正常日子里一轮都成不了。
> 附注：TR 含跳空，故 `ATR ≥ 平均高低差`，`k ≤ 1/3` 实际略偏保守——这是想要的方向。

**筛选振幅门槛（双档，按所用口径取）**：

| 所用口径 | 近 20 日平均振幅门槛 |
|---|---|
| ATR 动态（k ≤ 1/3）← 默认 | **≥ 1.5%** |
| 静态分级表 ← 备用（见 framework §4.4.2） | **≥ 4%** |

**何时可退回静态表**：仅 ① 取不足 K 线算不出 ATR(14)（新上市/数据缺失，且须额外确认振幅达该档"所需最低振幅"）② 纯手动心算无脚本环境且近 20 日均振幅 ≥ 4%。两种口径**回测与实盘必须固定其一**，严禁临场挑对自己有利的那个。

### 2.4 示例

某 ETF 现价 P=5.00，ATR(14)=0.12 → `ATR/P = 2.4%`。取默认 k=0.30：

```
W = 0.30 × 0.12 = 0.036 元       （落在 0.001 元 tick 网格上 ✅）
L = W / 2 = 0.018 元
w = 0.036 / 5.00 = 0.72%          l = 0.36%
（占总资金：θ=20% 时 l_A = 0.36% × 20% = 0.072%）

校验① 振幅：需 ≥ 3W = 0.108 元 = 2.16%；ATR/P = 2.4% ≥ 2.16% ✅
校验② 成本：2C = 0.0001 × 5.00 = 0.0005，4×2C = 0.002，W = 0.036 ≥ 0.002 ✅（72 倍）
校验③ 单笔：最小单笔 ≥ 40/w = 40/0.0072 ≈ 5,600 元 → 按整手（100 份 = 500 元）取 1,200 份 = 6,000 元
```

> ⚠️ 若此处误用 k=0.4（旧口径上限）：W = 0.048，需振幅 ≥ 2.88% > 实际 2.4% → **边界条件① 直接不满足**，本轮不该做。这正是 k ≤ 1/3 存在的意义。

## 三、折溢价（Premium / Discount）

### 3.1 IOPV 与折溢价率

```
IOPV（基金份额参考净值）= 按成分股实时价格加权算出的每份净值（行情软件多有实时推送）

折溢价率 = (二级市场价 − IOPV) / IOPV × 100%

  > 0  溢价（市价高于净值，买入偏贵）
  < 0  折价（市价低于净值，买入偏便宜）
```

### 3.2 阈值与做 T 影响（**先分品种，再取阈值**）

```
① 境内股票型 ETF（无额度限制）        → 沿用下方【绝对阈值表】
② 跨境 / QDII / 商品 ETF（有额度或申赎限制）→ 绝对阈值【不适用】，一律走 §3.3 的三级降级口径
```

**绝对阈值表 —— 适用范围：仅境内股票型 ETF**

| 折溢价率 | 定性 | 对做 T 的影响 |
|---|---|---|
| \|率\| ≤ 0.3% | 正常 | 忽略，正常做 T |
| 0.3% < \|率\| ≤ 0.5% | 关注 | 进出场价校正，避免在高溢价追买/深折价割卖 |
| \|率\| > 0.5% | 警惕 | 存在套利驱动，价格易向 IOPV 回归，可能打乱做 T 节奏；高溢价谨慎买、深折价谨慎卖 |

> ⚠️ **严禁把①的阈值套到②**：跨境/商品 ETF 常态溢价可达 5%+，用 ±0.5% 判会**系统性误报**（天天"警惕"，等于没有信号）。
> 这类品种的判定基准是**自身历史分位或近 20 日均价偏离**，见 §3.3 三级降级口径。

### 3.3 计算要点与陷阱

- **IOPV 有延迟**：成分股停牌、涨跌停或跨市场（如跨境/QDII ETF）时，IOPV 可能失真，折溢价率不可尽信 → 标注"IOPV 失真"。
- **跨境/商品 ETF 常态溢价**：受额度/申赎限制，跨境 ETF 长期高溢价是常态，不能简单当利空；需看溢价率相对**自身历史分位**，而非绝对值。判定按下方**三级降级口径**（见 framework §8.2）。

**跨境 ETF 高溢价判定的三级降级口径**（原"> 近 1 年 80% 分位"需 1 年 IOPV 序列，而免费源常连当日 IOPV 都没有 → 该判定实际走不到，故降级）：

```
① 有 IOPV 历史序列 → 原口径：
   溢价率 > 自身近 1 年 80% 分位 → 停做正向 T
     分位算法：取近 1 年（约 240 个交易日）每日折溢价率升序排列，第 80% 位即阈值

② 无 IOPV 历史、但有二级价日线 → 降级代理指标：
   代理值 = 当日收盘价 / 近 20 日均价（收盘价简单平均）− 1
   代理值 > +3% 且标的市场同期无对应涨幅 → 视同高溢价，停做正向 T
   ⚠️ 输出时必须标注「代理指标，非真实折溢价分位」

③ 二者皆无 → 标注「溢价分位不可得」，对跨境 ETF 一律【保守停做正向 T】
   （高溢价回归可在标的市场平盘时单独造成 3%+ 跌幅，与 W/L 无关，不确定时按不做处理）
```

> 阈值 +3% / 20 日均价为**示例起点，须回测校准**。②③ 均**不得**反过来当"溢价正常"的证据——降级口径只能用来触发收缩，不能用来放行。
- **溢价方向辅助多空**：持续放大的高溢价反映资金追捧（情绪偏热），深折价常伴恐慌抛售——可作 info-checklist §E 的资金/情绪佐证，但不单独构成信号。

### 3.4 示例

二级价 5.05，IOPV=5.00 → 折溢价率 = (5.05−5.00)/5.00 = **+1.0% 溢价**，> 0.5% → 警惕：价格有向 5.00 回归压力，追高买入做正向 T 风险偏大。

## 四、附：振幅与 RSI（信号配套口径）

**日内振幅**（对接边界条件"振幅 ≥ 3W"）：

```
当日振幅 = (当日最高 − 当日最低) / 昨收 × 100%
近 20 日平均振幅 = 近 20 个交易日振幅的简单平均
```

**RSI(周期, 14)**（对接 framework §4.1 午盘砸盘买点 RSI<30）：

```
RS = N 周期内平均涨幅 / N 周期内平均跌幅   （涨跌幅取绝对值，用 Wilder 平滑）
RSI = 100 − 100 / (1 + RS)

买点示例用 5 分钟周期、14 根：RSI(5分,14) < 30 视为超卖
```

> 所有指标的周期、平滑方式一经选定，**回测与实盘必须完全一致**，否则信号不可复现。

## 五、凯利风险预算校验（对接 strategy-framework §3.1）

> 本节把 §3.1 的凯利纪律落成可执行的算法。**关键：凯利算的是"风险预算"，不是 T 仓占比。** 做 T 设了止损，单轮只亏 L、不会亏光整个 T 仓，故 f\* 不能直接当仓位（详见 framework §3.1）。仓位上限的真正约束是 2-2-6 执行硬顶（震荡 20% / 下跌 10-15% / 上涨 ≤10%），凯利只用来**校验拟用仓位没有超出风险预算**。无可信历史样本时，直接按执行硬顶的保守端取值，不套凯利。

### 5.1 计算步骤

```
输入：p（该标的历史 T+0 胜率）、r（盈亏比，本体系恒 = 2）、
      买入价 P、止损差价 L（l = L/P）、执行硬顶 f_cap（依三态：0.20 / 0.15 / 0.10）、可做 T 资金 Cap
① 完整凯利（风险预算）：  f* = p − (1−p)/r
② 停做判定：              f* ≤ 0（r=2 时 p ≤ 1/3）→ 无正期望，停做 T，终止
③ 风险预算允许的仓位上限：f_risk = f* / l = f* × (P / L)
④ 取实际仓位占比 θ：      θ = min(f_cap, f_risk)   ← 通常 f_risk 远大于 f_cap，硬顶生效
⑤ 落地金额：              单轮 T 仓金额 = θ × Cap
```

**校验含义**：绝大多数情形下 `l` 只有约 1%（止损占买入价 1%），`f_risk = f*/l` 会是几十倍量级，远大于 20% 执行硬顶——此时 ④ 命中 `f_cap`，凯利校验通过、按 2-2-6 硬顶下单。只有当 f\* 很小（p 逼近 1/3）或止损被迫放很宽（`l` 很大）时，`f_risk < f_cap`，才按风险预算把仓位往下压。

> p 的取数闭环（滚动 100 轮、衰减判定）见 framework §7。

### 5.2 计算要点与陷阱

- **f\* 不是仓位**：③ 里 f\* 先除以 `l` 变成风险预算允许的名义仓位，再和执行硬顶取 min。**严禁把 f\* 直接当 T 仓占比**（那会严重低估可下仓位，也违背 framework §3.1 概念）。
- **别混 `l` 与 `l_A`**：③ 用的是 `l = L/P`（占买入价 ≡ 占 T 仓）。若误用 `l_A = l×θ`（占总资金），f_risk 会被放大 1/θ = 5 倍。
- **回撤口径 B 的触发线是"占总资金"**（framework §5.2 第一列）：其"等价占 T 仓"列按 `θ = 20%` 换算，θ=10%–15%（下跌态）时同一总资金阈值对应**更大**的 T 仓比例（0.2% 总资金 → T 仓 1.3%–2%，不是 1%）。**判触发一律用总资金列**，T 仓列仅供直观参照。
- **p 从哪来必须标注**：优先该标的自身回测/实盘胜率（样本 ≥100）；样本不足则标"胜率不可信"，直接用执行硬顶保守端、不用凯利放大（对接 ETA2 假设值标注）。
- **r 不是自由变量**：本体系 framework §4.4 恒定 W=2L，故 r=2；若某标的实际 W/L 达不到 2:1，先按 §4.4 校验能否做 T，而非调高 r 去凑大仓位。
- **硬顶永远优先**：④ 只取 min，凯利风险预算再宽也不突破 2-2-6；`f_risk` 只会把仓位往下压，不会往上放。

### 5.3 示例

某震荡态 ETF，历史 T+0 胜率 p=0.55（样本 120 次，可信），r=2，买入价 P=5.00、止损差价 L=0.05（即 `l = L/P = 1%`，**占买入价/T 仓**口径；换成占总资金则 `l_A = 1% × 20% = 0.2%`），执行硬顶 f_cap=0.20，可做 T 资金 Cap=10 万元。

```
① f* = 0.55 − 0.45/2 = 0.325                （风险预算 32.5%）
② f* > 0 → 可做
③ f_risk = 0.325 / 0.01 = 32.5              （= f* × P/L = 0.325 × 100，远大于硬顶）
④ θ = min(0.20, 32.5) = 0.20                ← 执行硬顶生效
⑤ 单轮 T 仓 = 0.20 × 10万 = 2 万元
```

结论：风险预算校验通过，按 2-2-6 硬顶下 **2 万元**（20%）。

> ⚠️ 本例的 2 万元单笔在"有 5 元最低佣金"的账户上**一定被咬合**（需 ≥ 10 万才不咬合），真实往返成本变万5、是名义万1 的 5 倍 → 必须先过 framework 边界条件⑥，判定见 §八。

**为什么风险预算几乎从不咬合**：要让 `f_risk < f_cap`（如 <20%），需 `f*/l < 0.20`。即便取胜率偏低的 p=0.40（f\*=0.40−0.60/2=0.10），只要止损正常（`l ≈ 1%`）→ `f_risk = 0.10/0.01 = 10`，远 >0.20，硬顶照样生效。只有当 p 逼近 1/3（f\* 趋 0）**且**止损被迫放宽到 `l > 10%`（P/L<5）时，f_risk 才可能压到 0.20 以下——但这种参数早被 framework §1 边界条件（振幅 ≥ 3W、W ≥ 4×2C）劝退了。**结论：现实 T+0 参数下永远是 2-2-6 执行硬顶生效，凯利校验的作用只是确认"没超风险预算"，而非算出仓位。**

## 六、三态判定量化（对接 strategy-framework §2.1）

> 三态判错则打法全错，是本体系最大亏损来源。"斜率≈0"这类描述不可复现，故本节给出**唯一主口径**。

### 6.1 20 日线斜率（主口径）

```
20MA(t) = 最近 20 个交易日收盘价的简单平均（含当日/基准日）

20 日线斜率 = (20MA(t) − 20MA(t−10)) / 20MA(t−10)
              ← 10 个交易日的相对变化率，无量纲，可跨标的比较

|斜率| < 0.5%   → 走平 → 震荡
斜率 ≥ +0.5%   → 向上
斜率 ≤ −0.5%   → 向下
```

阈值 **0.5% / 10 日**（≈0.05%/日）为**示例起点，须回测校准**；高波动标的（`ATR/P > 3%`）可放宽到 **1%**。

**输入要求**：至少 30 根日线（算 20MA(t) 与 20MA(t−10) 各需 20 根、相隔 10 根）；判定"20 与 60 谁上谁下"另需 60+ 根。K 线不足 → 标注"三态无法判定"，按 SKILL 退出码 3 处理，**不得用更短周期凑**。

### 6.2 三态判定表

| 行情 | 20 日线斜率 | 均线排列（辅助） | 价格位置 |
|---|---|---|---|
| 上涨 | ≥ +0.5% | 20 在 60 上方 | 收盘价 > 20MA |
| 下跌 | ≤ −0.5% | 20 在 60 下方 | 收盘价 < 20MA |
| 震荡 | \|斜率\| < 0.5% | 不看 | 反复穿越 20MA |

### 6.3 冲突态 tie-break

判定优先级：**「价格相对 20 日线位置」+「20 日线近 10 日斜率方向」为主，均线排列（20/60）仅作辅助**。

- 价格在 20MA 下方且斜率 ≤ −0.5% → 判**下跌**（视作趋势中的超跌反弹），**不因 20>60 的滞后残留而误判上涨**。
- 价格在 20MA 上方且斜率 ≥ +0.5% → 判**上涨**。
- 价格贴着 20MA 反复穿越且 `|斜率| < 0.5%` → 判**震荡**。

### 6.4 regime 二次确认（防打法横跳）

```
三态判定相对前一交易日发生变化 → 需【连续 2 个交易日一致】才切换打法
过渡日按新旧两态中【更保守者】执行
  保守序（T 仓上限从低到高）：上涨（≤10%） > 下跌（10-15%） > 震荡（20%）
  即过渡日取两态中 T 仓上限更低的那一档
```

### 6.5 MACD 的定位（回答 info-checklist §H 的 MACD 项）

> 📌 **MACD 仅作辅助佐证，不参与三态判定，也不构成买卖信号。**
> 理由：三态必须**单一口径、可复现**（§6.1 的斜率就是该口径）。再引入一套 MACD 判定必然产生
> "斜率说震荡、MACD 说金叉"的冲突，而本体系并未给 MACD 定义阈值与优先级——多一个无阈值的判据，
> 只会降低可复现性。**§6.1–6.3 是三态的唯一裁决链。**

若要在报告里写 MACD 作趋势强度佐证，参数固定为标准口径（**不得自选参数**）：

```
DIF = EMA(收盘, 12) − EMA(收盘, 26)
DEA = EMA(DIF, 9)
MACD 柱 = (DIF − DEA) × 2          周期：日线
```

表述只能是"MACD 柱走弱/走强，与三态判定一致 / 不一致（仅供参考）"，**不得据此改变三态结论或打法**。

### 6.6 示例

20MA(t) = 4.980，20MA(t−10) = 4.950 → 斜率 = (4.980−4.950)/4.950 = **+0.61%** ≥ +0.5% → **向上**。
若同时收盘价 5.06 > 20MA 且 20MA > 60MA → 判**上涨态**（T 仓上限 ≤10%、每日 ≤1 轮）。
但若前一日判定为"震荡"，则今日为**过渡日**：按二次确认取更保守者 → 当日仍按**上涨态**（≤10%）执行，次日再次确认为上涨后正式切换。

## 七、区间上下沿与支撑阻力口径（对接 strategy-framework §2.2 / §4.4）

> "区间上下沿等放量确认再动"被反复引用，必须有可复现的取价规则，否则上下沿全凭主观。

### 7.1 候选集与取值

```
候选集 = { 近 20 日最高价, 近 20 日最低价, 前一交易日最高价, 前一交易日最低价,
           当日开盘价, 20 日均线, 最近整数关口 }

日内区间上沿 = 现价【上方】最近的阻力候选
日内区间下沿 = 现价【下方】最近的支撑候选
```

### 7.2 有效性校验（不满足则本轮不做）

```
上沿 − 下沿 ≥ 2W

不满足 → 区间容不下一轮完整 T（进出各需 W/2 空间 + 止损缓冲）→ 本轮不做，写明"区间过窄"
```

### 7.3 输出要求

- **所有输出价位必须落在最小变动价位网格上**（ETF 最小变动价位取值见**主文档附录 D**「ETF 最小变动价位」行，引用须带快照日期），不得给出 `0.1234` 这类不可下单价。可转债不得套用 ETF 值——见附录 D 中标 **待核实** 的「可转债最小变动价位」行。
- 取整方向按保守侧：买入价向下取整到 tick、卖出价向上取整到 tick。
- 候选价来自哪一项必须写出来（如"下沿 4.980 = 20 日均线"），否则无法复盘。
- 候选集任一输入缺失（如取不到 20 日 K 线）→ 标注"数据缺失"，不得凭盘感给价位。

### 7.4 示例

现价 5.02，候选集：近 20 日高 5.30、近 20 日低 4.82、昨高 5.08、昨低 4.95、今开 5.00、20MA 4.98、整数关口 5.00。

```
上方最近阻力 → 5.08（昨高）  → 上沿 = 5.080
下方最近支撑 → 5.00（今开/整数关口，两者重合，强度更高） → 下沿 = 5.000

有效性：上沿 − 下沿 = 0.080；W = 0.036 → 2W = 0.072
        0.080 ≥ 0.072 ✅ 勉强容得下一轮，但余量仅 0.008（约 1/4 个 W）→ 报告须提示"区间偏窄，只做 A 档信号"
```

## 八、真实交易成本 2C 与最低佣金咬合判定（对接 strategy-framework §1 / §4.4）

### 8.1 按费率算的 2C（无最低佣金时）

```
2C = 佣金率 × 2 × P          单位：元/股

ETF 佣金 万0.5 单边 → 2C = 0.0001 × P（往返万1）
```

| 价格区间 | 参考中值 P | 真实 2C（元/股） |
|---|---|---|
| < 2 元 | 1.5 | 0.00015 |
| 2–5 元 | 3.5 | 0.00035 |
| 5–10 元 | 7.5 | 0.00075 |
| 10–20 元 | 15 | 0.0015 |
| > 20 元 | 25 | 0.0025 |

> ETF 无印花税。个股往返约**万7.2**（佣金 万1×2 + 印花税 千0.5 + 过户费 万0.1×2 —— **税费口径见主文档附录 D**「印花税率」「过户费」两行，引用时须带该行**快照日期**），是 ETF 的约 7 倍。
> ⚠️ 附录 D 的税费行快照日期为空、或距分析日 > 180 天 → 报告须标「规则快照可能过期，须复核」（ETA11）；税率变更后本行的 **万7.2** 需按附录 D 新值重算，不得沿用。

### 8.2 最低佣金咬合判定（framework 边界条件⑥）

```
设券商单笔最低佣金 F（元）、佣金率 c

咬合判定：单笔金额 < F / c   → 被最低佣金咬合，费率口径失效
此时真实 2C = 2F × P / 单笔金额      （元/股）
真实往返成本占比 = 2F / 单笔金额
```

**算例（F = 5 元、c = 万0.5 = 0.00005）**：

```
不咬合门槛 = F / c = 5 / 0.00005 = 100,000 元 → 单笔需 ≥ 10 万元

单笔 2 万元 → 2×5/20000 = 0.05% = 万5      = 名义万1 的 5 倍
单笔 5 千元 → 2×5/5000  = 0.20% = 万20     = 名义万1 的 20 倍
```

> ⚠️ 10 万级账户（θ=20% → 单轮 T 仓 2 万）**一定被咬合**。这就是"无最低佣金"是**硬门槛而非建议项**的原因：
> 咬合后成本会吃掉约 2/3 的策略收益（敏感度表见 framework §6.2）。
> **判定动作**：`F > 0` 且 `单轮金额 < F/c` → 报告必须写"成本硬门槛不满足"，策略降级为观望/换券商，**不得**照万1 口径继续算收益。

### 8.3 最小单笔金额（取三者最大值）

```
① 成本约束（仅当 F > 0 时生效，F = 0 则此约束消失）：
   最小单笔金额 ≥ 8 × F × P / W
   推导：W ≥ 4×2C，2C = 2F·P/金额 ⟹ 金额 ≥ 8FP/W

② 性价比下限（单轮毛利 ≥ 约 40 元，否则不值得占用注意力与风险额度）：
   最小单笔金额 ≥ 40 × P / W = 40 / w

③ 整手约束（申报单位取值见【主文档附录 D】，按品种取，不可互换）：
   最小单笔金额 ≥ 申报单位 × P

     ETF   ：申报单位 = 100 份  ⟹  ≥ 100 × P   （价 5 元 → 500 元）
     可转债：申报单位 = 10 张   ⟹  ≥ 10 × P    （价 120 元 → 1,200 元）
```

> ⚠️ **③ 的申报单位差 10 倍，是本节最易错处**：ETF 是「份」、可转债是「张」。把 ETF 的 `100 × P` 套到可转债会把整手门槛**高估 10 倍**（1,200 元算成 1.2 万元），进而错判"资金不够做不了"。取值与快照日期见附录 D。

> 📌 F = 5 元时 ① 与 ② 数值恰好相同（`8F = 40`）；F = 0 时只需过 ②③。
> 旧版静态表里"最小单笔 2000/3000/5000/10000/20000 元"是按最低佣金反推的，在"无最低佣金"门槛下依据已失效，一律改用上式。

**ATR 动态下的参考值（取 ②，40 元毛利下限）**：

| ATR/P | w = 0.30 × ATR/P | 最小单笔金额 |
|---|---|---|
| 1.5% | 0.45% | 约 8,900 元 |
| 2.0% | 0.60% | 约 6,700 元 |
| 3.0% | 0.90% | 约 4,500 元 |
| 4.0% | 1.20% | 约 3,400 元 |

**最小可行资金**（= 最小单笔 ÷ T 仓上限，对接 framework §3）：

| 场景 | T 仓上限 | 振幅 1.5%（w=0.45%） | 振幅 3%（w=0.90%） |
|---|---|---|---|
| 单标的·震荡 | 20% | ≥ 4.5 万 | ≥ 2.3 万 |
| 单标的·上涨态 | ≤ 10% | ≥ 9 万 | ≥ 4.5 万 |
| 3 标的分散（各 ≈7%） | 合计 20% | ≥ 13 万 | ≥ 6.5 万 |

> 资金 < 4.5 万且标的为低波动品种 → **不建议**按本体系做 T；资金 < 13 万 → **不建议**做 3 标的分散。
> 以上均为**示例起点，须按自身券商费率与标的实际振幅重算**。
>
> ⚠️ **本表按性价比下限（②`40/w`）测算**；当 `申报单位 × P > 40/w` 时绑定约束转为**整手（③）**，须按 `申报单位 × P / T仓上限` 另算。
> - **ETF（100 份）**：即 `w > 0.4/P`，w=1.2% 时对应 **P > 33 元** → 少数高价 ETF 命中；绝大多数 ETF 价格 < 10 元不受影响。
> - **可转债（10 张）**：整手金额 ≈ `10 × P` ≈ 1,000–1,300 元 < `40/w`（约 3,400–8,900 元）→ **不命中**，绑定约束仍为性价比下限。
>
> 📌 **已修正的旧结论**：原文写「百元面值可转债会命中此情形」，系误按 ETF 的 `100 × P ≈ 1 万元/手` 推得。可转债申报单位为 **10 张**（主文档附录 D，快照 2026-07-27），按 `10 × P` 实算并不命中。

### 8.4 计算要点与陷阱

- **佣金率与最低佣金必须问用户或查对账单**：拿不到就按 `F = 5 元` 的**保守假设**做咬合判定，并显式标注"费率为假设值，须用户核实"，**不得**默认 F=0 让成本看起来很美。
- **别把 2C 的单位搞混**：`2C` 是元/股，`W ≥ 4×2C` 两边都是元/股；写成占比时统一为 `w ≥ 4 × 2c/P`。
- **成本永远算往返**：单边佣金 ×2；反向 T 也是一买一卖，同样是往返。
- 取不到费率/规模/振幅任一输入 → 该结论标注"数据缺失"，**不得用估算冒充**。

## 九、盘口价差、深度与滑点估算（对接 framework §1 边界条件③）

> 边界条件③「滑点 < W/3」与"价差 ≤ W/5""深度 ≥ 3 倍"两个门槛长期只有门槛没有算法，是全体系唯一无法校验的边界条件。本节补齐口径，使③ 从定性要求变成**可校验项**。
> 输入均取自五档快照。新浪快照字段：**下标 6 = 买一价、下标 7 = 卖一价、下标 3 = 现价、下标 10–19 = 五档买（量,价）、下标 20–29 = 五档卖（量,价）**；字段对应以 data-sources §三 为准。

### 9.1 价差

```
一档价差 = 卖一价 − 买一价
相对价差 = 一档价差 / 现价

门槛：一档价差 ≤ W / 5      不满足 → 价差吃掉利润，本轮不做
```

> 一档价差恒为最小变动价位（取值见**主文档附录 D**，引用须带快照日期）的整数倍；`一档价差 = 1 个最小变动价位` 是最好情形。

### 9.2 盘口深度（**按方向取同向档位**，不可混算）

```
买入时看【卖侧】：depth_buy  = 卖一 + 卖二 + 卖三 挂单量之和
卖出时看【买侧】：depth_sell = 买一 + 买二 + 买三 挂单量之和

门槛：对应方向 depth ≥ 本轮计划股数 × 3     不满足 → 放弃本轮（防滑点）
```

> ⚠️ 常见错误：正向 T 买入时去看买盘厚不厚。**买入吃的是卖单**，必须看卖一~卖三；反向 T 卖出同理只看买一~买三。
> 单位统一为"股/份"（五档量若为手数需 ×100 后再比）。

### 9.3 滑点估算（用于校验边界条件③）

```
预估滑点 ≈ max(1 个最小变动价位, 一档价差 / 2)

单边穿档时（计划股数 > 一档挂单量）按加权均价算：
  成交均价 = Σ(各档成交价 × 该档成交量) / 计划股数
  预估滑点 = |成交均价 − 买一/卖一价|      （买入用卖一，卖出用买一）

校验：预估滑点 < W / 3     不满足 → 本轮不做，或把计划股数降到不穿档的量
```

### 9.4 失真情形（必须标注，不得下结论）

- **集合竞价期间（三段，缺一不可）** 与**临时停牌期间**：五档失真，不可当有效盘口。

```
09:15–09:25（开盘集合竞价）、09:25–09:30（无撮合）、14:57–15:00（收盘集合竞价）
```

> 📌 **为什么必须写全三段**：这三段的五档均不反映连续竞价的真实可成交量，**漏掉任一段都会让该时段的失真盘口被当作有效盘口使用**（旧版本节只写了 09:15–09:25、14:57–15:00，漏掉 09:25–09:30 无撮合段）。时段取值以**主文档附录 D**「集合竞价时段」行为唯一出处，引用时须带该行**快照日期**；快照为空或距分析日 > 180 天 → 标「规则快照可能过期，须复核」（ETA11）。与 data-sources §三 同口径。

- 上述三段时段、临停期间以及取不到五档数据时，**价差、深度、滑点三项判定一律标注"不可用"**，边界条件③ 记为"未校验"，**不得用失真盘口下结论**，更不得因"看起来盘口很厚"而放行。

### 9.5 示例

某 ETF 现价 5.00，W = 0.036（k=0.30 口径），计划单轮 6,000 元 = 1,200 份。盘口：买一 4.999/8,000 股，卖一 5.000/3,000 股，卖二 5.001/5,000 股，卖三 5.002/9,000 股。

```
一档价差 = 5.000 − 4.999 = 0.001；门槛 W/5 = 0.0072 → 0.001 ≤ 0.0072 ✅
买入方向深度 = 3,000 + 5,000 + 9,000 = 17,000 股；门槛 = 1,200 × 3 = 3,600 股 → ✅
预估滑点 = max(0.001, 0.001/2) = 0.001；门槛 W/3 = 0.012 → 0.001 < 0.012 ✅（不穿档：1,200 < 卖一 3,000）
→ 边界条件③ 通过，盘口可执行
```

> 若计划股数改为 10,000 份（穿到卖三）：成交均价 = (3,000×5.000 + 5,000×5.001 + 2,000×5.002)/10,000 = 5.0009，
> 预估滑点 = 5.0009 − 5.000 = 0.0009 < 0.012 ✅ —— 但此时 `depth_buy = 17,000 < 10,000 × 3 = 30,000` ❌，**深度门槛不过，本轮仍不做**。
> 两个门槛是并列关系，缺一不可。
