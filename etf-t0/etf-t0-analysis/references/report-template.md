## 八、状态文件
随本报告产出 `etf-t0-{6位代码}-{date}.state.json`（格式见主文档附录 B），用于**次日续用与自动化衔接**——轮次、连亏、回撤计数跨日累计不错乱。字段按**账户级 / 标的级**分组：

**账户级字段**（多标的时各份 state 的值必须一致；以运行时间戳最新的一份为准；不一致 → 本节须提示「账户级字段不一致，口径 A 结论可能失真」，不擅自取其一静默使用）

| 字段 | 含义与用途 |
|---|---|
| `account_equity` | 当日收盘**账户总资产（市值口径）** = 底仓按当日收盘市价计的市值 + 现金，等同券商 App「账户总资产」；口径 A 的当期权益 |
| `prev_close_equity` | 上一交易日收盘账户总资产（**市值口径**）= 口径 A **单日**跌幅基准（`(prev_close_equity − equity_now)/prev_close_equity`）。取历史 state 的 `account_equity`；未命中且用户未提供 → 写 `null` 并标「口径 A 单日档不可核查」，禁止当 0（ETA10）。**注意：单日档同样依赖历史 state 或用户提供，并非"只看当日涨跌幅"**；新账户/首次运行必然为 `null` → **走三级降级链的 ② 用户提供**（`position` 中的「昨收账户总资产」），或按**冷启动档**（名义**降一档** + 仅 A 档信号 + 轮次不变，`cold_start.active = true`）执行；**严禁按缺失字段数累计降档归零** |
| `account_equity_week_high` | 本自然周内 `account_equity` 峰值（**市值口径**）；`口径A单周跌幅 = (week_high − equity)/week_high`。续算四步（同周取较大者 / 跨周以本日 equity 重起算 / 未命中写 `null` 并标「口径 A 单周档不可核查」） |

> ⚠️ **口径一致性**：三者一律**市值口径**，同口径才可比；`total_capital` 是**成本口径**（持仓按成本估算 + 现金），**严禁用它参与口径 A 的任何计算**（跨口径相减得出的跌幅无意义）。附录 B 示例中两者数值相同仅因**成本价 = 市价，非通例**。

| 字段 | 含义与用途 |
|---|---|
| `symbol` / `name` / `total_shares` / `cost_basis` / `cash` / `total_capital` | 持仓与资金基线（`total_capital` = 持仓市值**按成本估算** + 现金，**成本口径**，不用于口径 A） |
