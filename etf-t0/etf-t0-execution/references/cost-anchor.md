# 专属成本锚点（Cost Anchor）

本文件定义把用户的**持仓成本价**转成四个锚点值的口径、摊薄测算方式，以及成本锚点的**用途白名单与禁用清单**。

本文件的全部输入只有两类：① 用户答复的 `Q1` 成本价 / `Q2` 持仓股数（见 [intake.md](references/intake.md)）；② 分析报告所载的现价、`W`、`L`、真实往返成本 `2C`、每日轮次上限、胜率来源。**严禁**自行重算第 ② 类的任何一项。

## 一、四个锚点值

| 锚点 | 符号 | 公式 | 输入来源 |
|---|---|---|---|
| 浮亏幅度 | `d` | `d = (P − C) / C` | `C` = `Q1`；`P` = 报告所载现价 |
| 浮亏总额 | `PnL_f` | `PnL_f = (C − P) × Q2` | 同上 + `Q2` |
| 保本卖出价 | `P_be` | `P_be = C + 2C` | `2C` = 报告所载真实往返成本（元/股） |
| 单轮净摊薄额 | `Δ` | `Δ = (W − 2C) × n / Q2` | `W`、`2C` = 报告所载；`n` = 本轮股数（见 [order-craft.md](references/order-craft.md)） |

- 四个值**必须**逐个写出代入过程（含每个输入的来源标注），**严禁**只给结果
- `P` **必须**写出其在报告中的取数时间戳；报告标注「数据缺失」时 `d` 与 `PnL_f` 一律写 `不可算`

## 二、摊薄测算

```
摊薄后成本      C' = C − Δ
单轮摊薄幅度    Δ / C
抹平浮亏轮次    N_flat = PnL_f / ((W − 2C) × n)      ← 每轮均达目标价、胜率 100% 的上限假设
按期望的轮次    N_exp  = PnL_f / E_round
每轮期望净额    E_round = p × (W − 2C) × n − (1 − p) × (L + 2C) × n
折算交易日      N_exp / R                            ← R = 报告所载每日轮次上限
```

- `p` **必须**取报告「胜率来源」所载值，并原样继承其「假设值 / 历史值」标注
- `N_flat`、`N_exp`、`折算交易日` 三者**必须**标注为**假设值、待回测**，**严禁**表述为「几天回本」「做满 N 轮即解套」
- `N_flat` 与 `N_exp` **必须同时给出**：只给 `N_flat` 会把 100% 胜率的上限当作预期，把最乐观情形讲成计划

## 三、用途白名单（只允许这三种用法）

| # | 允许的用法 | 具体动作 |
|---|---|---|
| U1 | 判断底仓是否满足长期持有前提 | 把 `d` 与用户的持有计划一并写入手册首部，供用户确认底仓仍按长期持有对待 |
| U2 | 费用与摊薄进度测算 | 出 §二 的 `C'`、`Δ`、`N_flat`、`N_exp` |
| U3 | 反向 T 卖出的已实现亏损记录 | 卖出价低于 `C` 时，在收盘回填清单中记录该轮已实现亏损金额 |

## 四、禁用清单

| # | 禁用 | 原因 |
|---|---|---|
| X1 | 把 `C` 或 `P_be` 写成买入/卖出触发价 | 买卖点由报告的 `W`、`L` 与信号决定；市场不知道你的成本，成本价上没有任何支撑或阻力 |
| X2 | 因浮亏扩大而加仓摊平 | 加仓改变底仓与 T 仓结构，超出报告所载生效上限，且把日内交易变成被动长持 |
| X3 | 「等回到成本价再卖」而持有 T 仓过夜 | T 仓过夜使当日 `L` 失效，隔夜跳空风险与 `W` 不成比例 |
| X4 | 用 `d` 的大小调整本轮股数 | 股数由现金上限与仓位上限取小决定，与浮亏幅度无关 |

```markdown
<!-- ✅ 正确：卖点取报告口径，成本只出现在摊薄测算里 -->
卖出触发价 = 买入价 + W = 4.471 + 0.090 = 4.561（口径：报告 W）
参考：本轮达标可把成本从 5.710 摊到 5.6932（假设值，待回测）

<!-- ❌ 错误：把保本价当卖出触发价，等于把成交概率交给成本 -->
卖出触发价 = 保本价 5.716（等回本再卖）

<!-- ❌ 错误：把最乐观上限讲成计划 -->
按每轮摊 0.29% 算，71 轮即可回本
```

## 五、反向 T 对成本显示值的影响

- 反向 T（先卖后买）卖出价低于 `C` 时**必须**在手册中写明「本轮为**已实现亏损**」，**严禁**只写差价收益
- 卖出后未按 `L` 买回 → 底仓股数减少，`Q2` 与后续全部股数测算失效，**必须**在收盘回填清单中更新 `Q2`
- 券商 App 的**摊薄成本**会在卖出后跳变、**买入均价**不变：两者跳变差异属显示口径差异，**严禁**据其调整任何触发价

## 六、算例（数值仅为算例，实盘一律代入报告与用户答复的当期值）

输入：`C` = 5.710 元/股（摊薄成本，用户提供）、`Q2` = 1000 股、`P` = 4.518 元（报告所载）、`W` = 0.090、`L` = 0.045、`2C` = 0.006 元/股、`n` = 200 股、`R` = 3 轮/日、`p` = 0.55（报告所载假设值）

| 锚点 | 代入 | 结果 |
|---|---|---|
| 浮亏幅度 `d` | `(4.518 − 5.710) / 5.710` | **−20.88%** |
| 浮亏总额 `PnL_f` | `(5.710 − 4.518) × 1000` | **1192 元** |
| 保本卖出价 `P_be` | `5.710 + 0.006` | **5.716 元** |
| 单轮净摊薄额 `Δ` | `(0.090 − 0.006) × 200 / 1000` | **0.0168 元/股** |
| 摊薄后成本 `C'` | `5.710 − 0.0168` | **5.6932 元**（摊薄 0.29%） |
| `N_flat` | `1192 / ((0.090 − 0.006) × 200)` = `1192 / 16.80` | **71 轮**（假设值：每轮均达目标、胜率 100%，待回测） |
| `E_round` | `0.55 × 16.80 − 0.45 × (0.045 + 0.006) × 200` = `9.24 − 4.59` | **4.65 元/轮**（假设值，待回测） |
| `N_exp` | `1192 / 4.65` | **≈ 256 轮**（假设值，待回测） |
| 折算交易日 | `256 / 3` | **≈ 86 个交易日**（假设值，待回测） |

> 这张表**必须**整表出现在手册里：只出前六行会让用户以为「71 轮」是计划，出到最后三行才看得出——在 `p = 0.55` 的假设下，靠做 T 抹平 20.88% 的浮亏需要约 86 个交易日**且期间不出现连亏停手**。这不是劝退，是把「做 T 解套」这件事的量级摆在下单之前。
