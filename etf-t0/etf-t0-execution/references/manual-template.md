# 个性化操作手册模板（Manual Template）

生成手册时严格套用本结构，逐节填写。缺输入的节**必须**写「因 `{项}` 未答/未载而不出」并说明影响，**严禁**留空或跳过。

继承参数一律抄自分析报告并注明报告位置；用户答复一律标注「用户提供 + 时间」；测算结果一律标注「假设值，待回测」。

```markdown
# {ETF名称}（{6位代码}）T+0 个性化操作手册 · {date}

- **来源报告**：{reportPath}
- **报告结论**：____（做 / 观望 / 停手 / 不适合做 T / 不适用本体系 / 当日不做 T）
- **状态文件**：{statePath}（未提供时写「未提供」）
- **手册生成时刻**：____
- **未答项及其影响**：____（逐条写「未答项 → 未出的节」；无未答项写「无」）
- **规则派生时点的快照标注**：____（原样抄自报告；报告未载时写「时点缺报告记载，须用户自行核实交易所当期规则」）

> ⚠️ 本手册的全部价位、差价、上限、轮次均继承来源报告，未做任何重算。报告失效（跳空穿透区间、盘中熔断、标的状态变化）时本手册同步失效。
```

## 常见填写错误

```markdown
<!-- ✅ 正确：缺输入的节写出未出原因与影响范围 -->
## 二、你的持仓与成本锚点
因 Q1（持仓成本价）未答，本节不出成本锚点与摊薄测算；第三节股数测算不受影响。

<!-- ❌ 错误：整节删除，手册看不出缺了什么 -->
（第二节不存在，直接从第一节跳到第三节）

<!-- ❌ 错误：继承参数栏填了报告未载的自算值 -->
| 目标差价 `W` | 0.100（按现价 2% 取） | — |
```
