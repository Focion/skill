# 常见错误预案（Error Playbook）

本文件定义八类日内高频失误的**可观测触发条件**与**立即动作**。手册的每个时段行都**必须**至少引用一个预案编号。

预案只规定「发生后怎么办」。触及止盈、止损、轮次、连亏、停牌等**纪律条款一律以分析报告所载为准**，本文件**严禁**改写其数值或放宽其条件。

## 一、八类预案

| 编号 | 情形（可观测触发） | 立即动作 | 严禁动作 | 记录项 |
|---|---|---|---|---|
| EP1 | **卖飞**：反向 T 已卖出，价格向上离开卖出价，未回落到买回价 | 价格触及「卖出价 + `L`」时**必须**立即按市场对手价买回同等股数，本轮记为亏损 | 不买回而等回落；以高于「卖出价 + `L`」的价格追买；用买回资金去买其他标的 | 卖出价、买回价、亏损额、是否按 `L` 执行 |
| EP2 | **接早**：正向 T 已买入，价格继续下行 | 价格触及止损价时**必须**立即卖出买入的股数，本轮记为亏损 | 下移止损价；补仓摊平；把这笔 T 仓改口称「长期底仓」 | 买入价、止损价、实际成交价、是否按 `L` 执行 |
| EP3 | **T 仓面临过夜**：进入尾盘缓冲段仍有未平 T 仓 | **必须**按报告「收盘清零升级链」逐时点执行（步骤见 [timetable.md](references/timetable.md) §五） | 用市价单清仓；把未平仓留到次日再看；在收盘集合竞价段挂新 T 单 | 触发时点、各级动作的成交结果、是否命中报告所载例外条款 |
| EP4 | **部分成交**：委托只成交一部分 | **必须**按报告所载「部分成交处理」条款执行 | 对未成交部分追价；按计划股数（而非实际成交股数）挂止盈止损 | 计划股数、实际成交股数、未成交部分的撤单时间 |
| EP5 | **量能误判**：用未走完的 5 分钟柱、或用盘口挂单量判定了放量 | **必须**撤回据此提交的未成交委托；已成交则按该轮原止盈止损纪律了结，不追加 | 以「量能马上就上来」为由保留委托；重新用同一根柱再判一次 | 误判时点、所用读数、实际收结后的量比 |
| EP6 | **连亏上头**：连亏轮次达到报告所载停手线，或出现加仓、缩短 `L`、加挂轮次任一动作 | **必须**撤掉全部未成交挂单并停止当日开新轮；已有未平轮按原纪律了结 | 加大股数「翻本」；缩短 `L` 以求少亏；把轮次上限改大 | 连亏轮次、停手时点、是否有超限动作 |
| EP7 | **涨跌停 / 临停 / 停牌**：标的进入涨跌停封死、临时停牌或全天停牌 | **必须**按报告所载铁律停做 T；已有未平仓按报告升级链的例外条款处置 | 在封死板上挂单等成交；把停牌当作「等复牌再平」的理由 | 触发时点、状态类型、未平仓处置结果 |
| EP8 | **手滑**：方向、股数或价格填错并已提交 | 未成交 → **必须**立即撤单；已成交 → **必须**立即按对手价反向平掉错单部分 | 把错单留着「反正差不多」；用第二笔错单去对冲第一笔 | 错单内容、纠正方式、是否占用轮次 |

## 二、三条通则

- **每次纠正动作都占用轮次**：EP1、EP2、EP8 的纠正成交**必须**按报告所载轮次口径计入当日已用轮次，**严禁**以「这是纠错不是交易」为由不计
- **纠正动作不设新价位**：全部纠正价一律为对手价或报告所载 `L` 派生价，**严禁**在纠正时临时定一个新价位
- **预案触发必须当场记录**：记录项**必须**在触发当日写入手册回填栏，**严禁**事后凭记忆补写

```markdown
<!-- ✅ 正确：卖飞按 L 派生价买回，且记为亏损轮次 -->
EP1 触发 14:06｜卖出 4.649｜触及 4.649+0.045=4.694 → 买回 4.695｜亏损 9.2 元｜计入第 2 轮

<!-- ❌ 错误：等回落，等于把日内交易变成裸空头 -->
EP1 触发 14:06｜等价格回到 4.60 再买回

<!-- ❌ 错误：纠正动作不计轮次，会绕过报告的轮次上限 -->
EP8 手滑买入已平掉｜纠错不计轮次
```

## 三、预案与时段的对应关系

| 段 | 必须引用的预案 |
|---|---|
| P1 / P2 | EP5、EP7 |
| P3 / P4 / P6 | EP1、EP2、EP4、EP6、EP8 |
| P5 | EP8 |
| P7 / P8 | EP3、EP7 |

- 手册中每段的「禁止动作」列**必须**写出该段对应的预案编号，**严禁**只写禁止动作而不给编号
