## 使用方式

```
/generate-curriculum <教材或学科描述>          # 默认：课程范围卡（轻量）
/generate-curriculum --full <学科> [课程描述]   # 完整课程设计模板（10 维度）
```

### 默认模式：课程范围卡

教师 Agent 多数场景只需要知道「教学内容边界」，不需要完整教学设计。默认输出一张范围卡即可。

- `/generate-curriculum 人教版高中三年级语文`
- `/generate-curriculum 人教版 初二数学 上册`
- `/generate-curriculum 北师大版 高一物理 必修一,只教运动学和牛顿力学`
- `/generate-curriculum 高一体育 腰旗橄榄球为主,兼顾足球篮球`
- `/generate-curriculum 语文` → 空白范围卡骨架（学科已填，其余留空待填）

### --full 模式：完整课程设计模板

只在用户明确需要教学目标、教学策略、评估体系、课时进度、差异化与安全规范时使用。

- `/generate-curriculum --full 语文 高三,难度中低,重点古诗文鉴赏和议论文写作,不涉及文学批评理论`
- `/generate-curriculum --full 体育 高一,大力发展装备橄榄球和腰旗橄榄球,兼顾足球篮球,难度中等`

看到 `--full` 时，读取 `references/full-template.md` 并按其中的规则生成；本文件其余部分只描述范围卡。

## 范围卡：模板结构

```yaml
# ============================================================
# 课程范围卡 — 告诉教师 Agent 本课的教学内容边界
# 学科: <subject>   教材: <textbook>
# 生成时间: <YYYY-MM-DD>
# ============================================================

meta:
  id: ""                  # <subject>-<教材slug>-<grade>，如 chinese-pep-g12
  subject: ""             # 学科名称
  grade: ""               # 学段 + 年级，如"高三""初二""高一"
  semester: ""            # 上学期/下学期/全学年，不确定则留空
  textbook: ""            # 教材全称，含版本与册次，如"人教版 普通高中语文 选择性必修 上册"

scope:
  # 教学范围：教师 Agent 只在这些内容内展开
  covers:
    - unit: ""            # 单元/章节名，带原书编号
      key_points: []      # 该单元要教到的核心内容，1~5 条；不确定可留空
  # 明确不教的内容
  excludes:
    - ""                  # 一句话，如"不涉及大学中文系的文学批评理论"
  # 学生问到范围外内容时的处理方式
  out_of_scope_action: "redirect"
  # redirect      = 一句话带过并引回本课内容
  # brief_mention = 简要回答后引回
  # refuse        = 明确说明不在本课范围内

notes: ""                 # 一句话补充：难度取向、侧重点、课时约束等；可留空
```

字段就这些，不要新增维度。范围卡的价值在于短——教师 Agent 每轮对话都要带着它。

## 范围卡：生成规则

1. **解析输入**。从描述中提取教材版本（人教版/北师大版/苏教版/外研版…）、学段年级、册次、学科、以及"只教/重点/不涉及"这类边界词。年级写法统一为「高三」「初二」而非「高中三年级」。
2. **填 covers**。
   - 确信教材目录时，按原书顺序列出单元/章节名（带编号），每条配 1~5 条 `key_points`。
   - 不确信具体目录时，**不要编造单元名**。只写册次层级的范围（如 `unit: "必修上册 全册（第一~八单元）"`），并在 `notes` 写「单元名待按实际教材目录校订」。
3. **填 excludes**。默认放三类：
   - 超出本册/本学段的内容（初中排除高中内容，高中排除大学内容）；
   - 用户描述中明说「不涉及」的内容；
   - 该学科常见的越界方向（语文→文学批评理论；数学→微积分/高等代数；体育→无保护极限运动与高对抗格斗；信息技术→攻击性代码与作弊工具）。
   每条一句话，讲清「不教什么」，不需要写理由。
4. **选 out_of_scope_action**。默认 `redirect`；学生年龄小或纪律要求严时用 `refuse`；拓展型/选修型课程用 `brief_mention`。
5. **无描述时**输出空白骨架：填 `meta.subject`、`meta.created_at`、`out_of_scope_action` 默认值，`covers` 留一条空模板，`excludes` 留该学科的常见排除方向作为注释提示。
6. **不做的事**：不生成教学目标、教学方法、评估标准、课时表、Agent 语气与行为规范。这些属于 `--full` 模板或 `generate-identity`（教师身份）的职责，不要混进范围卡。

## 范围卡：示例

`/generate-curriculum 人教版高中三年级语文` →

```yaml
# ============================================================
# 课程范围卡 — 告诉教师 Agent 本课的教学内容边界
# 学科: 语文   教材: 人教版 普通高中语文 选择性必修
# 生成时间: 2026-09-03
# ============================================================

meta:
  id: "chinese-pep-g12"
  subject: "语文"
  grade: "高三"
  semester: "全学年"
  textbook: "人教版（统编）普通高中语文 选择性必修 上册 / 中册 / 下册"

scope:
  covers:
    - unit: "选择性必修上册 全册"
      key_points:
        - "中国革命传统作品研习"
        - "外国作家作品研习"
        - "先秦诸子散文（《论语》《老子》《孟子》等）"
        - "逻辑的力量：发现潜藏的逻辑谬误、运用有效的推理形式"
    - unit: "选择性必修中册 全册"
      key_points:
        - "中国革命传统作品与中国现当代作家作品研习"
        - "外国作家作品研习（小说、戏剧）"
        - "史传散文与议论文（《屈原列传》《苏武传》《过秦论》《五代史伶官传序》等）"
    - unit: "选择性必修下册 全册"
      key_points:
        - "中华传统文化经典研习：诗歌（《离骚》《蜀道难》等）、明清小说"
        - "古代散文（《陈情表》《项脊轩志》《兰亭集序》等）"
        - "语言积累、梳理与探究"
    - unit: "高三复习专题"
      key_points:
        - "现代文阅读（论述类、实用类、文学类）"
        - "古诗文阅读与默写（含必修、选择性必修背诵篇目）"
        - "语言文字运用"
        - "议论文写作与材料作文"

  excludes:
    - "不涉及大学中文系的文学批评理论与流派分析"
    - "不涉及比较文学、语言学专业分析"
    - "不涉及学术论文写作规范"
    - "不代替学生完成作文，只做思路与结构指导"

  out_of_scope_action: "redirect"

notes: "高三以复习和应试能力整合为主；单元名与背诵篇目请按学校实际使用的教材版次校订。"
```

## 输出要求

1. 保存到 `curriculums/`（目录不存在则创建）。
2. 文件名：
   - 范围卡：`<subject>-<教材slug>-<grade>.scope.yaml`（如 `chinese-pep-g12.scope.yaml`）；空白骨架为 `<subject>-template.scope.yaml`
   - `--full` 模板：`<subject>-<grade>-<slug>.yaml`
3. 回复用户时只说三件事：文件路径、教学范围一行摘要、明确排除了什么。不要把 YAML 全文再贴一遍。
4. 提示可手动编辑校订教材目录，以及此文件可与 `generate-identity`（教师身份）、`generate-guideline`（学校准则）组合使用；需要完整教学设计时加 `--full`。
