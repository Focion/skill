# 营销段字段清单

本文件为 `blueprint-marketing` 段提供本段的待闭环字段、闭环判据、追问句式、空洞回答的追加问法、必核字段、上游锚点与档位处置。候选生成规则、处置分类、来源等级、发散手法与单轮输出格式以 [co-create.md](references/co-create.md)为唯一来源，本文件**严禁**复述。

本段字段总数为 5，单轮输出的完整度分母**必须**取该数，**严禁**另取。

本段管的是「说什么」—— 定位、叙事、卖点、痛点语言、素材主线、说服顺序。客观判据：某字段的产出物是一句可以被读出来的话时归本段；是一个可以被计数的触达位置或触达机制时归推广段，**严禁**在本段追问渠道、种子用户、获客成本与分发合作。

---

## 一、本段字段清单

| 字段 | 要拿到的东西 | 闭环判据 | 追问句式 |
|------|------------|---------|---------|
| `MKT1` | 定位与一句话叙事 | 取值型：一句能被用户原样转述的话 | 用户向朋友介绍它时会怎么说？这句话里哪个词是你要抢的？ |
| `MKT2` | 人群洞察与痛点语言 | 取值型：用户自己描述该问题时的原话 | 目标用户自己抱怨这件事时用的是哪些词？他们不会用哪些词？ |
| `MKT3` | 核心卖点与差异化证据 | 枚举型：选定的卖点 + 每条卖点对应的可验证证据 | 三个卖点里哪个是主打？拿什么证明它（数据、对比、试用、案例）？ |
| `MKT4` | 素材形态与内容主线 | 枚举型：选定的素材形态 | 靠什么让人看懂：短视频、截图对比、可试玩链接还是长文？ |
| `MKT5` | 转化路径与说服顺序 | 枚举型：从看到到行动之间的步骤序列 | 用户从刷到它到真正用起来要经过几步？哪一步最容易掉队？ |

- 本表为**封闭清单**，**必须**逐字取用，**严禁**在本段追问本表之外的字段编号
- `MKT1` 的取值**必须**是一句用户能原样转述的话，**严禁**写成一段功能罗列
- `MKT3` 的每条卖点**必须**各配一条可验证证据与其来源等级，**严禁**写下无证据的卖点
- `MKT5` 的步骤序列**必须**沿用产品分册主流程的步骤名，**严禁**另起一套步骤命名

## 二、空洞回答与追加问法

| 空洞回答 | 追加问法 |
|---------|---------|
| 「主打好用、体验好」 | 「好用」在这个品类里是默认项。换成一个竞品做不到的具体动作来说，是哪一个？ |
| 「面向所有人」 | 先说第一批一百个人。他们的共同身份标签是什么？ |
| 「产品好自然有人传」 | 用户传播时截的是哪一屏、说的是哪一句？这一屏现在存在吗？ |
| 「卖点就是便宜」 | 便宜多少、跟哪一家比？对方降价到同一档时你还剩什么？ |
| 「素材到时候再想」 | 现在就定一种：用户第一眼看到的是哪一屏截图、哪一段几秒的画面？ |

- 用户的回答命中本表任一行时**必须**发出对应的追加问法，**严禁**把空洞回答记为【已确认】

## 三、本段必核字段

下列字段**必须**联网取证，**严禁**以模型记忆中的数据代替。

| 字段 | 要核的事实 | 检索方向 |
|------|----------|---------|
| `MKT3` | 主打卖点是否已被同类产品具备 | 同类产品官网功能页、更新日志、公开对比评测 |

- 取证记录的形态与取不到时的处置以 [co-create.md 第六节](references/co-create.md#六取证记录与取不到时的处置)为唯一来源
- 取证结果显示主打卖点已被同类具备时**必须**在分册中逐条写出该同类与其出处并交由裁决段判定，**严禁**在本段给出否决结论
- 卖点证据的来源等级为 `E5` 或 `E6` 时**必须**在该行标注「无外部证据」，**严禁**按已取证记录

## 四、上游锚点与档位处置

追问本段字段之前**必须**先读字段台账的下列上游取值，**严禁**在未读台账时开始追问。

| 台账字段 | 本段用它做什么 |
|---------|-------------|
| `RQ3` | `MKT2` 的痛点语言取自该人群自己的说法 |
| `RQ5` | 逐条比对本段取值有无与硬约束直接冲突 |
| `PRD1` | `MKT1` 与 `MKT3` 由核心体验那句话改写而来 |
| `PRD2` | `MKT5` 的转化路径沿用主流程的步骤名 |
| `COM2` | `MKT2` 的人群与场景以商业段目标客群为准 |
| `COM5` | `MKT3` 的差异化维度对着用户当前替代做法立 |

- 字段台账不存在时**必须**先新建台账、追问 `RQ2` 与 `RQ4` 两项并写入，**严禁**在产物类型未确定时开始本段追问
- 台账缺 `PRD` 分区时**必须**把本表所列上游 `PRD` 字段全部标为【缺口】，并在分册首行下方写出「本册未经产品方案锚定」一行，**严禁**凭模型代填的产品方案往下算
- 上游取值标为【缺口】时其下游字段的取值**必须**同步标注依赖该缺口，**严禁**当作已确认事实入算
- 用户在本段改写了上游字段取值时**必须**把该改写回读并交回编排段，**严禁**在本段就地改写上游分册

`scope=screen` 时本段**必须**不做任何追问，直接输出段交回信号并在未闭环行写「本档不调用本段」，**严禁**在本档追问本段任一字段。

- 本段字段不进入快筛档的任何算式，故本档**必须**跳过整段，**严禁**为凑完整度而在本档补问
- 本档跳过时**严禁**建立本段分册 —— 空分册会让索引的分册索引节把本段标为已交回
