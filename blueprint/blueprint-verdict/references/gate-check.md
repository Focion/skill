# 完整度门禁

本文件为 `blueprint-verdict` 段提供字段台账的读取与判定、非字段门禁项清单、【模型假设】占比的统计口径与门禁输出格式。硬否决项、算式与结论态判定表以 [feasibility-gate.md](references/feasibility-gate.md)为唯一来源，来源等级与标签定义以 [co-create.md](references/co-create.md)为唯一来源，本文件**严禁**复述两者。

本档应闭环字段总数：`scope=full` 取 41，`scope=screen` 取 14。该数**必须**按当前 `scope` 取用，**严禁**另取。

---

## 一、台账读取与字段判定

裁决前逐条读取字段台账，每个字段按其 `label` 归入下列三态之一，三态之外一律视为未判定。

| 态 | 判据 | 附加要求 |
|----|------|---------|
| 通过 | `label` 为 `已确认`，且 `value` 非空 | — |
| 未通过 | `label` 为 `缺口`、`待核实` 或 `模型假设` | **必须**逐条进入本册的全局缺口表或全局模型假设清单 |
| 不适用 | `label` 为 `不适用` | **必须**附台账中该记录所载理由，缺理由时按未通过判 |

- 存在未判定字段时**必须**在结论中记为不可判定输入，**严禁**按通过处理
- `label` 为 `模型假设` 的字段**严禁**被计为通过 —— 它是模型代填的取值
- `label` 为 `待核实` 的字段**严禁**因为已尝试取证就计为通过
- 未通过**必须**照常推进到结论态判定 —— 门禁的目的是让每一项都有明确判定，**严禁**把未通过当作停止出结论的理由
- 台账某段分区整体缺失时该段全部字段**必须**记为未通过，**严禁**按不适用处理

## 二、非字段门禁项清单

下列六项不指向单个字段，逐条判定，**严禁**跳过任一项。

| 编号 | 门禁项 | 通过判据 | 未通过时的处置 |
|------|-------|---------|--------------|
| `CG1` | 各段均已交回 | `scope=full` 时六个段的分册文件均存在；`scope=screen` 时产品、商业、技术、实施四份分册均存在 | 在结论中列出缺席的段，交回编排段补调 |
| `CG2` | 取证痕迹齐全 | 台账中每条记录的 `source` 与 `date` 同时非 `null`，或其 `label` 属于 `待核实` / `缺口` / `不适用` | 逐条列出无出处的记录，交回对应段补取证 |
| `CG3` | 缺口清单齐全 | 台账中 `label` 为 `缺口` 或 `待核实` 的字段均出现在本册全局缺口表 | 补齐全局缺口表后重判 |
| `CG4` | 模型假设清单齐全 | 台账中 `label` 为 `模型假设` 的字段均出现在本册全局模型假设清单 | 补齐全局模型假设清单后重判 |
| `CG5` | 行动项主体齐备 | 各段分册行动项表的每一行均含主体与完成标准两列的取值 | 逐条列出缺主体的行动项，交回对应段补齐 |
| `CG6` | 候选路线数达标 | `scope=full` 时候选路线不少于 2 条；`scope=screen` 时本项记为不适用 | 补出候选路线后重判 |

- 六项**必须**逐条给出通过、未通过或不适用之一，**严禁**留空任一项
- `CG2` 的判定**必须**逐条扫过台账全部记录，**严禁**抽样
- 门禁未通过**必须**在结论的判据编号中一并列出，**严禁**只在门禁节留一行
- 门禁项**严禁**由模型增删条目 —— 本表为封闭清单

## 三、【模型假设】占比的统计口径

| 项 | 取值 |
|----|------|
| 分子 | 台账中 `label` 为 `模型假设` 的字段数 |
| 分母 | 本文件文首所载的本档应闭环字段总数 |
| `不适用` 字段 | 不计入分子，也不从分母中扣除 |
| 还原字段 | 不计入分子，也不计入分母 |

- 分母**必须**按当前 `scope` 取文首所载数，**严禁**按台账中已写入的记录数动态缩小分母
- 占比**必须**写成分数与百分数两种形态，**严禁**只写一个百分数

```markdown
<!-- ✅ 正确：分母取本档应闭环字段总数，分数与百分数都给出 -->
【模型假设】占比 = 7/41 = 17.1%

<!-- ❌ 错误：分母按已写入的记录数缩小，占比虚低 -->
【模型假设】占比 = 7/20 = 35%
```

## 四、门禁输出格式

门禁判定结果写入本册的完整度门禁节，格式固定如下。

```markdown
## 完整度门禁

- 字段：{通过数}/{本档应闭环字段总数} 通过 ｜ 未通过 {数量} ｜ 不适用 {数量}
- 【模型假设】占比：{分数} = {百分数}
- 非字段门禁：{通过的编号列表} 通过 ｜ {未通过的编号列表} 未通过 ｜ {不适用的编号列表} 不适用

| 编号或字段 | 判定 | 判定依据 |
|-----------|------|---------|
```

- 三行汇总**必须**齐备，**严禁**省略任一行
- 通过数、未通过数与不适用数之和**必须**等于本档应闭环字段总数，不相等时**必须**回台账逐条重判
- 表格**必须**逐条列出未通过与不适用的项，**严禁**只写汇总数
