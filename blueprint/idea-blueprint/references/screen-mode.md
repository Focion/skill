# 快筛档（mode=screen）

本文件为 `idea-blueprint` 编排段定义 `mode=screen` 与 `mode=full` 两档的差异：调用哪几段、各段以哪个 `scope` 调用、升档问询格式与本档产物。各段的字段子集由该段自己的字段清单在 `scope=screen` 下声明，结论态的判定表由裁决段声明，本文件**严禁**复述两者。

快筛档的用途：在花大量轮次之前先判断这个诉求值不值得继续。它**必须**能给出「不做」，**严禁**给出成套方案。

---

## 一、两档差异总览

| 项 | `mode=screen` | `mode=full` |
|----|--------------|------------|
| 调用的段 | 第二节所列 | [pipeline-contract.md 第一节](references/pipeline-contract.md#一段序与产物清单)全部七段 |
| 传给各段的 `scope` | `screen` | `full` |
| 结论态 | 裁决段以 `scope=screen` 判定 | 裁决段以 `scope=full` 判定 |
| 产物 | 第四节 | pipeline-contract 第一节所列全部分册 |
| 收尾动作 | 第三节升档问询 | 直接回显产物清单 |

- 两档的还原字段一致，**必须**按 [fields.md 第一节](references/fields.md#一诉求还原字段)全表还原，**严禁**在快筛档裁剪还原字段
- 两档的取证要求一致，**严禁**以「只是快筛」为由跳过任何段的取证要求

---

## 二、screen 档调用的段

快筛档固定调用下列五段，段总数取 5。

| 出手序 | 段代码 | 传入的 `scope` |
|-------|-------|--------------|
| 1 | `PRD` | `screen` |
| 2 | `COM` | `screen` |
| 3 | `TEC` | `screen` |
| 4 | `OPS` | `screen` |
| 5 | `VERDICT` | `screen` |

- 本表为**封闭清单**，**必须**逐字取用，**严禁**在执行中增删段
- 营销段与推广段在本档**严禁**被调用 —— 它们的字段不进本档的任何算式
- 产品段仍**必须**排在最前并交回产品方案回读确认行，**严禁**因为是快筛档而跳过该行
- 段进度的分母**必须**取 5，**严禁**取 `mode=full` 的段总数

---

## 三、升档问询格式

裁决段交回的结论态为「可继续」时以下列三行收尾，由用户选出口。

```markdown
快筛结论：{结论态}（判据：{判据编号列表}；本档未判项：{裁决分册所载未判项编号}）
已闭环：{已闭环字段编号列表} ｜ 段进度：{已交回段数}/5
出口：A 转完整流程，补全其余字段并调用营销、推广两段 ｜ B 就此停在快筛
```

- 出口**必须**由用户选，**严禁**替用户升档
- 用户选 A → 以 `mode=full` 继续调度，各段以 `scope=full` 重新调用，已闭环字段**严禁**重问
- 用户选 B → 按第四节回显产物后收尾
- 「本档未判项」**必须**逐条列出编号，**严禁**省略该括号内容
- 结论态为「可继续」**严禁**被表述为「这件事可行」，它只表示本档未发现否决项

```markdown
<!-- ✅ 正确：三行齐备，未判项逐条列编号，两个出口都留给用户 -->
快筛结论：可继续（判据：{编号列表}；本档未判项：{编号列表}）
已闭环：PRD1、PRD2、PRD4、COM3、COM4 ｜ 段进度：5/5
出口：A 转完整流程，补全其余字段并调用营销、推广两段 ｜ B 就此停在快筛

<!-- ❌ 错误：把「可继续」读作「可行」，未判项未列出，并替用户选了升档 -->
快筛看下来这事可行，我按完整流程接着往下走。
```

## 四、screen 档的产物

| 文件 | 条件 |
|------|------|
| 索引 | 必产，节次取 [pipeline-contract.md 第三节](references/pipeline-contract.md#三索引骨架) |
| 字段台账 | 必产 |
| 产品、商业、技术、实施四份分册 | 必产，由各段自行写入 |
| 裁决分册 | 必产，由裁决段写入 |
| 营销分册、推广分册 | **严禁**产出 |

- 索引的分册索引节**必须**为营销与推广两行保留 `未调用` 状态，**严禁**删除这两行
- 本档**严禁**产出候选路线对比与成套方案，出现即违规
- 落盘文件名**必须**沿用 `SKILL.md` 产物文件表所载命名，**严禁**另立命名
