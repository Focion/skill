# 活动产品方案字段实例化

本文件为 `blueprint-product` 段提供 `RQ2` 产物类型为活动时，`PRD` 十一个字段各自要拿到的具体东西与计数单位。字段名与闭环判据以 [fields.md](references/fields.md)为唯一来源，取值的记录形态、砍单排序与回读格式以 [product-spec.md](references/product-spec.md)为唯一来源，本文件**严禁**复述。

| 字段 | 该类型下要拿到的东西 | 计数单位 |
|------|------------------|---------|
| `PRD1` | 参与者到场后要做的那一件事，做完带走什么 | — |
| `PRD2` | 活动当天从入场到散场的环节序列，标出人最容易走掉的环节 | 环节 |
| `PRD3` | 第一场的环节、物料、场地、嘉宾、奖品逐条点名与各自优先级 | 项 |
| `PRD4` | 每类物料要准备多少份，准备一份的工时 | 份 · 小时/份 |
| `PRD5` | 报名与筛选规则、名额与分组规则、奖惩与退费规则的取值 | — |
| `PRD6` | 主办、执行、志愿者、参与者各自能做的动作 | 角色 |
| `PRD7` | 参与者从报名到到场到复参的状态序列 | 状态 |
| `PRD8` | 人数不足、超员、嘉宾缺席、场地取消、天气与安全事件的处理 | 情形 |
| `PRD9` | 从开放报名到活动结束收尾的那条路径，逐步写出 | 步 |
| `PRD10` | 一场消耗多少环节、按环节时长算全场能撑多少分钟，几场之后参与者不再来 | 环节/场 · 分钟 |
| `PRD11` | 先做一场多少人的小规模预演、什么结果算通过 | 人 |

**本类型的追问侧重**：

- `PRD8` **必须**逐项问到人数不足与安全事件两种情形，**严禁**归入「临时应变」—— 这两项决定活动能否开办
- `PRD5` 的退费规则**必须**在开放报名之前定下取值，**严禁**留到出问题时再定
- `PRD10` **必须**给出单场时长与复参衰减两项取值，**严禁**只算单场 —— 只办一场的活动无留存可言
- `PRD11` 的预演**必须**有可数人数与通过判据，**严禁**用内部走场充当预演
