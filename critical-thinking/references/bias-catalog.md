# 认知偏差清单与反制

本文件为 `critical-thinking` 技能的偏差面攻击提供判据，源自《思考，快与慢》。偏差面攻击**必须**引用本文件的偏差编号，并按第三节的可证伪化写法呈现。

---

## 一、双系统与 WYSIATI

- **系统 1**：快、自动、联想、情绪驱动，永远在给答案，且答案总是自洽的
- **系统 2**：慢、费力、可核算，天性懒惰，默认对系统 1 的输出照单全收

批判性对抗的本质就是**强制启动系统 2** —— 用外部程序（提问清单、数据核对、外部视角）替代「我觉得」。

**WYSIATI（眼见即为事实）是所有偏差的公共母体**：人只用手头已有的信息构造一个连贯故事，信息的**缺失**不会产生任何不适感。由此得到一条可直接使用的攻击原则：

> 判断的信心水平来自故事的**连贯性**，而不是证据的**完备性**。用户讲得越顺、越像一个好故事，越要问「这个故事需要哪些信息才成立，其中哪些你其实没有」。

## 二、偏差清单

### 2.1 判断捷径类（`BI-J*`）

| ID | 偏差 | 可观测特征 | 反制提问 |
|----|------|-----------|---------|
| BI-J1 | 锚定效应 | 结论数值贴近对话中最先出现的那个数 | 如果最初听到的是另一个数，你的估计会落在哪 |
| BI-J2 | 可得性 | 论据全部来自近期、亲历或媒体高曝光事件 | 你举的例子是不是恰好都是你最近听说的 |
| BI-J3 | 代表性 | 靠「像不像」下判断，不问该类事物的总体占比 | 符合这个画像的总体里，真正达成的比例是多少 |
| BI-J4 | 基础比率忽视 | 只用个案特征，完全不引用总体发生率 | 这类事情在全体样本中本来的成功率是多少 |
| BI-J5 | 合取谬误 | 细节越多的情节被判为越可能发生 | 加上这三个限定后，概率只会更低，为什么反而更信 |
| BI-J6 | 小数定律 | 用极小样本得出稳定结论 | 样本量多少，换一批样本结论还一样吗 |
| BI-J7 | 问题替换 | 把难问题（会不会成功）换成易问题（团队看着靠不靠谱）作答 | 你回答的是原来那个问题吗 |
| BI-J8 | 情感启发 | 先有喜欢/厌恶，再补理由 | 假设这件事是你讨厌的人提出的，你的评价会变吗 |
| BI-J9 | 光环效应 | 因某一项突出而对全部维度打高分 | 把这个优点拿掉，其余维度各自的证据是什么 |
| BI-J10 | 回归均值忽视 | 把极端值之后的回落解释成某个干预的功劳 | 什么都不做的情况下，下一期本来会是多少 |

### 2.2 信心与预测类（`BI-C*`）

| ID | 偏差 | 可观测特征 | 反制提问 |
|----|------|-----------|---------|
| BI-C1 | 过度自信 | 给点估计不给区间；区间宽度小于历史误差 | 给个 90% 把握区间，上下界分别是多少 |
| BI-C2 | 有效性错觉 | 信心来自模型自洽，而非过往预测的命中率 | 你用同一套方法过去判断对过几次，错过几次 |
| BI-C3 | 规划谬误 | 工期/成本估算等于顺利情形，未含意外 | 同类项目历史上的实际耗时分布是什么 |
| BI-C4 | 叙事谬误 | 用一条因果清晰的故事解释复杂结果 | 运气在这个结果里占几成，你怎么区分运气与能力 |
| BI-C5 | 后见之明 | 「早就看出来了」，事后重构必然性 | 事发之前你写下过这个判断吗，白纸黑字在哪 |
| BI-C6 | 结果偏差 | 用结果好坏评价当初决策的质量 | 在当时可得的信息下，这个决策还是错的吗 |
| BI-C7 | 确认偏误 | 只检索支持己方的证据 | 你为找反面证据花了多少时间，找到了什么 |

### 2.3 取舍与框架类（`BI-F*`）

| ID | 偏差 | 可观测特征 | 反制提问 |
|----|------|-----------|---------|
| BI-F1 | 损失厌恶 | 对同等量级的失与得反应不对称 | 把「避免损失 X」改写成「获得 X」，选择会变吗 |
| BI-F2 | 框架效应 | 结论随表述方式（存活率/死亡率）改变 | 换成互补的另一种表述，你的判断还一致吗 |
| BI-F3 | 禀赋效应 | 已拥有之物估价远高于同物的购入价 | 如果现在没有它，你愿意花多少钱买进 |
| BI-F4 | 沉没成本 | 用已投入辩护继续投入 | 假设今天从零开始，你还会选这条路吗 |
| BI-F5 | 现状偏好 | 默认不变即安全，不评估不变的成本 | 什么都不做的三年后代价是多少 |
| BI-F6 | 峰终效应 | 用最强烈时刻与结尾代表整段体验 | 把全过程按时间平均，评价还一样吗 |
| BI-F7 | 可能性效应 | 高估小概率（彩票式押注） | 这个小概率的具体数值是多少，凭什么这么估 |
| BI-F8 | 确定性效应 | 为消除最后一点不确定性付出不成比例代价 | 从 95% 提到 100% 的这笔成本，换算成期望值划算吗 |

## 三、可证伪化写法（偏差面攻击的强制格式）

只说「你这是确认偏误」是贴标签，不是论证 —— 它不可证伪，用户只能选择接受或翻脸。必须改成三段式：

1. **特征**：`{偏差 ID} 的可观测特征是 {表格第三列原文}`
2. **对照**：`你的表述里 {具体引用用户原话}，命中该特征`
3. **验证动作**：`要排除这个可能，需要 {具体可执行的取证动作或数据}`

用户完成验证动作后特征消失 → 该攻击判为【挡住】。这样偏差指控本身也变成可被推翻的命题，对抗才对称。

```markdown
<!-- ✅ 正确：特征、对照、验证动作三段齐全，指控本身可被用户推翻 -->
BI-C7 的可观测特征是「只检索支持己方的证据」。你列举的 {3} 个案例全部支持该结论，且你提到反面情形「没细看」，命中该特征。
要排除这个可能，需要你找出 {3} 个采用同样做法却失败的案例，并说明它们与你的案例在机制上差在哪。

<!-- ❌ 错误：只有偏差名，没有可观测特征与验证动作，用户除了接受或翻脸没有第三种回应 -->
你这就是确认偏误。
```

**严禁**在同一轮里堆叠 3 个及以上偏差编号：偏差之间高度重叠，堆叠会让用户无从回应，只剩「你说什么都对」的败退感，认知没有任何提升。

## 四、系统性反制手段

| 手段 | 操作 | 治哪些偏差 |
|------|------|-----------|
| 外部视角 / 参照类预测 | 先找同类事件的历史分布，把本案当成该类中的一例，再据个案特征做小幅调整 | BI-J3、BI-J4、BI-C3 |
| 事前验尸 | 设定「一年后此事已失败」，倒推最可能的三条死因 | BI-C1、BI-C4、BI-C7 |
| 决策日志 | 判断做出时即写下预测与置信度，事后按记录复盘 | BI-C2、BI-C5、BI-C6 |
| 双向换框 | 同一选择用收益框与损失框各陈述一遍，比较判断是否一致 | BI-F1、BI-F2 |
| 频率化表述 | 把「概率 5%」改成「100 次里发生 5 次」再判断 | BI-J5、BI-F7 |
| 归零重问 | 「今天从零开始，还会这么选吗」 | BI-F3、BI-F4、BI-F5 |

## 五、施加偏差指控的边界

- 偏差**只解释判断可能如何产生，不证明判断为假**：一个由锚定产生的数字仍可能恰好正确。攻击落点**必须**是「这个判断缺少独立于直觉的验证」，而不是「这个判断是错的」
- 用户给出了独立于直觉的验证路径（数据、对照、外部参照类）→ 偏差指控立即失效，**必须**当场判【挡住】
- **严禁**用偏差编号解释用户的动机或人格 —— 那属于 [fallacy-catalog.md](references/fallacy-catalog.md) 的 FL-R1 人身攻击，对抗方自身同样受谬误清单约束
