# 全局重构与认知升级报告

本文件为 `critical-thinking` 技能定义对抗之后的收束动作：把视角从「这个观点对不对」拉升到「这件事在更大的图景里是什么」，提炼本质，并按《金字塔原理》的结论先行结构产出报告。

---

## 一、四个拉升透镜

对抗解决的是**局部真假**，透镜解决的是**全局位置**。四个透镜逐一过，每个透镜至少产出一条用户原表述里没有的判断。

### 1.1 外部视角（参照类）

用户的叙述天然是内部视角 —— 只看本案的细节。外部视角把本案当作某个类别里的一个样本。

操作：

- 定义参照类：与本案在「机制」上同类的历史事件集合，而不是在「表面特征」上相似
- 取该类的基础分布：成功率、耗时中位数、典型失败原因
- 用基础分布做锚，再依本案特有条件小幅调整，得到修正后的估计
- 内部视角估计与外部视角估计的差距，就是本次判断中直觉溢价的规模

### 1.2 层级拉升

把这件事放回它所属的系统，问三层：

- **上一层**：这件事是哪个更大问题的一部分；上层问题解决了，这件事还需要解决吗
- **同一层**：与它并列的还有哪些事；把资源投到并列项上，回报会更高吗
- **下一层**：这件事由哪些子部件构成；哪个子部件的变化对结果的影响最大

层级拉升最常见的产出：**用户在优化一个不该存在的环节**。

### 1.3 时间轴与二阶效应

| 问项 | 内容 |
|------|------|
| 一阶效应 | 直接、立即、可见的结果 |
| 二阶效应 | 别人对一阶结果的反应，以及反应带来的结果 |
| 三阶效应 | 反应固化为新规则、新习惯、新均衡之后的长期结果 |
| 时间反转 | 把时间尺度换成 3 倍与 1/3，结论是否翻转；翻转说明结论依赖特定时间窗 |
| 不可逆性 | 这个决定错了以后能撤回吗，撤回成本多大 —— 可逆决策快做，不可逆决策慢做 |

一阶效应人人看得到，绝大多数判断失误发生在二阶。凡涉及他人会做出反应的事（价格、规则、激励、竞争），**必须**推到二阶。

### 1.4 立场矩阵

同一件事在不同立场看是不同的事。列出核心利益相关方，逐个填：

| 立场 | 这件事对他是什么 | 他的成功判据 | 他会怎么反应 |
|------|----------------|------------|------------|

用户的原判断往往只站在一个立场上成立。矩阵里出现「某方的反应会直接推翻本判断」时，该判断必须补限定条件。

## 二、本质提炼三问

四个透镜过完后，用三问把现象归约为机制。三问全部答完才算完成提炼。

| # | 问项 | 要求 |
|---|------|------|
| 1 | **不变量** | 这件事里，什么在变、什么不变；剥掉所有会变的表层，剩下的那条稳定关系是什么 |
| 2 | **驱动机制** | 是什么力量在推动结果；写成「因为 A 增加，所以 B 必然减少」形态的机制句，而不是现象描述句 |
| 3 | **约束条件** | 这条机制在什么边界内成立；边界之外会发生什么 |

判定提炼是否完成的客观信号：三问的答案能推导出用户原表述里的现象，反之则不能 —— 机制解释现象，现象不解释机制。答案仍是现象罗列时，回到问 2 重做。

## 三、认知升级报告模板

对话输出与落盘文件均采用以下结构。模板内所有表格**只给表头、不带示例行**，按实际内容逐行填写。标签一律取 [argument-anatomy.md 第七节](references/argument-anatomy.md#七标注标签) 的四个标签。

```markdown
# 批判性对抗：{claim 摘要}

## 1. 结论先行
- 修正后的观点：…（一句话，含限定条件）
- 置信度：高 / 中 / 低 + 一句理由
- 与原观点的关系：保留 / 收窄 / 推翻 / 替换

## 2. 靶心命题
| 项 | 内容 |
|----|------|
| 原始表述 | |
| 还原后的靶心命题 | |
| 对抗后的修正版 | |

## 3. 攻防记录
| 轮次 | 攻击面 | 靶点 | 判据编号 | 判定 | 一句话理由 |
|------|--------|------|---------|------|-----------|

## 4. 承重假设状态
| 假设 | 类别 | 状态 | 为假时的后果 |
|------|------|------|------------|

## 5. 全局重构
| 透镜 | 新增判断 |
|------|---------|

## 6. 本质提炼
- 不变量：…
- 驱动机制：…
- 约束条件（成立边界）：…

## 7. 待取证清单
| 待验证的事实 | 为什么关键 | 取证途径 | 取不到时对结论的影响 |
|------------|-----------|---------|------------------|

| 反复出现的模式 | 出现在哪几轮 | 典型后果 |

## 9. 可迁移自查表

|---|------------------------|

```

## 四、报告的两条硬要求

- **第 8 节是本技能的主产出**。修正一个观点只影响一次判断；识别出用户反复出现的思维模式才影响后续所有判断。归纳依据**必须**是攻防记录里同一类判据编号的重复出现，**严禁**凭印象给用户下性格式结论
- **第 9 节的每一条都要能脱离本次话题独立使用**，绑定本次具体对象的条目属本次行动项，**严禁**写入本表

```markdown
<!-- ✅ 正确：脱离本次话题仍可照做，属可迁移自查项 -->
下次做同类估算前，先取参照类的历史基础分布做锚，再依个案特征调整

<!-- ❌ 错误：绑定本次话题的具体对象，换个议题即失效，属本次行动项而非自查项 -->
下次注意 {某项目} 的排期
```
