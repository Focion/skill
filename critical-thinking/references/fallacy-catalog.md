# 谬误清单与推理有效性

本文件为 `critical-thinking` 技能的逻辑面与证据面攻击提供判据，源自《逻辑学导论》的演绎有效性、谬误分类与归纳因果部分。攻击时**必须**引用本文件的谬误编号，未命中任何编号的攻击按「立场性否定」作废。

---

## 一、先分清有效与可靠

| 概念 | 含义 | 对应攻击路径 |
|------|------|------------|
| **形式有效**（valid） | 前提为真时结论必然为真，只看推理形式 | 攻形式：给出「前提全真而结论假」的反例模型 |
| **可靠**（sound） | 形式有效 **＋** 前提全部为真 | 攻前提：指出某条前提为假或无证据 |

两条路径二选一即可击穿一个论证。攻击前先声明走哪条：说「你的推理不成立」而不指明是形式问题还是前提问题，等于什么都没说。

归纳论证不适用「有效」，只论**强度**：前提为真时结论有多大概率为真。攻归纳论证走第五节。

## 二、形式谬误（`FL-F*`）

| ID | 名称 | 形式 | 反例模型 |
|----|------|------|---------|
| FL-F1 | 肯定后件 | 若 P 则 Q；Q；故 P | 下雨则地湿；地湿；未必下雨（可能洒水） |
| FL-F2 | 否定前件 | 若 P 则 Q；非 P；故非 Q | 不下雨，地也可能湿 |
| FL-F3 | 中项不周延 | 所有 A 是 C；所有 B 是 C；故 A 是 B | 猫是动物，狗是动物，猫不是狗 |
| FL-F4 | 四词项 | 三段论中同一词在两处含义不同 | 见 FL-A1，按歧义处理 |
| FL-F5 | 选言肯定 | A 或 B；A；故非 B | 相容选言中 A、B 可同时为真 |
| FL-F6 | 换质换位错误 | 所有 A 是 B → 所有 B 是 A | 全称肯定命题不可简单换位 |

**FL-F1 是商业判断中出现频率最高的形式谬误**：「成功的公司都做了 X，我们做 X 就能成功」正是肯定后件叠加幸存者偏差。

## 三、相关性谬误（`FL-R*`）—— 理由与结论无关

| ID | 名称 | 识别信号 | 拆解提问 |
|----|------|---------|---------|
| FL-R1 | 人身攻击 | 攻击提出者的身份、动机、过往，而非其论证 | 换个人说同样的话，这个论证会变对吗 |
| FL-R2 | 诉诸权威 | 「某某大佬/某某公司也这么说」 | 这位权威在这个具体问题上做过什么可验证的工作 |
| FL-R3 | 诉诸大众 | 「大家都这么做」「行业共识」 | 共识形成时依据的是哪些事实，那些事实现在还成立吗 |
| FL-R4 | 诉诸传统 | 「一直都是这么干的」 | 当初这么定的约束条件，今天还在吗 |
| FL-R5 | 诉诸情感 | 用恐惧、同情、愤怒代替证据 | 把情绪词全部删掉，剩下的事实还支持结论吗 |
| FL-R6 | 诉诸无知 | 「没人能证明它不行，所以它行」 | 举证责任在主张方，你的正面证据是什么 |
| FL-R7 | 稻草人 | 把对方立场替换成更好打的弱化版再打 | 对方原话是什么，你复述的版本他会认吗 |
| FL-R8 | 转移话题 | 用相邻但不同的议题作答 | 我问的是 X，你答的是 Y，X 的答案是什么 |
| FL-R9 | 诉诸后果 | 「承认这一点后果很糟，所以它不真」 | 后果好坏与命题真假无关，证据在哪 |

## 四、预设谬误（`FL-P*`）—— 偷偷塞进未经证明的前提

| ID | 名称 | 识别信号 | 拆解提问 |
|----|------|---------|---------|
| FL-P1 | 虚假原因 | 把相关、时序先后当成因果 | 见第五节因果三条件，第三条排除了吗 |
| FL-P2 | 以偏概全 | 用少数案例、身边样本推全局 | 样本量多大，怎么抽的，覆盖了哪些反面情形 |
| FL-P3 | 丐题 | 结论以换词形式塞进前提，循环论证 | 把结论从前提里删掉，还剩下什么支撑 |
| FL-P4 | 假两难 | 只给两个选项，暗示别无他路 | 第三、第四条路是什么，为什么被排除 |
| FL-P5 | 滑坡 | 由 A 一路推到极端后果，中间环节全不论证 | 从 A 到 Z 的每一步转移概率分别是多少 |
| FL-P6 | 复杂问语 | 问题本身预设了未经同意的前提 | 这个提问预设了什么，那个预设成立吗 |
| FL-P7 | 偶例 | 把一般规则硬套到例外情形 | 这条规则成立的适用条件是什么，本案满足吗 |
| FL-P8 | 逆偶例 | 从特殊个案推出一般规则 | 这个案例的特殊条件，在一般情形里存在吗 |
| FL-P9 | 幸存者偏差 | 只统计留下来的样本 | 用同样方法失败的那批样本在哪，分母是多少 |
| FL-P10 | 移动球门 | 反例出现后临时给结论加限定 | 这个限定是原来就有，还是刚补上去的 |

**FL-P10 需在对抗中实时监测**：用户回应质询时临时缩小结论范围是正常修正，但**必须**当场把新限定写进靶心命题，否则同一命题会被反复以不同范围复用。

```markdown
<!-- ✅ 正确：接受限定的同一时刻改写靶心命题，适用范围被永久收窄 -->
接受该限定。靶心命题更新为「在 {条件 X} 下，{原命题}」，后续轮次一律以此版本为准。

<!-- ❌ 错误：口头接受却不改写命题，下一轮用户又按原始范围复用，对抗永远收敛不了 -->
好，那就算加上这个条件，我们继续看下一条。
```

## 五、归纳与因果（证据面攻击的主判据）

### 5.1 因果成立的三个必要条件

- **共变**：原因变化时结果随之变化
- **时序**：原因在结果之前
- **排他**：排除了共同原因与反向因果

三条缺任一条 → 命中 FL-P1。绝大多数「相关即因果」的错误死在第三条。

### 5.2 排除第三因的四个检查动作

| 动作 | 内容 |
|------|------|
| 找共同原因 | 是否存在同时驱动 A 与 B 的第三变量 |
| 查反向因果 | 有无可能是 B 导致 A |
| 找对照组 | 没有 A 的那组，B 的发生率是多少 |
| 看基础比率 | 在全体样本中 B 本来就以什么频率出现 |

### 5.3 证据类型与效力排序

从强到弱：`随机对照/受控实验` > `大样本统计（含对照组）` > `多来源一致的观察数据` > `专家意见` > `个案与轶事` > `个人直觉与类比`。

攻击写法：指出用户所用证据的类型，说明它支撑得起多强的结论，再指出其结论强于该证据 —— 这是证据面最有效的一击，比争论事实真假更难被反驳。

### 5.4 数据欺骗的常见手法

| 手法 | 识别信号 |
|------|---------|
| 平均数掩盖分布 | 只给均值不给分位数与方差 |
| 换基数 | 「增长 200%」不给绝对量；相对风险不给绝对风险 |
| 选择性区间 | 起止时间恰好落在有利端点 |
| 分母缺失 | 只报分子（案例数），不报总体 |
| 精确性伪装 | 给出小数点后两位以营造可信感，来源却无法追溯 |
| 指标替换 | 拿容易测的代理指标代替真正关心的目标 |
